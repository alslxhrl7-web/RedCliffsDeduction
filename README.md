# 적벽추리 — Red Cliffs Deduction

조조군 진영에서 사라진 화공대비책을 추적하는 한국어 싱글플레이 3D 추리 게임.
3일 동안 용의자를 심문하고 단서를 비교해 최종 지목한다.

## 프로젝트 설정

- Unity: 6000.6.0f1
- 템플릿: 3D URP
- 목표 플랫폼: Windows PC
- 광고 및 인앱결제: 없음
- 입력: 새 Input System
- UI: uGUI 기반, 기존 기획의 UnityEngine.UI 사용 방향 유지

## 현재 상태

첫 조사 프로토타입을 구현했다. 기존 프로젝트의 코드와 애셋은 아직 이식하지 않았다.

- 조조군 지휘 천막에서 조조를 마주한 채 시작 → 이름 입력 → 임시 참모 임명과 조사 명령 → 문서고로 전환.
- 지휘 천막, 문서고, 수군 진영은 같은 씬 안에 분리된 공간이다. 도입부 동안 이동은 잠기며, 임명 대화를 마치면 문서고 도착 지점으로 이동한다.
- 조조는 군략 탁자와 군기를 배경으로 한 바르코 3D 모델이다. 도입부 UI는 왼쪽에 배치하여 조조가 가려지지 않게 한다.
- WASD로 1인칭 이동, 마우스로 시점 조절, E로 가까운 대상을 조사하거나 대화.
- 빈 보관함에서 문서의 부재를 확인하고, 설평에게 형주 시절의 경력을 질문.
- 문서고 입구를 돌아보면 출입문 옆에 창을 든 두석이 있다. E로 경비 상황과 수군 진영으로 가는 길을 묻는다. 두석의 진술은 선택 조사이며 수군 진영 이동 조건에 포함되지 않는다.
- J로 수첩 열기. 사실·확인할 일과 설평·두석·채모·장윤의 미검증 진술을 페이지별로 구분한다.
- 빈 보관함 조사와 설평 경력 진술 확인을 마치면 문서고 출입문에서 E로 수군 진영 이동을 선택한다. 두석의 길 안내, Esc → ‘장소 이동’, J → ‘다음 조사 선택’으로도 이동할 수 있다. 조사가 부족하면 남은 확인 항목을 안내한다.
- 수군 진영의 두 천막 앞에서 채모·장윤에게 어느 순서로든 질문한다. 두 사람은 기록을 대조하는 관점을 설명한다. 구체적인 과거 사건의 모순을 확정하거나 범인을 자동 판정하지 않는다.
- 수군 진영 입구의 나무 화살표 표지에서 E로 문서고 귀환을 선택한다. 두 장소를 오가도 이름과 모든 조사 기록은 유지되며, 설평·두석과 다시 대화할 수 있다.
- Esc로 대화/수첩 닫기 또는 일시정지. 도입부는 버튼으로 진행한다.
- 이름은 최대 16자이며 공백 입력은 ‘이름 없는 참모’로 처리한다.
- 이름과 조사 기록은 이번 Play 실행 동안만 유지된다. 저장, 3일 시간 진행, 구체적 진술 모순 판정, 경력·호적 재조사, 최종 지목 및 엔딩은 아직 구현하지 않았다.
- 조조·설평·두석·채모·장윤은 바르코에서 제작한 3D 모델을 사용한다. 공간은 임시 도형이며, 인물은 아직 애니메이션 없는 정적 모델이다. UI는 Windows의 맑은 고딕을 실행 시 불러오며 폰트 파일은 배포하지 않는다.
- 모델 원본과 URP 재질은 `Assets/Art/Characters/Varco`에 있다. 모델 출처와 재적용 방법은 `Docs/바르코 인물 모델.md`를 참고한다.

`Docs/사건 정답지.md`는 이번 대화에서 정한 사건 설정의 사본이며 스포일러를 포함한다.
노션 원본과의 동기화는 아직 수행하지 않았다.

## 시작하기

Unity Hub에서 이 폴더를 열고 Unity 6000.6.0f1을 사용한다.
`Assets/Scenes/Investigation.unity`를 열고 Play를 누른다. 또는 `적벽추리 > 첫 조사 장면 생성 또는 열기` 메뉴를 사용한다. 이 메뉴는 기존 조사 씬을 덮어쓰지 않는다.
Assets, Packages, ProjectSettings와 문서는 버전 관리하고 Library 등 자동 생성 폴더는 제외한다.
기존 조사 씬에 두석·수군 진영과 이동 참조를 추가하거나 다시 연결할 때는, 씬을 저장한 뒤 `적벽추리 > 문서고와 수군 진영 연결`을 사용한다. 기존 문서고와 도입부를 다시 만들지 않으며, 재실행 시 같은 이름의 배치를 갱신한다.

## 직접 확인할 순서

1. 시작 배경이 문서고가 아닌 지휘 천막인지, 오른쪽에 조조가 보이는지 확인한다. 이름 입력 후 시작 버튼을 누르고 조조의 명령을 끝까지 읽는다.
2. ‘명을 받고 문서고로 향한다’를 누른 뒤 문서고에서 WASD와 마우스로 이동한다.
3. 중앙 책상의 빈 보관함에 접근하여 아래를 보고 E를 누른다.
4. 오른쪽 설평에게 접근해 E를 누르고 ‘형주에서 무슨 일을 했는가?’를 선택한다.
5. 진술 확인까지 진행하고 대화를 끝낸 뒤 J로 수첩을 확인한다.
6. 조사 순서를 바꾸거나 대화를 중단해도 다시 진행할 수 있는지 확인한다.
7. 뒤쪽 출입문 옆의 두석을 바라보고 E로 경비 상황을 묻는다. ‘수군 진영으로 가려면?’을 선택하거나 출입문을 바라보고 E를 눌러 진영 이동을 선택한다. 두 필수 조사를 마치기 전에는 남은 조사 항목을 안내한다.
8. 진영 입구에서 왼쪽 천막 앞 채모, 오른쪽 천막 앞 장윤에게 E로 ‘당시 수군 훈련과 기록에 관해’를 질문한다. 둘 중 누구부터 만나도 된다. 수첩의 다음/이전 기록으로 각 진술을 확인한다.
9. 진영 입구의 나무 화살표 표지를 바라보고 E로 문서고 귀환을 선택한다. 이름·단서·진술이 유지되고, 이동과 재조사가 가능한지 확인한다. Esc → ‘장소 이동’과 수첩의 ‘다음 조사 선택’으로도 왕복할 수 있다.
10. 실행 검사는 새 Play 세션에서 `적벽추리 > 조사 동선 검사 (문서 먼저)`를 실행하고, Play를 재시작한 뒤 `(진술 먼저)`를 실행한다. 각 검사는 진행 상태를 변경한다.
