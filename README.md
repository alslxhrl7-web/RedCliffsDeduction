# 적벽추리 — Red Cliffs Deduction

조조군 진영의 군령 분실을 조사하고, 문서의 이동과 사람들의 진술을 대조하는 한국어 1인칭 추리 게임.

주요 업데이트: [패치노트](Docs/PATCH_NOTES.md). 이후 주요 수정도 버전별 패치노트로 기록한다.

## 현재 기준 버전

현재 기준은 `0.1.0-demo.8`이다. 군령 후속 수사, 기록관, 인물 대화·대기 동작과 2026-10-13 손가락·장윤 옷자락 국소 보정을 포함한다.
프로젝트 경로는 고정되어 있지 않다. 저장소를 받은 폴더에서 작업한다.
별도 사본과 복구 씬의 내용 비교 및 통합 내역은 [로컬 통합 기록](Docs/로컬%20통합%20기록%202026-10-09.md)에 있다.

## 구현된 범위

- 타이틀 → 이름 입력 → 조조의 군령 분실 조사 명령.
- 문서고와 수군 진영 이동, 반출 기록과 미수령 진술 확인.
- 전달자의 인계 주장 검증, 자백 없이도 가능한 문서 회수.
- 회수 군령·인계 확인표·보관 부본·승인 여부 비교.
- 수군 배치 영향 추론, 조조 최종 보고의 근거 선택과 BAD/NORMAL/TRUE 엔딩.
- 수첩·저장과 불러오기. 새 이야기 저장은 버전 2 및 별도 order-investigation 파일을 사용한다.
- 인물 자세·대화 손짓·대기 움직임, 2D 증거 문서, 문서고 소품, 걸어서 왕복하는 연결 길, 거리 감쇠 발소리와 소리 설정. 입을 벌리는 변형은 제거했다.

재작성 의뢰·반환 원문·접수/출고 기록·거절 회신의 도착 순서를 조사한다. 중간 보고는 제거했으며 최종 보고에서 선택한 결론·제출 근거·시행 조치로 제17호 사건의 엔딩이 갈린다. 자료 수집만으로 진엔딩이 자동 확정되지 않는다. 전체 적벽 전투 승패와 한진의 내통 동기는 별도 미구현 구간이다. 한진은 기존 서기 외형을 임시 사용하고 조사 한도 12회는 임시 규칙이다.

## 실행

1. Unity Hub에서 프로젝트 폴더를 Unity **6000.6.0f1**로 연다.
2. `Assets/Scenes/Investigation.unity`를 열고 Play를 누른다.
3. WASD 이동, 마우스 시점, E 조사·대화, J 수첩, Esc 메뉴를 사용한다.

Windows 실행본은 Unity 메뉴 **적벽추리 → Windows 빌드**로 만든다. 현재 빌드 버전은 `0.1.0-demo.8`이며 `Builds/RedCliffsDeduction-0.1.0-demo.8-windows-x64/`에 저장한다. 같은 버전 폴더가 있으면 시각을 붙여 새 폴더를 만든다. **적벽추리 → 배포 ZIP 만들기**는 현재 버전의 가장 최근 실행본을 묶는다. 실행 파일과 같은 폴더의 Data·DLL 파일을 함께 유지한다.

메뉴에는 빌드와 배포 ZIP 두 항목만 표시한다. 기존 제작·검사 도구는 `Assets/Editor/`에 보존하며 메뉴 등록만 제거했다. 과거 패치노트에 적힌 제작·검사 메뉴는 현재 메뉴 구성을 나타내지 않는다.

## 다른 컴퓨터에서 이어서 작업하기

1. Git과 Git LFS를 설치한 뒤 저장소를 받는다.

   ```sh
   git lfs install
   git clone https://github.com/alslxhrl7-web/RedCliffsDeduction.git
   cd RedCliffsDeduction
   git lfs pull
   git lfs fsck
   ```

2. Unity Hub에서 **6000.6.0f1**과 Windows 빌드 지원 모듈을 설치하고, `Assets`, `Packages`, `ProjectSettings`가 있는 저장소 루트를 연다. 처음에는 패키지 다운로드와 Library 재생성을 기다린다.
3. `Assets/Scenes/Investigation.unity`에서 이어서 작업하거나 위 빌드 메뉴를 사용한다. 실행용 보정 메시·텍스처·모션 데이터와 `.meta`가 포함되어 있어 Blender나 VARCO 연결 없이 Unity 편집·빌드가 가능하다.
4. 최근 Blender 편집 원본(`ArtSource/CharacterRepair20261012`, `ArtSource/ConversationMotions20261012`)은 요청에 따라 Git에서 제외한다. 이 Blender 작업 자체를 이어가려면 해당 두 폴더를 별도로 옮겨야 한다. Unity용 에셋은 저장소에 포함한다.

`Library`, `Temp`, `Logs`, `Builds`, `LocalArchive`는 로컬 생성물이다. 다른 컴퓨터에 복사할 필요가 없다. `com.unity.pipeline`은 `Packages/com.unity.pipeline`에 포함된 프로젝트 내부 패키지이며 개인 PC의 절대 경로를 사용하지 않는다. .NET 기반 별도 컴파일 도구를 사용할 때 Unity 설치 경로가 다르면 `UNITY_MANAGED` 환경 변수로 지정한다.
