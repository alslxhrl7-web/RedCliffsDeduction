# 적벽추리 — Red Cliffs Deduction

조조군 진영에서 사라진 화공대비책을 추적하는 한국어 싱글플레이 3D 추리 게임.
3일 동안 용의자를 심문하고 단서를 비교해 최종 지목한다.

## 프로젝트 설정

- Unity: 6000.6.0f1
- 템플릿: 3D URP
- 목표 플랫폼: Windows PC
- 광고 및 인앱결제: 없음
- 입력: 새 Input System
- UI: uGUI 기반, 기존 기획의 UnityEngine.UI 사용 방향 유지

## 현재 상태

첫 조사 프로토타입을 구현했다. 기존 프로젝트의 코드와 애셋은 아직 이식하지 않았다.

- 조조군 지휘 천막에서 조조를 마주한 채 시작 → 이름 입력 → 임시 참모 임명과 조사 명령 → 문서고로 전환.
- 천막과 문서고는 같은 씬 안에 분리된 공간이다. 도입부 동안 이동은 잠기며, 임명 대화를 마치면 문서고 도착 지점으로 이동한다.
- 조조는 군략 탁자와 군기를 배경으로 한 임시 모델이다. 도입부 UI는 왼쪽에 배치하여 조조가 가려지지 않게 한다.
- WASD로 1인칭 이동, 마우스로 시점 조절, E로 가까운 대상을 조사하거나 대화.
- 빈 보관함에서 문서의 부재를 확인하고, 설평에게 형주 시절의 경력을 질문.
- J로 수첩 열기. 확인된 사실과 미검증 진술을 구분한다.
- 빈 보관함 조사와 설평 경력 진술 확인을 마치면 수첩에서 ‘다음 조사 선택’을 연다. 채모·장윤 조사는 준비 중으로 표시하며, 수첩이나 문서고로 돌아갈 수 있다. 이 화면을 오가도 이름과 조사 기록은 유지된다.
- Esc로 대화/수첩 닫기 또는 일시정지. 도입부는 버튼으로 진행한다.
- 이름은 최대 16자이며 공백 입력은 ‘이름 없는 참모’로 처리한다.
- 이름과 조사 기록은 이번 Play 실행 동안만 유지된다. 저장, 3일 시간 진행, 채모·장윤 조사, 최종 지목 및 엔딩은 아직 구현하지 않았다.
- 임시 도형으로 구성한 공간과 설평을 사용한다. UI는 Windows의 맑은 고딕을 실행 시 불러오며 폰트 파일은 배포하지 않는다.

`Docs/사건 정답지.md`는 이번 대화에서 정한 사건 설정의 사본이며 스포일러를 포함한다.
노션 원본과의 동기화는 아직 수행하지 않았다.

## 시작하기

Unity Hub에서 이 폴더를 열고 Unity 6000.6.0f1을 사용한다.
`Assets/Scenes/Investigation.unity`를 열고 Play를 누른다. 또는 `적벽추리 > 첫 조사 장면 생성 또는 열기` 메뉴를 사용한다. 이 메뉴는 기존 조사 씬을 덮어쓰지 않는다.
Assets, Packages, ProjectSettings와 문서는 버전 관리하고 Library 등 자동 생성 폴더는 제외한다.

## 직접 확인할 순서

1. 시작 배경이 문서고가 아닌 지휘 천막인지, 오른쪽에 조조가 보이는지 확인한다. 이름 입력 후 시작 버튼을 누르고 조조의 명령을 끝까지 읽는다.
2. ‘명을 받고 문서고로 향한다’를 누른 뒤 문서고에서 WASD와 마우스로 이동한다.
3. 중앙 책상의 빈 보관함에 접근하여 아래를 보고 E를 누른다.
4. 오른쪽 설평에게 접근해 E를 누르고 ‘형주에서 무슨 일을 했는가?’를 선택한다.
5. 진술 확인까지 진행하고 대화를 끝낸 뒤 J로 수첩을 확인한다.
6. 조사 순서를 바꾸거나 대화를 중단해도 다시 진행할 수 있는지 확인한다.
7. 두 조사를 마친 뒤 J로 수첩을 열고 ‘다음 조사 선택’을 누른다. ‘채모·장윤 조사 · 준비 중’이 비활성 상태인지 확인한다.
8. ‘수첩 다시 보기’와 ‘문서고로 돌아가기’ 또는 Esc를 사용해도 이름·단서·진술이 유지되고, 문서고에서 이동과 조사가 다시 가능한지 확인한다.
