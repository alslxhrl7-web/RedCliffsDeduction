## 구현된 범위

- 타이틀 → 이름 입력 → 조조의 군령 분실 조사 명령.
- 문서고와 수군 진영 이동, 반출 기록과 미수령 진술 확인.
- 전달자의 인계 주장 검증, 자백 없이도 가능한 문서 회수.
- 회수 군령·인계 확인표·보관 부본·승인 여부 비교.
- 수군 배치 영향 추론, 조조 중간 보고와 현장 복귀.
- 수첩·저장과 불러오기. 새 이야기 저장은 버전 2 및 별도 order-investigation 파일을 사용한다.
- 인물 자세·대기 움직임·대화 입 움직임, 2D 증거 문서, 문서고 소품, 걸어서 왕복하는 연결 길, 발소리와 소리 설정.

현재 구간은 중간 보고까지다. 군령 교체 수법, 원래 본문의 행방, 조작자 입증, 새 최종 보고·전투 엔딩은 아직 구현되지 않았다. 조사 한도 12회는 임시 규칙이다. 미확정 후속 제안을 구현 완료로 취급하지 않는다.

## 실행

1. Unity Hub에서 위 프로젝트 폴더를 Unity **6000.6.0f1**로 연다.
2. `Assets/Scenes/Investigation.unity`를 열고 Play를 누른다.
3. WASD 이동, 마우스 시점, E 조사·대화, J 수첩, Esc 메뉴를 사용한다.

Windows 실행본은 Unity 메뉴 **적벽추리 → 데모 수정 → 수정 데모 빌드**로 만든다. 현재 빌드 버전은 `0.1.0-demo.4`이며 Builds에 저장한다. 같은 버전 폴더가 있으면 시각을 붙여 새 폴더를 만든다. 실행 파일과 같은 폴더의 Data·DLL 파일을 함께 유지한다. 이전 demo.2·demo.3 실행본에는 최신 군령 조사 내용이 없다.

최신 군령 조사 검사는 타이틀이 보이는 Play 상태에서 **적벽추리 → 군령 조사 → 진행과 저장 검사**로 실행한다. 이전 이야기의 회귀 검사는 현재 군령 구간의 검증을 대신하지 않는다.
