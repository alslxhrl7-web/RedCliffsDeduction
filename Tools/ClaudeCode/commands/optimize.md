적벽추리 프로젝트를 최적화해 줘. 범위: $ARGUMENTS (비어 있으면 프레임 시간과 빌드 크기부터). CLAUDE.md의 "최적화 원칙"과 "꼭 지킬 것"을 따른다.

1. **측정:** 지금 상태의 기준값을 잰다. Unity MCP로 플레이 모드 통계·프로파일러를 보거나, 최근 빌드 보고서와 빌드 폴더 크기를 본다. 잰 방법과 값을 기록한다.
2. **원인 찾기:** 가장 효과가 클 후보 3~5개를 근거(수치, 코드 위치)와 함께 정리한다. 추측은 추측이라고 적는다.
3. **제안하고 멈추기:** 후보마다 예상 효과, 위험, 화면·플레이가 달라지는지를 적어 사용자에게 보여 주고 승인을 받는다. 화면이나 플레이가 달라지지 않는 순수 코드 개선(할당 줄이기 등)도 먼저 목록으로 보여 준다.
4. **적용:** 승인된 것만 한 번에 하나씩 바꾼다. 바꿀 때마다 `Tools\CompileCheck\compile-check.cmd`와 `적벽추리/군령 조사/진행과 저장 검사`를 다시 돌린다.
5. **재측정:** 같은 방법으로 다시 재서 전후를 비교한다.
6. **기록:** `Docs/PATCH_NOTES.md`의 작업 중 버전에 "개선"으로 전후 수치와 함께 적는다. 최적화 중 발견한 버그는 `Docs/수정기록.md`에 적는다.
7. 빌드, commit, push는 사용자가 요청할 때만 한다. 보고는 구현 / 검사 / 빌드 / GitHub 업로드를 따로 적는다.
