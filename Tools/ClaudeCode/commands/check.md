적벽추리 프로젝트를 검사해 줘. CLAUDE.md의 "검사 방법"과 "꼭 지킬 것"을 따른다. 코드는 고치지 말고 검사와 보고만 한다(고칠 게 보이면 보고서에 제안으로 적는다).

1. `Tools\CompileCheck\compile-check.cmd`를 실행해 컴파일 결과를 확인한다.
2. Unity MCP가 연결돼 있으면:
   - 플레이 모드에 들어가 타이틀 화면이 뜨면 `적벽추리/군령 조사/진행과 저장 검사`를 실행한다.
   - `Logs/OrderChapter/checks.txt`가 `COMPLETE`로 끝날 때까지 기다린다.
   - 타이틀 검사 3개도 실행한다.
   - 콘솔의 오류·경고를 모은다. 끝나면 플레이 모드를 나온다.
   연결이 안 돼 있으면 사용자에게 어떤 메뉴를 눌러야 하는지 알려 주고, 결과 파일을 읽어서 이어간다.
3. "실행 전에 물어볼 메뉴"는 실행하지 않는다.
4. 결과를 이렇게 보고한다.
   - 통과/실패 개수, 실패한 검사 이름과 원인 추정(코드 위치 포함)
   - 콘솔 오류
   - 검사하지 못한 것과 그 이유
   - 구현 / 검사 / 빌드 / GitHub 업로드 상태를 따로
5. 새로 발견한 문제는 `Docs/수정기록.md`에 "미수정" 항목으로 추가한다(발견·관련 코드·상태). 패치노트에는 쓰지 않는다.
