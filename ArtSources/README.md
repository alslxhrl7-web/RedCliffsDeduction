이 폴더의 `20261019/characters-source.zip.partNNN`은 **Blender 편집 원본 파일 자체**를 손실 없이 압축·분할한 것이다. 경로 안내만 있는 자료나 LFS 포인터가 아니다. 각 조각은 42MiB 이하이며 일반 Git에 저장한다.

저장소 루트에서 Python 3.11 이상으로 실행한다.

```text
python Tools/Restore-CharacterSources.py --verify-only
python Tools/Restore-CharacterSources.py
```

두 번째 명령은 원래 프로젝트 상대 구조의 LocalArchive에 복원한다. 다른 작업 원본이 이미 있으면 덮어쓰지 않고 중단한다. 다른 사본에서 열려면 `--destination 원하는폴더`를 사용한다. manifest.json에는 원본과 분할 파일의 크기·SHA-256을 기록한다.

현재 원본은 작업 중이다. 설평의 게임 눈 청록색 표시가 미해결이며 판매 품질 완료를 의미하지 않는다. 과거 파츠 원본에 보존된 교육용 Enemies 자료는 상업 이용 허가를 받은 자료가 아니다. 최종 판매용 의존성 검토가 필요하다. 게임 런타임의 폐기된 조조 EnemiesHair 출력과 검토 캡처·캐시는 이번 커밋에서 제외한다.
