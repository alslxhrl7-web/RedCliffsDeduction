# v3 캐릭터 블렌더 정리본 — 2026-10-11

`RedCliffs_Characters_v3_refined.blend`를 열면 10명을 5열 2행으로 확인할 수 있다. 텍스처를 내부에 포함했다. 각 인물은 별도 이름·컬렉션으로 구분한다.

## 변경

- 10명 원본은 상위 `ModelsOriginal`에 그대로 보존. 다운로드 출처와 SHA256은 `download-manifest.json`.
- 게임용 크기 1.68–1.80m로 정규화하고 발밑을 원점 Z=0에 배치. 신장은 게임용 설정값이며 역사적 실측치가 아니다.
- 같은 위치의 중복 정점만 0.001mm 허용 오차로 결합. 총 233,265 → 149,348 정점. 각 모델 30,000면·UV 유지. UV 이음매는 내보내기/게임 엔진에서 다시 분리될 수 있으므로 GPU 정점 수 36% 감소를 뜻하지 않는다.
- 면 방향 재계산, 부드러운 음영과 55도 이상 모서리 구분. 정리 후 열린 경계·비정상 연결·퇴화 면·독립 정점 검사값 모두 0.
- 생성 ORM을 금속성으로 해석했을 때 옷과 피부가 금속처럼 반사되어 무광 검토 재질로 보정(roughness .82, metallic 0). 원래 ORM 이미지는 보존. 실제 철갑과 옷감의 물리적 재질 분리는 아직 필요하다.
- 개별 FBX와 GLB는 발밑 원점에 저장. 편집 장면에서만 보기 좋게 배열했다.
