- 장수의 과장된 금속 장식을 줄이고 나이·체형·복장 색을 구분한다.
- 한진을 기록 담당자 복제 외형에서 분리할 고유 원화를 만든다.
- 두석의 사각형 자루·상자형 창날을 원형 자루·소켓형 창날로 보완한다.
- 문구 세트에서 붓대와 붓끝이 분리돼 보이는 연결 문제를 보완한다.
