# 큰 Blender 원본 인계

기존 LFS 원본 4개를 내용 변경 없이 최대 25MiB 조각으로 분리했다. manifest.json에 원래 경로, 크기, 원본 및 조각의 SHA-256을 기록했다. 이 폴더는 일반 Git이며 원래 .blend는 로컬에 보존하고 Git에서 제외한다.

게임 실행에는 복원이 필요하지 않다. 다른 PC에서 과거 편집 원본이 필요하면 프로젝트 루트에서 Python 3.9 이상으로 실행한다.

    python Tools/restore_portable_art.py

조각과 결합 결과를 검증한 뒤 원래 위치에 복원한다. 이미 편집된 파일은 덮어쓰지 않는다. 검사만 하려면 `--verify-only`를 붙인다. 이 원본을 수정한 경우 조각도 새 버전으로 재생성해야 하며, 원본만 수정하면 Git 변경에 나타나지 않는다.

현재 버전의 파일은 LFS 없이 보관한다. 과거 커밋은 바꾸지 않았으므로 이전 버전을 체크아웃할 때는 LFS가 필요할 수 있다. 복원한 원본은 Unity Assets 밖에 있어 Blender 원본 복원 여부가 게임 자산 GUID에 영향을 주지 않는다.
