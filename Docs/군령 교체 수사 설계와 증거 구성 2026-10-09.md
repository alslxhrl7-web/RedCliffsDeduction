# 군령 교체 수사 — 설계와 증거 구성 v2

작성일: 2026-10-09. 사용자는 **설계와 증거 구성을 먼저 다듬기**를 선택했다. 아래는 그 요청으로 구체화한 추천 집필안이며, 개별 설정의 사용자 확정이나 Unity 구현 완료가 아니다. 코드·씬·빌드는 변경하지 않는다. 기존 확정 사항은 단계별 조사 구성과 확정 기록을 따른다.

## 1. 이번 구간의 질문과 도달점

문서 회수 뒤의 질문은 “전달자가 왜 숨겼는가”에서 “승인된 문서가 출고되는 사이에 누가 무엇을 바꾸었는가”로 이동한다.

추천 사건: **읽기 어려워진 군령을 그대로 다시 쓰는 권한을 받은 연락관이, 본문을 바꾼 뒤 정상 재작성 결과물로 제출한다.** 원래 본문은 작업 전후를 확인하기 위한 반환 묶음에 남는다. 인물은 기존 집필안의 한진을 가칭으로 사용한다. 그의 최종 이름과 적측 내통 동기는 이번에 확정하지 않는다.

이번 설계가 입증할 범위는 다음 세 가지다.

1. 한진이 다른 내용의 본문을 완성물로 제출하여 기존 본문을 대체시켰다.
2. 허용된 작업은 내용을 보존하는 재작성이며, 감시선 철수는 승인되지 않았다.
3. 한진은 철수 요청이 거절된 사실을 전달받은 뒤에도 그 내용의 본문을 제출했다.

세 번째까지 확보해야 단순 착오를 넘어 고의 유통을 판단한다. ‘한진이 모든 글자를 직접 썼다’나 ‘적과 내통했다’까지 자동으로 인정하지 않는다. 재발행 초안·필적·접근 권한만으로 위 세 판단을 대체하지 않는다.

## 2. 유지할 내용과 바꿀 후보

유지: 제17호, 같은 수령 부대, 강 입구 유지와 본진 철수의 차이, 전달자의 대조 생략·정상 확인·뒤늦은 불일치 발견·보류·은닉. 설평의 과거와 장윤의 보호 사정은 선택 조사다. 안내인 누명은 사용하지 않는다.

이번 구체화: ‘출고 준비 중 교체’의 기회를 **손상 자료 재작성 업무**로 좁힌다. 이 업무와 반납·내용 확인의 역할 분담은 게임의 창작 절차다. 실제 후한 군제의 확인된 제도로 소개하지 않는다.

한진은 중간 보고 뒤 처음 등장하는 인물이어서는 안 된다. 향후 구현 때 최초 문서고 조사에서 발급 담당이 재작성 담당을 소개하고, 한진에게 “본문을 다시 적어 넘기는 일을 맡았다”는 중립적인 설명을 들을 수 있게 한다. 이 대화를 빠뜨려도 작업 의뢰에서 신원과 역할을 확인할 수 있다. 초반 대화 완료를 진행 조건으로 만들지 않는다.

## 3. 물리적인 교체와 원본이 남는 이유

### 정상 업무

발급 담당은 군령과 보관 부본을 대조한 뒤 출고를 준비한다. 출고용 본문의 끝부분 목간이 갈라져 취급하기 불편해 재작성을 맡긴다. 핵심인 ‘강 입구 유지’ 부분은 읽을 수 있어야 한다. 파손 때문에 정답을 추측해야 하는 퍼즐은 만들지 않는다.

의뢰 범위는 **본문 내용 그대로 옮겨 쓰기, 원래 묶음 반환하기**다. 내용 변경은 별도 승인 사항이다. 기존 부본과 인계 확인표는 발급 담당에게 남고 재작성 담당에게 함께 넘기지 않는다.

새 묶음을 반납하면 발급 담당은 원래 묶음의 회수와 완성물 접수를 기록한다. 출고 담당은 전달자에게 넘길 묶음의 번호·부대·핵심 지시를 자기 인계 기록에 남긴다. 이 기록은 내용을 새로 승인하는 행위가 아니다. 내용 보존을 책임지는 담당자의 업무와 전달자의 실제 대조 의무가 따로 있다.

### 범행 — 추천 집필안의 제작용 진실

한진은 먼저 ‘본진 철수’로 바꿀 수 있는지 문의하지만 승인권자는 거절한다. 거절 회신이 한진에게 전달된 뒤, 그는 같은 번호와 수령 부대가 적힌 새 목간 묶음에 철수 지시를 넣어 완성물로 반납한다. 출고 봉인은 그 뒤 정상 담당자가 한다. **봉인을 훼손하지 않는 신기한 교체나 위조 도장이 수법의 핵심이 아니다.** 봉인은 이후 묶음의 이동을 추적하는 보조 자료이지 내용 변경의 승인 증명이 아니다.

한진이 바꿀 수 있는 것은 맡은 본문이다. 확인표와 독립 부본까지 고치려면 다른 보관 담당을 거쳐야 한다. 전달자가 정상적으로 대조하면 발각될 위험이 남는다. 기존 집필안처럼 위험을 감수한 시도이며, 전달자의 확인 생략을 완벽하게 예측한 계획으로 묘사하지 않는다.

이 선택에는 약점도 있다. 재작성 권한이 왜 연락관에게 있는지 설명 없이 넘어가면 수법을 위해 직책을 늘린 것처럼 보인다. 향후 초반 소개에서 한진의 업무를 ‘군령 정서와 인계를 맡은 연락관’으로 일관되게 보여 주는 안이 필요하다. 또한 원본은 결국 대조될 수 있으므로, 범인의 기대는 영구 은폐가 아니라 정식 대조가 이루어지기 전에 변경된 명령이 전달·시행되는 것이다. 발급 측이 반환물을 즉시 전면 대조하는 절차로 설정한다면 이 수법은 성립하지 않으며 폐기해야 한다. 전달자의 확인 실수는 이미 승인된 사건 원인이지만, 다른 담당자들까지 무능하게 만들어 성공시키지는 않는다.

### 원본 위치

원래 본문은 **문서고의 재작성 완료·반환 묶음**에 있다. 작업을 맡길 때 반환 의무와 수량을 기록했으므로, 한진이 없애면 완료 접수가 되지 않는다. 반납 뒤에는 발급 담당이 보관한다. 플레이어는 작업 의뢰의 반환 위치를 따라 찾는다. 우연히 뒤진 쓰레기통이나 범인의 숨겨 둔 자백문에서 발견하지 않는다.

원본이 남아 있는 이유가 한진의 무지가 되어서는 안 된다. 그는 이전 명령과 새 결과물이 다르다는 사실 자체를 영원히 숨기려 한 것이 아니라, 변경된 내용도 허가받은 것으로 취급시키려 했다. 그래서 “다시 쓰는 동안 변경 지시를 받았다”는 방어 주장을 할 수 있다. 플레이어는 원본을 찾은 뒤에도 그 방어를 검증해야 한다.

## 4. 문서 이동과 상대적인 시간표

기존 집필안의 분 단위 시각을 확정하지 않는다. 작업 번호·접수 순서·회신 수령 순서로 선후를 검증한다.

| 순서 | 사건 | 독립적으로 남는 자료 |
|---|---|---|
| A | 강 입구 유지 명령 승인, 부본과 확인표 보관 | 기존 부본·승인 확인 |
| B | 손상 본문 재작성 의뢰, 한진 수령 | 작업 의뢰와 수령 표시 |
| C | 한진의 철수 변경 문의에 승인권자가 거절 | 승인 측 회신 원기록 |
| D | 거절 회신이 한진에게 도착 | 수령 표시와 전달 기록 |
| E | 한진이 원래 본문과 ‘본진 철수’ 완성물을 반납 | 발급 담당의 반납 접수 기록 |
| F | 새 묶음 출고, 전달자가 내용 대조 없이 정상 확인 | 별도 출고 인계 기록·기존 반출 대장 |
| G | 전달자가 확인표의 장소 차이를 발견, 보류 후 은닉 | 현재 구현 구간의 자료와 진술 |
| H | 플레이어 회수·대조·중간 보고 | 현재 조사 기록 |

핵심은 **거절 도착 D가 완성물 반납 E보다 앞선다**는 사실이다. 승인 측의 발송 시각만 있고 실제 도착이 입증되지 않으면 한진이 알고 있었다고 판정하지 않는다.

## 6. 필요한 주장과 대체 경로

### 판단 A: 전달자가 받기 전에 내용이 바뀌었다

- 기본: K0 + K4의 ‘인계 전 철수’ 기록.
- 대체: K0 + K3의 완성물 내용 + 같은 묶음이 출고됐다는 인계 연결 확인.
- 불충분: 전달자의 “처음부터 이랬다”는 말만 듣기.

### 판단 B: 한진이 그 본문을 대체 결과물로 제출했다

- 기본: K1 + K2의 반환 이력 + K3의 직접 접수 기록.
- 대체: K1 + K4의 직접 인계 기록 + 발급 담당에게 K3의 접수 사실·묶음 연결을 재확인. 서류 카드를 놓쳤다고 인물 확인까지 막지 않는다.
- 한진의 자백은 두 경로 모두 필수가 아니다. K3 카드와 담당자 설명은 같은 출처이므로 각각을 독립 근거로 중복 계산하지 않는다.
- K3와 K4 및 보관 담당 확인이 모두 확보되지 않으면, 권한만으로 제출자를 확정하지 않는다. ‘담당 후보’ 상태로 둔다.

### 판단 C: 승인되지 않은 변경을 알고 제출했다

- K5 + K6의 동일 회신 연결·실제 수령·반납 전 도착 + 판단 B.
- K6의 수령 기록을 놓친 경우, 해당 전달 담당의 직접 설명과 승인 측 발송 원기록·완성물 접수 순서를 교차 확인하는 대체 경로를 둔다. 이 설명의 역할은 회신 전달 확인이며, 문서 본문을 바꾸는 장면을 목격했다는 만능 증언이 아니다.
- 이 대체 확인 때문에 새 핵심 증인을 추가하지 않는다. 기존 발급 담당이 회신 수령을 대면 확인한 업무로 배치하는 안을 사용한다. 그 확인과 K3가 같은 사람에게서 나왔다는 점을 표시하고, K5의 승인 측 기록과 K4의 출고 기록으로 교차 확인한다.
- 수령 순서가 모호하거나 거절이 반납 뒤에 도착했다면 고의 판단은 보류한다. K7이 있어도 최초 범행의 인지를 소급해서 채우지 않는다.

‘어떤 자료를 놓쳐도 항상 같은 결론’은 보장하지 않는다. **자백 없이 가능, 선택 비밀 없이 가능, 핵심 자료의 재열람·담당자 확인으로 복구 가능**을 보장한다. 독립 근거가 실제로 없으면 결론도 제한한다.

K2 실물을 아직 못 찾았어도, 검증된 부본과 승인 자료로 원래 명령을 보류·복원하는 조치를 요청할 수 있다. 원본 찾기를 이유로 이미 드러난 군령 위험을 방치시키지 않는다. K2의 보상은 문서 이동의 완성과 재작성 설명의 검증이지 무조건적인 진엔딩 열쇠가 아니다.

## 7. 실제 조사 장면 — 세 번의 설명 변화

### 장면 1: ‘훔쳐 없앤 원본’이 아니라 ‘돌려준 원본’

문서고에서 K1을 읽고 반환 묶음을 찾는다. 위치는 기록이 알려 주고, 원본은 다른 보관 문서와 함께 눈에 보이게 둔다. 과도하게 작은 클릭 지점은 사용하지 않는다. K2를 기존 부본과 나란히 비교한다.

플레이어 선택: “이 원본이 오래됐으니 회수본이 무조건 가짜다” / “재작성 전후에 내용이 달라졌다. 변경 허가를 확인해야 한다” / “원본이 여기 있으니 전달자는 숨긴 일이 없다”. 두 번째가 현재 입증 범위다. 오답은 반례와 함께 재검토하도록 한다.

### 장면 2: ‘전달자가 바꿨다’는 설명을 검증

수군 진영에서 K4와 회수본을 대조하면 전달자가 받기 전에도 철수 지시였다는 근거가 나온다. 문서고의 K3와 연결하면 한진이 제출한 완성물로 범위를 좁힌다. 전달자의 은닉 책임은 그대로 남는다.

한진 재질문 예시: “그 본문을 넘긴 것은 맞소. 다시 쓰는 동안 명령이 바뀌었다면 이전 묶음과 다른 것이 이상하오?” 이 대사를 보지 않아도 K3/K4로 같은 가설을 검토할 수 있다.

### 장면 3: ‘허가받은 변경’과 ‘잘못 들은 명령’을 가른다

플레이어가 K5를 확보하면 거절 내용이 보이지만, 그 순간 범인 확정 버튼을 주지 않는다. K6으로 실제 수령과 반납의 순서를 직접 배치한다. 정상 순서는 ‘변경 거절 도착 → 철수 본문 제출’이다.

최종 질문: “접근할 수 있었기 때문” / “글씨가 비슷하기 때문” / “거절을 전달받은 뒤에도 철수 본문을 완료물로 제출했기 때문”. 마지막 주장에 자료를 연결해야 고의 유통 판단이 성립한다. 자료만 수집해 자동으로 정답 문장을 완성하지 않는다.

한진이 끝까지 부인해도 판단은 가능하다. 자백 대사는 결론을 만든 뒤 선택적으로 제공하는 인물 반응이며, 미확보 자료를 대신 설명하지 않는다.

## 8. 안전 조치와 범인 수사는 별도로 진행

중간 보고에서 확인된 것은 승인 내용과 회수본의 차이다. 조조는 해당 제17호와 이를 대체하는 재발행을 **내용 확인 전 보류**시키는 방향을 추천한다. 현재 코드에는 이 후속 조치 상태가 별도로 구현되어 있지 않으므로 향후 추가 대상이다.

한진을 아직 특정하지 못했더라도 보류는 가능하다. 재발행 시도가 발견되면 보류 절차에서 걸린 신청으로 보여 준다. 범인이 아직 자유롭다는 이유로 조조가 이미 내린 보류가 저절로 무효화되지 않는다.

다음 세 상태를 구별한다.

- 위험 군령 보류: 잘못된 이동 명령을 잠시 막음.
- 올바른 배치 확인·집행: 부대가 유지 지시를 실제로 받고 준비했는지 확인.
- 범행 입증: 행위자·승인 위반·고의를 자료로 판단.

새 엔딩 조합은 별도 설계 대상이다. 무고한 사람을 잘못 지목했다고 이미 지킨 감시선이 갑자기 철수하는 연출은 사용하지 않는다. 수사 평가와 군사 결과를 구분해야 한다.

## 9. 현재 구현과 충돌하는 부분

- 현재 군령 본문은 감시선 배치 한 항목만 다룬다. 옛 리디자인 집필안에는 접근 확인 생략·소화대 이동까지 있다. 이번 구간의 자료가 나머지 두 명령도 입증한 것으로 처리하지 않는다. 후속에서 실제 자료를 추가할지, 감시선 한 명령으로 범위를 줄일지 따로 결정한다.
- 현재 씬에는 한진 조사 대상이 없다. 역할을 기존 병사에게 이름만 바꾸어 덮어쓰지 않는다. 초반 소개·배치·인계 자료 접근을 포함한 구현 계획이 필요하다.
- K1~K7은 새 설계 자료다. 기존 화면에 이미 적혀 있었다고 설명하지 않는다. 현재 부본·승인 확인과 식별 번호를 연결하는 개편이 필요하다.
- 현재 6~7회로 중간 보고에 도달하는 경로는 유지 가능하다. 후속은 ‘반환·접수 확인’, ‘승인 회신 추적’ 두 조사 묶음을 유료로 두고 기존 대상 재질문·비교·재열람·위험 보류 요청은 무료로 하는 시안을 둔다. 합계 8~9회는 대체 경로를 포함한 비용표를 만들기 전 예상이며, 12회 유지의 검증 결과가 아니다.

## 10. 반례 점검과 다음 검증

| 반례·플레이 상태 | 설계상 허용할 결론 |
|---|---|
| 한진 담당 서명만 확보 | 접근 기회만 확인, 범인 확정 불가 |
| 원본·부본·회수본만 비교 | 내용 변경 확인, 행위자 미확정 |
| 한진 제출 사실만 확인 | 제출 책임 확인, 착오·승인 여부 추가 조사 |
| 거절 발송만 확인, 도착 미확인 | 고의 입증 불가 |
| 거절 도착이 반납보다 늦음 | 최초 제출의 고의 입증 불가 |
| 전달자가 자백하지 않음 | K1~K6의 보관 자료 경로로 진행 가능 |
| K3를 읽지 않았으나 담당자 확인·K4 확보 | 같은 출처를 중복 세지 않는 대체 판단 가능 |
| 설평·장윤·두석의 개인 비밀 미조사 | 핵심 수사와 보류·복원 진행 가능 |
| K7 재발행 문구만 동일 | 최초 교체·내통 단정 불가 |
| 반환 본문을 먼저 발견 | 조사 자료로 보관, 출처 확인 전 진본 결론은 보류 |
| 비교 오답·판단 보류 | 증거 소실이나 영구 진행 차단 없음 |
| 군령 보류 성공, 범인 미확정 | 보류 효력 유지, 수사는 미완결 |

위 표는 설계 반례 점검이며 실행 테스트 통과 기록이 아니다. 구현 전에는 처음 보는 사람이 ‘재작성 허가’와 ‘명령 변경 허가’를 구분하는지, 원본 발견 뒤 추가 수사가 납득되는지, 세 번의 비교가 같은 정답 누르기의 반복인지 검토한다. 긴 기록은 K1/K2, K3/K4, K5/K6의 세 묶음으로 보여 주고 핵심 발췌와 원문 열람을 함께 제공하는 방향이다.

## 11. 고증 범위와 자료

한대 목간에 먹으로 쓴 문서, 끈으로 묶는 형식은 유물 자료를 참고할 수 있다. [Smithsonian National Museum of Asian Art의 한대 목간](https://asia-archive.si.edu/object/F1981.4a-e/)은 목재·먹과 묶음 형태를 설명하며, [중앙연구원 역사문물진열관](https://museum.sinica.edu.tw/en/collection/20/item/1039/)은 한대 목간·편철용 끈의 운송 기록을 소개한다.

이 자료만으로 208년 조조 진영의 구체적인 재작성·회신·반납 절차를 입증할 수는 없다. 문서 외형은 그 범위에서 참고하고, 제17호 양식·업무 분장·승인 회신 및 인물 행동은 창작으로 명시한다. 현대 인쇄 결재서, 서명 진위의 기계적 판독, 밀랍 편지 봉투를 필수 장치로 삼지 않는다.

## 12. 이번에 선택한 추천 방향과 남은 결정

추천 방향은 **정상 재작성의 악용 → 업무상 반환된 원본 → 거절 회신의 도착 순서로 고의 입증**이다. 자백·우연한 비밀 쪽지·과거 비밀 완주에 의존하지 않는다.

다음 결정은 한진의 최종 배역, 문서 업무의 복잡도를 실제 대사에서 얼마나 줄일지, 나머지 군령 두 항목을 다룰지, 수사 결과와 군사 조치를 결합한 엔딩 조합이다. 내통 동기와 새로운 전투 엔딩까지 이 문서가 확정한 것으로 해석하지 않는다.
