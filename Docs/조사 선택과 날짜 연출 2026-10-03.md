# 조사 선택과 날짜 연출

이번 변경은 자료 조사 비용 통일, 날짜 전환 연출, 정답 경로 안내 완화다. 진엔딩 외 엔딩 후일담은 추후 작업으로 남긴다. Unity 실행·빌드·청음 검증은 사용자 요청에 따라 수행하지 않았다.

## 조사 규칙

‘무료 자료’ 분류를 없앴다. 보관함(document), 정비 명령서(maintenance), 목패(token)도 새 조사 주제로 각각 1회를 쓴다. 인물 질문과 자료 확인 모두 시작 전 비용 확인을 거친다. 이미 조사한 주제의 기록 다시 읽기와 확보한 기록의 정리는 중복 차감하지 않는다. 이동·수첩·보고는 새로운 증거를 주는 조사가 아니다.

기존 저장의 이미 확보한 세 자료는 보존하고 소급 차감하지 않는다. 새 저장에는 세 조사 ID를 기록한다. 새 플레이의 주제 수는 16개, 시작할 수 있는 횟수는 12회다.

## 한 번의 플레이에서 가능한 진엔딩 경로 — 개발자용

| 조사 | 비용 |
|---|---:|
| 보관함 | 1 |
| 설평의 업무·경력·목패 소유 이력 질문 | 1 |
| 목패 | 1 |
| 채모 | 1 |
| 장윤 | 1 |
| 정비 명령서 | 1 |
| 설평의 현장 경험 재확인 | 1 |
| 인계 명부와 이전 근무 기록 | 1 |
| 신고 신원 대조 | 1 |
| 허가받은 개인 서류 수색 | 1 |
| 밀서 취조 | 1 |
| 합계 | 11 |

보관함 확인은 사건 이해를 위한 경로에 포함했으나 진엔딩의 필수 판정 항목은 아니다. 핵심 판정은 기존의 검증된 신원 대조와 밀서 증거를 유지한다. 목패 소유 이력 질문, 모순 판정, 조사 허가, 목패 대조 등은 확보한 주제 안에서 진행한다. 경비 기본 진술까지 듣는 경로는 12회가 된다. 다만 허가가 필요한 수색은 기한 종료 전에 허가를 받아야 한다. 숨은 회차 잠금이나 무작위 실패 조건은 추가하지 않았다.

## 정답으로 유도하지 않기

- 상단 목표에서 특정 인물 순서 안내를 없애고 플레이어가 조사 대상을 선택하게 했다.
- 진술 비교 화면에서 정답 설명과 필수 증거 체크리스트를 먼저 보여주지 않는다. 기록을 읽고 직접 판단해야 한다.
- 경력 확인 결과에서 호적 대조로, 신원 대조 결과에서 수색 허가로 바로 이어지는 지름길 버튼을 없앴다. 담당자와 대화하거나 지휘 천막에서 보고해 다음 조사를 선택한다.
- 미확인 자료의 구체적인 위치와 발견 전 밀서·접선 일정 노출을 줄였다. 발견한 기록과 인물의 실제 설명은 유지한다.
- 누구를 지목할지, 현재 기록으로 보고할지 선택할 수 있다. 보고를 위해 모든 자료를 모을 필요는 없다.

## 날짜 전환

최신 변경: 합성 종소리와 날짜 안내 확인 단계는 제거했다. 암전 중 날짜만 표시하고 자동 복귀하며 VARCO 군영 환경음이 계속 재생된다. 자세한 현재 사양은 `군영 배경음과 날짜 암전 2026-10-03.md`를 참고한다. 아래는 이전 연출 기록이다.

현재 장면 위에 전체 화면 전환을 띄운다. 별도 Unity 장면을 로드하지 않으므로 조사 플래그·위치·대화 이어하기를 보존한다.

0.45초 암전 → 날짜·잔여 조사 자막과 직접 합성한 낮은 종소리 1.8초 → 0.55초 복귀 → 날짜 안내 확인 후 원래 조사 계속. 총 약 2.8초. 셋째 날은 마지막 조사일로 표시한다. 현실 시간 기준으로 재생하며 전환 중 이동과 대화 입력을 막는다. 저장 불러오기는 진행 중 전환을 취소한다.

`InvestigationDayTransition`이 화면과 효과음을 생성하므로 별도 장면 연결이나 외부 음원 없이 실행할 수 있다. 기존 논리 검사에서는 연출 시간만 건너뛰도록 보조 함수를 연결했다. 실제 화면 크기, 청음, 입력 잠금 및 경로 완주는 Unity에서 확인해야 한다.

## 나중에 추가할 작업

진엔딩 이외의 노멀·대상별 배드·미해결 엔딩 이후 모습은 이번에 변경하지 않았다. 이후 각 결말에 맞는 군영 상황, 인물의 처리, 사건 여파를 별도 후일담으로 제작한다.
