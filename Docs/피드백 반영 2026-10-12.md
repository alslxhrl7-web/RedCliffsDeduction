# 2026-10-12 피드백 반영 — 한진 사건 기준

## 기준

원문은 사용자가 제공한 「적벽추리 피드백 · 적벽 기록관 설계.pdf」(2026-10-12, 5쪽)다. 문서의 제안과 현재 구현을 비교한 뒤, 사용자는 기록관을 **현재 한진의 제17호 군령 사건 기준**으로 구성하도록 선택했다. 원문 PDF는 수정하지 않았다.

## 이번 구현

- 인물 10명의 기존 RolePose 적용을 확인했다. 원본을 보존한 별도 Rest 메시에서 팔의 벌어진 각도를 작게 줄였다. 정식 리깅이나 새 애니메이션 제작을 완료했다는 뜻은 아니다.
- 대화 중에만 따뜻한 키 조명·차가운 윤곽 조명·약한 눈 반사 조명을 켠다. 세 조명 모두 그림자를 만들지 않는다. 가까운 인물과 대화할 때 시야각을 약 45도로 좁히고 인물을 화면 오른쪽, 대화를 왼쪽에 놓는다. 너무 가까운 경우 55도로 완화한다. 종료·장소 이동 때 원래 시점으로 복원한다.
- 타이틀에 기록관 버튼을 추가하고, 현재 군령 사건의 엔딩 화면에서도 들어갈 수 있게 했다. 조사 중 이동 메뉴에는 추가하지 않았다.
- 기록관은 인물 10명, 증거 12개, 결말 3종, 사건 순서 6개로 구성한다. 잠긴 카드에는 실제 제목·내용을 숨긴다. 실제로 확보한 자료를 다시 읽을 수 있으며, 인물은 회전하는 3D 모형으로 본다.
- 일반 저장 슬롯과 별개인 `redcliffs-order-archive-v1.json`에 해금·열람 여부를 누적한다. 재시작이나 과거 진행도 불러오기는 수집 기록을 되돌리지 않는다. 원자적 교체와 백업 복구를 사용하며, 손상된 파일을 모두 읽지 못하면 원본을 보존하고 저장 실패를 표시한다.
- 문서 외형 참고 이미지에 더해 VARCO에서 생성한 증거별 삽화 12종과 결말 삽화 3종을 연결했다. 해금한 기록에서만 별도 버튼으로 열 수 있다. 그림은 참고용이며 정확한 단서 내용은 본문으로 구분한다.
- 진엔딩 후일담은 「한진의 진술」로 구성했다. 재작성 의뢰, 거절 답신 수령, 전달자의 은닉과 변경 책임의 구분을 묻는 질문 3개다. 기존 증거를 벗어난 동기·첩자 관계를 새로 단정하지 않는다. 현재는 기록관에서 읽는 대화이며, 감옥 세트와 앉은 애니메이션은 아직 없다.
- 낮은 바람 앰비언스와 새 기록 열람 시 짧은 발현음(현을 뜯는 느낌의 합성음)을 추가했다. 기존 배경음·효과음 설정을 따른다.

## 후속 작업

1. 수군 진영 울타리 바깥의 강·배·안개·시간대별 하늘: 1차 적용. 강 수면, 정박선 4척, 먼 강둑, 거리 안개와 조사 시계 기반 하늘을 연결했다. 물결 셰이더·정교한 배 모델·실기기 성능 측정은 남아 있다.
2. 2막 조사 예산·날짜별 분기: 수치와 분기 조건이 원문에 구체적으로 없어 기존 12회 규칙을 유지했다. 변경 전 별도 설계가 필요하다.
3. 기록관 전용 결말 삽화 3종과 증거 고유 삽화 12종: 생성·연결 완료. 목록은 기존 텍스트 카드를 유지하고 상세 화면에서 그림을 연다. 목록 썸네일과 신규 해금 액자의 전환 연출은 남아 있다.
4. 감옥 세트·앉은 포즈를 사용하는 후일담 3D 연출: 현재는 대화 열람 단계다.
5. 건물 재질·비대칭 배치·배경 NPC·공유 애니메이션 12종: 미적용. 이번 포즈 보정으로 완료 처리하지 않는다.
