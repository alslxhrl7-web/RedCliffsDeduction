## 2026-10-18 두석 얼굴 파츠 — 제작 중

- 첫 UV 전개에 겹침이 있어 베이크 전에 기각했다. URPLab 안전 전개로 겹침은 없어졌지만 섬이 과도하게 분리되어 근접 품질 문제가 남았다. 얼굴 원본 밀도와 원본 UV를 보존한 별도 후보로 재검토한다.
- 첫 얼굴 베이크와 cage/ray 거리 변경 재시도에서 목에 검은 누락 무늬가 남았다. 거리 문제만으로 단정했던 초기 가설은 기각했다. 고밀도·저밀도 목 표면의 최근접 법선 방향을 대조해 뒤집힌 면이 섞인 것을 확인했다. 목의 변형·접합 형상 문제였다.
- 목 아래를 연결된 링으로 다시 구성하고 법선을 정리한 뒤 재베이크했다. `head-baked-neck-rebuilt.png`의 정면 전신에서 검은 무늬가 사라졌다. 근접 셰이딩 및 최종 게임 검증은 별도이며 아직 완료하지 않았다.
- 원본·설정·실패 출력은 `LocalArchive/CharacterParts20261018/Duseok`에 보존한다. `Baked/Head_FirstRejected`, `head-bake-report.json`, `head-bake-repair.json`, `bake-diagnosis.json`, `neck-topology-rebuild.json`을 대조한다. 베이크 성공 응답만으로 외형 검사를 통과 처리하지 않는다.

## 2026-10-18 머릿결 재제작

- 기존 균일 색상과 약한 가닥 베이크로 게임에서 매끈한 덩어리처럼 보였다. UV 방향을 따라 큰 결·잔결을 함께 구성하여 색상/탄젠트 노멀/AO를 재베이킹했다. 2K 베이크를 게임용 1K로 필터링하여 가는 선의 점무늬를 줄였다.
- 뒤통수 외피의 안쪽 교점과 기존 1.5도 자세 변환 누락은 형상·배치 문제였다. 외피 교점 보정과 포즈 정렬로 해결했으며 뒤통수 보정 뒤 두피 맵을 다시 구웠다. 베이킹만으로 접합 오류를 해결했다고 보지 않는다.

## 2026-10-18 조조 Enemies 헤어

- 초기 검토 렌더: 한국어 Blender의 노드 이름을 영문 `Background`로 조회해 실패했다. 노드의 표시 이름 대신 `type == BACKGROUND`로 조회하도록 수정하고 같은 창에서 재실행했다. 베이킹 자체는 이후 완료됐다.
- 가는 모발을 텍스처로 옮기면 원본의 실루엣과 개별 가닥 대비가 완전히 유지되지 않는다. 보조 가닥 메시를 추가했으나 Unity 근접 화면에서 점무늬가 발생했다. 최종 게임에서는 보조 가닥을 비활성화하고 색상·노멀·AO 베이크를 사용한다. 원본 가닥은 편집 파일에 보존한다.
- 재발 방지: 베이크 완료와 엔진 품질 통과를 구분하고 실제 게임 조명·거리에서 확인한다. FBX 앞뒤 축 오류는 베이킹 결함과 별개이며 적용 단계에서 수정했다.

## 2026-10-18 설평 UV 통합 노멀 경계 오류
- 서로 다른 원본 UV를 4K의 별도 영역으로 배치하고 자체 베이킹했다. 색상은 유지됐지만 원본 노멀을 재표본화한 결과 얼굴 UV 경계가 균열처럼 드러났다. 최초 결과는 Unity에 적용하지 않았다.

- 후속 진단: 깨끗한 노멀로 교체해도 같은 균열이 유지되어 노멀 단독 원인이 아님을 확인했다. 머리카락과 불투명 피부를 합친 재질에서 원본 UV의 알파가 피부에도 적용된 것이 주요 원인이다. 피부·옷·손발·모자의 알파를 불투명으로 고정하고 머리카락 영역만 투명도를 유지하도록 수정, 재검토 중이다.
- 최종 원인 진단: 노멀·알파를 제거한 단색 검토에서도 균열이 유지됐다. 조립 시 활성 부품인 모자의 Solidify(Cloth thickness)가 결합 게임 메시 전체에 남아, UV 분리 경계마다 중복 두께 면이 생긴 것이 주원인이었다. 위 노멀/알파 가설은 단독 원인이 아니었다. 원본 모자의 두께 설정은 보존하고 게임 결합 메시의 잘못 상속된 모디파이어를 제거, 노멀 재베이크와 FBX 재출력을 진행한다. 재발 방지: 부품별 모디파이어를 각 부품에 적용한 뒤 결합하며, 결합 후 잔여 모디파이어 목록을 검사한다.
- 최종 해결 확인: 모자 두께의 전체 상속 제거 후 Blender 얼굴 근접 렌더와 Unity 실제 얼굴 화면에서 균열이 사라졌다. 설평 게임 반영·대기/발화·대화 확인 완료. 오류 결과를 완성본으로 전달하지 않았다.

- **모발 알파:** 첫 곡면 수염에 투영 이미지가 반복되어 머리카락 조각/배경이 직사각형으로 나타났다. 투영 범위 밖을 차단하고, 색·밝기 기반 알파와 수염 범위를 결합해 다시 구웠다. 폐기한 밑형·시험 가닥은 게임 출력에 포함하지 않는다.
- **도구 지연:** 표면 방향 반복 조회와 속성 기록을 섞은 마스크 처리의 장기 지연은 베이킹 실패와 구분한다. 스크립트만 중단하고 같은 Blender 창에서 일괄 조회/기록으로 수정한 후 완료했다. 원본은 보존했다.
