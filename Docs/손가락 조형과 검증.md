# 손가락 조형과 검증

## 제작 원본

- `ArtSource/HandRefinement20261013/Hands.blend`: 기존 인물과 새 손, 손목 연결면, 편집용 손가락 구성 부품을 보관한다.
- `build_hands.py`: Blender 5.2에서 손바닥·엄지·네 손가락을 개별 구성하고 접합한다. 손가락별 길이·굵기·관절 곡률과 손목 각도를 조절할 수 있다. 원본이 있으면 기본 실행은 중단하며, 자동 생성본을 다시 만들 때만 `--replace-generated`를 사용한다.
- 기존 얼굴·의복과 동작 원본은 `CharacterDetail20261013/CharacterDetails.blend`에 그대로 남긴다. 원본 FBX를 덮어쓰지 않는다.
- 손 조형은 자체 제작이다. 검토했던 Quaternius 마네킹 손은 게임용 손 메시로 사용하지 않았다. 기존 외부 대기 동작의 CC0 출처는 `인물 세부 보정.md`에 유지한다.

## 베이킹과 게임 연결

- 손별 UV를 정리하고 Cycles에서 512×512 색상·탄젠트 노멀·거칠기를 베이킹한다. 거칠기는 Unity용 마스크의 A 채널에 매끄러움(1−거칠기)으로 변환하고 R 채널의 금속성은 0으로 둔다. 장면 조명과 그림자는 굽지 않는다.
- 네 손가락의 손톱 판과 관절 굴곡, 손등 힘줄은 실제 메시로 보강했다. 피부의 약한 표면 변화는 노멀 맵으로 옮겼으며 피부와 손톱의 거칠기를 구분했다. 고정 AO는 움직임과 맞지 않아 생략한다. 재현 코드는 `build_hands.py`와 `hand_detail.py`이며 편집 원본의 `Finger construction` 컬렉션에 조형 부품을 남긴다.
- `Assets/Art/Characters/RefinedHands`에 손 메시·색상·재질과 기존 손 면을 제거한 몸체 복사본을 둔다. 원래 몸체의 정점 번호를 유지해 기존 대기·대화 동작을 연결한다.
- `HandRefinementAuthoring`의 `Tools/Character Hands/Apply` 메뉴로 적용한다. 저장된 Investigation 씬의 Edit 상태에서만 실행한다. 같은 자산과 오브젝트를 갱신하므로 중복 생성하지 않는다.
- `RefinedHand`는 팔의 실제 변형 결과에서 손목 방향을 계산한다. 연결면의 경계는 원래 몸체 정점을 직접 따라간다. 네 손가락에는 Blender에서 만든 독립 이완 형태를 연결해 쉬는 구간을 두고 작게 움직인다. 기존 팔의 대기·대화 동작을 복제하지 않는다.
- 서류를 든 설평·기록 담당자·전령은 엄지·검지·중지의 접촉 자세를 고정하고 약지·소지만 미세하게 움직인다. 빈손은 손가락마다 굴곡과 이완 시점을 다르게 한다. 범용 물체 잡기나 손가락 IK 구현은 아니다.
- `WristSurface`는 잘린 손목 경계를 원래 삼각형 변의 보간으로 갱신한다. 제거된 손가락의 미사용 정점 번호를 재사용하므로 기존 동작 데이터의 정점 수를 바꾸지 않는다. 몸체 재질 구분은 실제 사용하던 `Repair20261012` 원본에서 복원한다.
- 설평·기록 담당자·전령의 서류는 Blender 원본에서 4cm 내려 손 위치에 맞췄다. Unity에는 같은 `HeldRecordOffset`을 적용한다.
- 원본 `.blend`와 제작 코드, 최종 게임 자산을 보관한다. Output·Preview·자동 백업은 Git 제외 대상이다.

## 품질 판단 범위

다섯 손가락 형상, 소매 연결, 몸통 관통, 실제 대기 동작과 진행·저장을 확인한다. 이번 추가 보정은 관절·손톱·피부 맵과 작은 이완 동작까지다. 가까이서 보이는 피부의 균일한 느낌, 엄지 손톱과 손바닥의 세부 조형, 물건을 바꿔 잡는 동작은 다음 작업으로 남긴다. 개별 손가락 뼈 리그 대신 블렌드셰이프를 사용하며, 출시 품질 검수가 완료됐다고 판단하지 않는다.
