# 날짜 전환 수정

아래는 최초 변경 당시 기록이다. 현재는 종소리·안내 확인 버튼을 제거하고 배경음이 이어지는 암전 → 날짜 자막 → 자동 복귀를 사용한다. 자료 최초 조사도 1회를 사용한다. 현재 사양은 `군영 배경음과 날짜 암전 2026-10-03.md`, 최신 확인 범위는 `적용 내용 점검 2026-10-04.md`를 참고한다.

## 변경 사항

- 신규 조사로 4회 또는 8회 경계를 넘으면 `둘째 날이 밝았습니다` / `셋째 날이 밝았습니다` 안내 화면을 표시한다. 셋째 날에는 마지막 날이라는 문구도 표시한다.
- 계속 버튼, E/Enter, Esc로 안내를 넘기면 원래 선택한 조사를 이어간다. 중복 입력으로 같은 조사를 다시 시작하지 않는다.
- `Esc → 날짜와 조사 일정 / 시간 보내기 → 남은 시간을 보내고 다음 날로`에서 오늘 남은 시간을 보낼 수 있다. 포기할 횟수를 확인한 뒤 다음 날 오전으로 이동한다.
- 셋째 날의 시간 보내기는 확인 후 조사 기한 종료와 조조의 호출로 이어진다. 넷째 날 조사나 추가 횟수를 만들지 않는다.
- 시간 보내기는 증거나 진술을 지급하지 않는다. 취소하면 날짜와 남은 횟수는 유지된다.
- 시간 보내기 기록도 기존 저장 형식의 일정 목록에 저장한다. 이전 저장 파일은 그대로 읽을 수 있다.

## 원인과 확인 범위

기존 날짜 계산은 신규 조사 시작 횟수만 센다. 같은 주제 재방문, 이동, 무료 자료 확인에는 시간이 흐르지 않는다. 따라서 이 행동만 반복하면 날짜가 바뀌지 않는 것은 기존 규칙이며, 실제로 간헐적인 계산 실패가 발생했다는 재현 증거는 아직 없다. 기존 화면에는 날짜 변경 안내와 직접 시간을 보내는 경로가 없었다. 이번 수정은 안내와 진행 경로를 추가하며 무료 재방문 규칙은 유지한다.

시간 계산 코드의 별도 실행 검사에서는 4회/8회 경계, 12회 종료, 중복 차감 방지, 각 시점의 시간 보내기, 일정 복원과 엔딩 조건 검사를 통과했다. Unity 플레이 및 배포 빌드 검증은 사용자 요청에 따라 수행하지 않았다.

## Unity에서 확인할 순서

1. Investigation 장면을 실행하고 새 조사를 4개 시작한다. 날짜 안내를 확인하고 계속 눌렀을 때 원래 대화가 이어지는지 본다.
2. 같은 주제를 다시 열어 시간이 추가 차감되지 않는지 확인한다. 무료 물건 확인과 장소 이동도 마찬가지다.
3. 일정 화면에서 다음 날 넘기기를 취소해 날짜가 유지되는지 확인한 뒤, 다시 선택해 다음 날 오전으로 넘어간다.
4. 시간 보내기 후 저장하고 불러와 날짜·남은 횟수·증거가 유지되는지 확인한다.
5. 셋째 날 시간 보내기를 선택하면 기한 종료 확인을 거쳐 조조의 호출이 나오는지 확인한다.

편집기 메뉴 `적벽추리 → 플레이 검증 → 날짜 전환과 시간 보내기`에 플레이 모드 회귀 검사를 추가했다. `조사 시간 계산` 메뉴는 시간 계산만 검사한다. 기존 동선 검사는 날짜 안내를 넘긴 뒤 원래 검사를 이어가도록 조정했다.
