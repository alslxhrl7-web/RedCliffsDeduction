# 조사 피로도와 대화 분산 개선

2026-10-09. 사용자 요청: 중간 확인 제거 → 비교 통합 → 동선 정리 순서로 적용하되, 한두 인물에게 대화 선택지가 몰리지 않게 수정.

## 바뀐 흐름

- 답변 뒤 별도의 ‘돌아가기’를 누르던 화면을 없앴다. 기존 인물 답변을 읽으면서 같은 화면에서 다음 질문 또는 대화 종료를 선택한다.
- 후속 문서 묶음을 열면 핵심 내용과 출처가 한 화면에 표시되고, 표시된 자료를 수첩에 함께 기록한다. 전문은 선택 열람한다. 기록만으로 추론 결과를 획득하지 않는다.
- 핵심 판단은 변경 시점 → 제출자 → 거절 답신 수령 후 제출인지의 세 질문으로 연결한다. 정답 확인 화면 없이 다음 질문으로 넘어가며 기록 여부는 아래 안내에 표시한다.
- 비교 화면은 확보한 근거만 짧게 모아서 보여준다. 문서 원문과 기본 군령·확인표·부본은 수첩에서 계속 열람할 수 있다.
- 중간 보고 이후 J 수첩은 후속 조사 요약을 바로 연다. 미확보 자료에 맞춰 다음 장소를 안내하며, 근거가 충분하면 현장 재방문을 요구하지 않는다.
- 완료한 배치 요청·후속 보고는 선택지에서 제외하고 결과를 본문에 남긴다. 옛 저장의 미완료 조치는 계속 요청할 수 있다.

## 담당 역할과 선택지

| 대상 | 역할 | 대화 주제 |
|---|---|---|
| 한진 | 자신의 작업과 제출 경위 | 작업 의뢰, 제출 기록에 대한 해명. 최대 두 질문 |
| 발급 기록 담당자 | 직접 받은 물건·건넨 회신의 증언 | 반납 확인, 답신 전달 확인. 두 질문 |
| 문서고 반환 묶음 | 의뢰·반환 원문·접수 목록 | 문서 묶음 열람. 인물 증언 메뉴 없음 |
| 수군 진영 발급 기록 탁자 | 보관 부본·승인 대장·회신철 | 문서 조사와 내용 대조. 담당자 대화와 별개 상호작용 |
| 전령 옆 출고 기록 | 실제 출고물의 별도 기록 | 출고 내역 열람 |
| 전령·채모·장윤·두석 | 기존 인계 주장·수령 확인·절차·목격 | 맡은 역할 유지. 무관한 후속 자료를 다른 병사에게 나눠 주지 않음 |

인물 수를 늘리지 않았다. 문서고에서 반환 묶음을 먼저 읽고 수군 진영에서 회수·출고·발급·회신을 조사하면 후속 자료 때문에 다시 문서고로 돌아갈 필요가 없다. 누락한 자료를 회수하는 이동 자체는 남아 있다. 한진 면담이나 발급 담당 증언은 주 경로의 추가 필수 관문이 아니다.

## 유지한 조건과 한계

- 주 경로의 조사 비용은 여전히 8회, 전체 한도 12회다. 첫 조사 전 비용 확인은 유지했다.
- 오답은 증거를 지우거나 고의 판단을 기록하지 않는다. 원문 미확보 시 의뢰·담당자 확인·출고 기록의 대체 경로를 유지한다.
- 회신철은 승인 측 회신과 수령 기록을 함께 보여준다. 직접 전달 증언은 별도 선택 조사이며, 수령 카드가 없는 기존 저장에서도 사용할 수 있다.
- 저장 버전과 사실 값은 유지했다. 기존 단계별 판단 진척은 그대로 이어진다.
- 이 조정은 클릭·메뉴 왕복을 줄인다. 실제 피로도와 추리 난이도는 초행 플레이 관찰로 확인해야 한다. 현재 오답과 정답 사이의 난이도 차이는 추가 조정 대상이다.
- 한진 전용 외형, 배치 이행 회신, 후속 심문과 결말은 이번 범위 밖이다.

이 문서는 같은 날짜의 후속 수사 구현 기록 중 ‘접수·증언 메뉴와 긴 수첩 구성’에 관한 설명을 대체한다.


## 검증 결과

Unity Play Mode 검사 42개 통과. 역할별 선택지, 물리적 기록 탁자 상호작용, 문서 묶음 자동 기록과 추론의 분리, 세 질문 진행, 오답 방어, 저장 복원, 대체 경로, 완료 조치 중복 방지, 핵심 요약의 스크롤 없는 표시를 확인했다. 결과: Logs/OrderChapter/checks.txt. 비교·수첩 이미지를 함께 검토했다.

첫 실행에서 기록 탁자의 충돌체를 루트에만 찾는 검사 오류가 있었다. 실제 탁자 상판·문서에 있는 자식 충돌체를 확인하도록 수정하고 플레이어와 같은 시선 검사로 접근 가능함을 확인했다.
