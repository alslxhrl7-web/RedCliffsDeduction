# 엔딩 구성 — 확정 및 구현 기준

기준일: 2026-10-01. 기존 링크를 유지하기 위해 파일명에만 ‘초안’을 남겼다. 별도 엔딩 씬 파일은 없으며 Investigation 씬에서 텍스트·버튼·암전으로 실행한다.

## 판정

| 확정 보고 | 엔딩 |
|---|---|
| 설평 + 검증된 호적·밀서 | True — 진엔딩 · 되찾은 대비책 |
| 설평 + 검증 단서 부족 | Normal — 엔딩? · 끝내 닿지 못한 증거 |
| 채모 | Caimao — 배드엔딩 · 빗나간 지휘선 |
| 장윤 | Zhangyun — 배드엔딩 · 장부 밖으로 사라진 문서 |
| 두석 | Duseok — 배드엔딩 · 빈 경비 자리 |
| 기한 종료 후 미해결/의심 | Unresolved — 배드엔딩 · 늦어 버린 보고 |

기한 전 의심·미해결은 조사 복귀다. 모순 발견 자체나 두석 조사 완료는 별도 엔딩 조건이 아니다. [최종 보고](최종%20보고%20구성.md) 참조.

## 진엔딩

조조는 실제 서리 경력과 숨긴 신원을 구분하고 신병 확보를 명한다. 군사들이 몸에 숨긴 화공대비책을 회수한다. 회수 뒤 후일담에서 설평의 본명 목연, 공동 근무 중 두석의 부재를 직접 확인한 범행 경위, 열닷새 새벽의 인계 계획을 밝힌다. 두석의 정확한 복귀 시각을 미리 알았다는 설정은 쓰지 않는다. 조기에 보고해도 성립하도록 ‘인계 직전’이 아닌 ‘예정된 인계 전’에 막았다고 표현한다.

결과: 범인·위장 신원 확인, 문서 회수, 전달 저지.

## 노멀엔딩

설평을 지목했지만 사건의 전모를 입증하지 못한다. 문서의 소지자와 행방은 확인하지 못한다. 설평의 체포·도주·처형이나 미확보 본명을 임의로 공개하지 않는다.

후일담 → ‘보고서를 덮는다’ → 암전 → ‘엔딩?’으로 연결한다. 다른 질문과 재검토로 다른 결말이 있을 수 있음을 암시하지만 진엔딩의 정답 목록은 주지 않는다. 재조사 또는 결과 확인을 선택한다. 증거 조합별 별도 노멀 대사는 현재 구현하지 않았다.

## 오지목·미해결 배드엔딩

- 채모: 훈련 지휘 책임과 절도를 구분하지 못한 결론의 한계를 짚는다. 채모의 처형을 묘사하지 않는다.
- 장윤: 군량 기록만으로 문서 반출을 입증하지 못했음을 짚는다. 플레이어가 하지 않은 오답 주장을 강제로 넣지 않는다.
- 두석: 경비 공백과 실제 절도를 구분한다. 노름과 근무 태만은 절도 자백이 아니다.
- 미해결: 사흘의 기한이 끝난 보고가 해결에 이르지 못한다.

모두 열닷새, 나흘째 새벽 접선 이후의 후일담에서 오나라 책상에 도착한 화공대비책을 서술한다. 전달자의 얼굴·본명·설평임을 드러내는 특징은 공개하지 않는다. 조사 당시 남은 횟수를 후일담 날짜처럼 계속 표시하지 않는다.

## 처형 암시와 다시 조사

배드엔딩 후일담 다음 조조가 조사 실패 책임을 주인공인 임시 참모에게 묻고 참형을 명한다. 군사들이 데려가는 설명 뒤 1.2초 암전과 0.8초 검은 화면을 거쳐 ‘다시 조사하시겠습니까?’를 표시한다. 처형 동작·신체 훼손·타격음은 없다.

‘예’는 이름 입력부터 재시작, ‘아니요’는 결과 화면이다. 수동 저장 파일은 삭제하지 않는다. 노멀엔딩에는 처형 암시를 넣지 않는다.

## 결과 화면과 구현 위치

결과 화면에서 제출 보고서, 엔딩 다시 보기, 초기화 확인 후 재시작, 저장한 조사 불러오기를 제공한다. 별도 제목 화면과 별도 3D 엔딩 연출은 없다.

코드는 `Assets/Scripts/Investigation/InvestigationSession.Endings.cs`와 `.Report.cs`, 암전은 `InvestigationView.cs`다. 실제 Play 모드의 엔딩·암전·재시작 검증은 [검증 결과](플레이%20검증%20결과%202026-10-01.md)에 기록한다.
