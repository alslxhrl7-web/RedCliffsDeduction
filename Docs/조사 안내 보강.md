# 조사 안내 보강 — 2026-10-01

12회 제한, 조사별 비용, 조사 개방 조건과 엔딩 판정은 유지한다.

- 조사 시작 확인창에 그 조사에서 확인하려는 질문을 표시한다. 답이나 결과를 예고하지 않는다.
- 두석 시간대 조사 메뉴와 수첩의 증언 페이지에서 확보한 진술, 아직 모르는 점, 더 확인할 질문을 구분한다.
- 교대 병사의 이탈·복귀 진술은 실제로 들은 범위만 표시한다. 노름은 두석의 해당 진술을 들은 뒤에만 안내한다.
- 다른 조사 방향은 이미 획득한 기록에 따라 표시한다. 비교 준비가 됐으면 수첩 비교 가능 사실만 알리고 모순의 정답을 알려주지 않는다. 모순을 직접 발견한 뒤에만 그 발견을 언급한다.
- 수첩 재검토와 이동은 무료임을 알린다. 새 안내를 읽는 것으로 시간이나 단서를 지급하지 않는다.

## 남은 검토

- 초보자가 안내를 이해하고 스스로 조사 방향을 바꾸는지 관찰하는 플레이 평가. 현재 12회 유지.
- 저장 미리보기는 구현 완료. 자동 저장·다중 슬롯은 별도 선택 사항.
- 기획 문서는 2026-10-01 기준으로 통일했다. 기준 문서와 항목별 안내는 [문서 안내](README.md)를 따른다.
- 배포 빌드 및 다른 해상도 확인, 추가 광원 그림자 품질 경고 검토.
