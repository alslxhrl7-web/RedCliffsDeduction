## 베이킹·게임 연결

- Cycles 16 samples, margin 12px. 몸통 색/탄젠트 노멀 2K, 얼굴 전용 색/노멀 2K, 손 전용 색/노멀 1K. 금속 R·매끄러움 A: 몸통 2K/얼굴 1K. 수염 RGBA 1K, 두피 2K, 상투 1K, 묶음 256px. 옆머리 전용 색/노멀 512px. 세부 모발은 공유 팔레트와 기하 노멀을 사용해 불필요한 노멀 맵을 생략한다.
- 색은 emission으로 옮겼으며 게임의 조명·그림자나 AO를 색에 추가하지 않았다. 기존 생성물과 보정 이미지에 내재한 명암이 있어 완전한 무음영 실측 알베도로 인증하지 않는다. 움직이는 인물의 고정 AO는 전달하지 않는다.
- 출력: 같은 Revision16의 `GameExport/CaoCao_Rework.fbx`와 `materials.json`에 열거된 텍스처. Unity 위치: `Assets/Art/Characters/VarcoV3/CaoCao/FullRework`, 프리팹: `CaoCaoVisual.prefab`, 씬: `Investigation`.
- 게임 FBX는 UV0만 전달하며 베이킹용 UV·색상 마스크는 원본에 보존한다. `Import Baked Revision` 메뉴는 완성된 묶음을 동기적으로 가져온다. 기존 메시 GUID를 유지하면서 Mesh API로 버퍼를 재작성한다. NPC 루트·충돌·상호작용을 유지한다.
- `CharacterHair.shader`는 결 방향에 따른 두 반사 성분, 실제 장면 광원·그림자·환경광을 사용한다. 모발의 정면/뒷면을 처리한다. 입모양 동작은 제외하며 기존 호흡·흔들림은 유지한다.

## 실제 실패와 수정

1. 사용자 첨부 화면에서 정지 상태의 검은 얼굴·뒤섞인 몸 텍스처를 확인했다. 재생 때만 정상인 상태를 완료로 취급하지 않는다. 기존 저장 메시의 `CopySerialized` 갱신을 없애고, 레이아웃을 비운 뒤 위치·노멀·탄젠트·UV0·부분별 인덱스를 Mesh API로 다시 작성·업로드했다. CPU 데이터 일치도 검사한다. 실제 네이티브/GPU 내부 원인은 직접 계측하지 않았으므로 버퍼 갱신 문제라는 판단은 관찰에 따른 추론이다.
2. 후속 손 분리 과정의 원본 UV 재구성이 위치만으로 대응해 UV 경계의 다른 값을 섞었다. 새 출력에서 갑옷의 붉은 번짐을 발견했다. 원본의 **면과 각 꼭짓점**으로 대응해 UV 경계를 보존하고 몸/얼굴/손의 색을 재베이킹했다. 형상·게임 UV는 유지했다.
3. 옆머리의 회색 경계를 원본 색·부위 ID·Unity의 실제 텍스처 샘플로 대조했다. 얼굴/몸 분리 양쪽에 걸친 차가운 두피 색을 마스킹하고 피부색을 보호해 색과 금속/거칠기를 다시 베이킹했지만 회색 반사가 남았다. 최종적으로 몸 567면·얼굴 96면의 두피 영역을 옆머리 파츠로 분리하고 512px 색/노멀과 헤어 셰이더를 적용해 회색 띠가 사라진 것을 확인했다. 색/재질 맵만 바꾸던 중간 시도는 해결로 판정하지 않았다.
4. 반복 표면 방향 조회와 속성 갱신을 섞은 처리 구간에서 지연이 발생했다. 현재 스크립트만 한 번 중단하고 같은 Blender 창의 연결을 복구했다. 방향·좌표를 일괄 읽은 뒤 일괄 기록하도록 바꾼 후 후속 작업이 완료됐다. 이전 블렌더 파일은 삭제하지 않았다. 복구 때 읽힌 `sys.last_exc`는 과거 FBX 오류이며 이번 지연의 원인 증거로 사용하지 않는다.

베이킹 문제는 [별도 기록](베이킹%20문제.md)에 구분한다. 실패 첨부·적용 전 진단은 Revision16의 `Failures`, 요청별 실행 결과는 같은 원본 폴더에 보존한다.

역사 기준은 [인물 고증 검토](인물%20고증%20검토%202026-10-18.md)의 후한 말 208년과 철편·교차 깃 비교 자료를 유지한다. 얼굴은 창작 해석이고 갑옷의 정확한 결속·편수는 미확정이다. 생성 이미지나 셰이더의 개선을 고증 완료로 표현하지 않는다. Enemies 교육용 모발 데이터는 최종 게임 의존성에서 제외하며, 원본은 별도 보관한다. 상용 AA 등급을 인증한 결과는 아니다.
