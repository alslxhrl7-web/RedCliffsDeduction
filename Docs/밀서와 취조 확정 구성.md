# 밀서와 취조 — 확정 구성

사용자가 채택한 기획 설정이다. 기존 문서의 밀서 관련 제안과 충돌하면 이 구성을 우선한다. 이번 변경은 기획 문서 반영이며 후속 조사 장면을 구현하지 않았다.

## 확정 흐름

1. 호적 대조로 신고 출신지의 ‘설평’이라는 신원이 확인되지 않는다는 사실을 얻는다. 실제 서리 근무 경력은 사실이며 호적 부재만으로 본명이나 범행을 확정하지 않는다.
2. 설평에게 귀속된 개인 서류에서 ‘목연’을 수신인으로 하는 밀서를 발견한다. 내용은 화공대비책 확보·전달 지시다. 밀서에 ‘설평의 본명은 목연’이라는 정답 설명을 적지 않는다.
3. 기록과 밀서를 제시하며 설평을 취조한다. 그가 밀서와 무관하다는 해명을 검토하고, 설평과 목연의 연결을 확인한다. 접선 장소를 실수로 말하게 하는 방식은 사용하지 않는다.
4. 주인공이 조조에게 최종 보고한다. 검증된 밀서를 신병 확보와 소지품 수색의 결정적 근거로 제출한다. 명령을 받았다는 사실과 절도를 실행했다는 사실은 구분한다.
5. 신병 확보 후 몸에 숨긴 화공대비책을 회수한다. 이 발견이 범행 실행을 최종 확인하며 진엔딩으로 이어진다. 이전 개인 서류 조사에서 화공대비책을 미리 발견하지 않는다.

## 단서의 역할과 기존 판정 유지

- 호적: 신고한 신원이 실제 인물의 기록으로 뒷받침되는지 확인한다. 누락·이름 표기·자료 범위를 검토한다.
- 밀서: 오나라의 절도·인계 지시와 목연이라는 수신인을 보여 준다. 발견 장소와 귀속, 취조 결과를 함께 검증한다.
- 화공대비책 회수: 실제 절도와 문서의 현재 행방을 최종 확인한다.
- 기존 진엔딩 조건인 설평 지목과 두 핵심 단서 확보를 유지한다. 밀서 핵심 단서 `clue_wu_secret_letter_true_name`은 내부 식별자를 유지하되, 후속 구현에서는 단순 발견이 아니라 설평에게 귀속되고 목연과 연결됨을 검증한 상태를 뜻하게 한다. 단순 발견과 검증 완료 상태를 구분한다.
- 취조를 별도의 숨겨진 엔딩 조건으로 추가하지 않는다. 밀서 단서 검증 과정으로 포함한다. 기존 런타임의 핵심 단서 획득 함수는 검증 완료 시에만 호출한다.

## 다음에 정할 세부 사항

- 설평과 목연을 연결하는 구체적 기록 또는 물증, 이를 제시하는 취조 대사.
- 설평의 개인 서류임을 확인하는 발견 경로와 밀서의 진위 확인 방식.
- 위험한 밀서를 보관한 이유. 전달 때 제시해야 할 증표를 겸한다는 방식은 유력 후보이며 아직 구체 형식은 미정이다.
- 밀서의 실제 지시 문구, 접선 시각과 전달 방식.

연결 근거가 부족한 상태에서 ‘부인할 수 없다’거나 강제로 자백하는 장면을 만들지 않는다. 아직 정하지 않은 부분은 후속 설계로 남긴다.
