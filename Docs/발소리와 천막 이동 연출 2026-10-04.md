# 발소리와 천막 이동 연출

실제 수평 이동 거리 1.2m마다 발소리를 재생한다. 문서고는 나무 바닥, 수군 진영은 흙 바닥 소리를 사용한다. 정지, 이동 차단, 공중 이동, 순간이동에는 발소리를 재생하지 않는다. 음원은 프로젝트에서 직접 합성한 원본이다.

문서고에서 수군 진영으로 이동하면 천막이 양옆으로 접히고 천 스침 소리와 시점 이동이 이어진다. 바깥 흙길과 등불을 지나 화면이 잠시 어두워진 뒤 수군 진영에 도착한다. 이동 중 입력을 차단하고 조작 안내와 조준점을 숨기며, 완료 또는 중단 시 복구한다. 저장 불러오기 등 위치 복원은 즉시 이동한다.

출구를 가리던 벽의 가운데를 개방하고 중앙 기둥을 옆으로 옮겼다. 기존 출구 조사 판정은 유지했다.

검증 결과: 이동 연출 플레이 검사 10개, 전체 회귀 검사 27개, 조사 판정 검사 22개 모두 통과. 검사 범위에서 새 오류 없음.

검사 기록: `Logs/MovementPresentation/result.txt`, `Logs/PlayRegression/result.txt`, `Logs/Editor.log`. 연출 화면: `Logs/MovementPresentation/curtain-opening.png`.

Windows 빌드 출력: `Builds/RedCliffsDeduction-0.1.0-demo.2-windows-x64/RedCliffsDeduction.exe`.

## 천막 연출 다듬기

천막 상단을 고정하고 아래 천이 접혀 밀려나는 형태로 변경했다. 양쪽 개방 시점에 차이를 주고 접힘에 작은 잔흔들림을 더했다. 전체 이동 시간을 1.75초에서 2.65초로 늘려 다가서기, 천막 열기, 몸을 낮춰 통과하기 순서를 구분했다. 시점 기울임과 암전도 부드럽게 연결했다. 중단 시 시점 회전까지 복구한다.

변경 후 이동 연출 플레이 검사 10개 통과. 상단이 고정된 천의 외곽 경계에는 빈 공간도 포함되므로 통로 검사는 실제 메시 삼각형 교차를 확인하도록 보완했다.

## 발소리 음색 다듬기

규칙적인 사인파 저음을 제거하고 발뒤꿈치와 발바닥의 두 짧은 접촉음을 합성했다. 나무 바닥은 낮은 접촉음, 흙 바닥은 짧은 마찰음에 중점을 두었다. 음원 길이를 0.27초에서 0.22초로 줄이고 종료 부분을 감쇠했다. 연속 동일 음원을 피하고 음높이와 강도를 작게 변화시킨다. 자기 발소리는 공간 감쇠를 줄이고 좌우를 아주 약하게 번갈아 배치한다. 거리 간격 1.2m는 유지하며 기본 재생 강도를 나무 .22→.16, 흙 .26→.18로 낮췄다. 사용자 효과음 설정도 계속 적용된다.

발소리 및 이동 연출 검사 10개 통과. 에디터 캡처 및 재로딩 지연을 고려해 검사 타임아웃을 20초로 늘렸다. 실제 연출 길이는 2.65초로 유지한다. 음색의 최종 선호도는 플레이 청취로 판단한다.
