## 실행에서 발견한 오류와 수정

최초 실행에서 `자동저장 실패: 보고 대상 기록이 손상되었습니다.`가 발생했다. Unity `JsonUtility`는 null인 중첩 직렬화 객체를 다시 읽으면 빈 인스턴스로 만들 수 있고, null 문자열도 빈 문자열로 돌아올 수 있다. 따라서 보고를 시작하지 않은 일반 조사 저장도 보고 상태 검증에서 거부됐다. 앞선 별도 .NET 검사는 Unity 직렬화를 실행하지 않았으므로 이 오류를 발견하지 못했다.

- 선택 없는 빈 보고 객체를 저장 데이터 검증 단계에서 ‘보고 없음’으로 정규화한다. 실제 보고 분기가 보고 상태 없이 저장된 경우는 계속 거부한다.
- 보고 대상의 null과 빈 문자열을 모두 ‘아직 선택하지 않음’으로 허용하고, 복원 시 null로 통일한다. 실제 인물 이름의 검증은 유지한다.
- `InvestigationSaveChecks`에 보고 없는 저장 및 대상 미선택 보고의 실제 Unity JSON 왕복 검사를 추가했다.
- `DemoReleaseBuilder.BuildChecked`를 추가하여 이 검사를 통과한 경우만 지정된 `-buildOutput` 경로로 빌드한다.

최초 수정 후의 검사에서 메모리상 JSON 복제 데이터도 빈 객체가 되는 것을 확인했으므로, 정규화는 파일 읽기만이 아닌 공통 데이터 검증에 적용했다. 그 후 실제 Unity 검사가 통과했다.
