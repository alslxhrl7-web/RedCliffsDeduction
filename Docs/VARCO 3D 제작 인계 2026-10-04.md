# VARCO 3D 인물 제작 인계

## 현재 요청

사용자가 VARCO 3D를 이용해 아직 정식 모델이 없는 조사 인물을 제작하도록 요청했다. 이 대화에서 사이트 접근이 막혀 실제 생성은 시작하지 못했다. 사용자는 오류 신고와 새 대화에서 작업을 이어가도록 명시적으로 요청했다.

작업 폴더는 반드시 `C:/Users/나민재/Documents/poject/RedCliffsDeduction`이다. `Documents/RedCliffsDeduction`과 혼동하지 않는다. 기존 변경과 사용자 저장을 보존하고 먼저 현재 파일을 확인한다. 이 인계 작성 시 HEAD는 `99166ea`이며 진단 문서만 미추적 상태였다. 새 대화에서는 상태를 다시 읽는다.

## 제작 대상

현재 `Assets/Art/Characters/Varco`에는 CaoCao(조조), Seolpyeong(설평), Duseok(두석), Caimao(채모), Zhangyun(장윤)의 FBX·프리팹이 있다.

`Assets/Editor/InvestigationRouteBuilder.cs`에서 생성하는 추가 인물에는 아직 별도의 VARCO 모델이 없다.

| 게임 인물 | 오브젝트 이름 | 제작 구분 방향 |
| --- | --- | --- |
| 기록 담당자 | RecordsClerk | 실용적인 관리 복장, 문서 업무 담당자 |
| 문서 전달 전령 | DocumentCourier | 가벼운 이동 복장, 문서 전달 역할 |
| 교대 병사 | ReliefGuard | 경비용 갑주·투구, 군영 수비 역할 |
| 휴식 중인 병사(동석 병사) | GamblingSoldier | 갑주를 간소화한 병사, 경비와 다른 외형 |

실제 장면의 남은 원형 모델과 조사 역할을 다시 확인하고, 기존 인물의 Reference.png와 모델을 보고 그림체·체형·재질·복장 수준을 맞춘다. 전쟁 직전 후한 말 군영이라는 기존 분위기를 따른다. 이 표의 의상은 제작 제안이며 기존 대사와 설정이 우선한다.

## 브라우저 접근

공식 작업 URL은 https://3d.varco.ai/explore 이다. 현재 사용자에게 내장 브라우저에 열려 있지만 새 대화의 탭 연결 상태는 새로 확인한다.

이전 대화의 실패 원인은 전역 허용과 별개로 남아 있는 **대화별 거부**였다. `Docs/VARCO 3D 브라우저 권한 진단 2026-10-04.md`를 읽는다. 새 대화에서는 정상 접근 절차로 권한을 확인하고 필요하면 사용자 승인 요청을 제시한다. 이전 대화의 권한 파일을 직접 고치거나 다른 브라우저로 우회하지 않는다. 새 대화에서도 거부되면 생성했다고 주장하지 말고 해당 오류를 기록한다.

현재 사이트의 로그인, 크레딧, 생성 비용·대기 상태는 미확인이다. 화면에서 확인하고 기존 크레딧으로 합리적인 범위의 모델 제작을 진행한다. 별도 결제·구독은 승인되지 않았다. 생성만 제출한 상태를 완성으로 표현하지 않는다. 결과의 외형·텍스처·내보내기 가능 여부를 확인한다.

## Unity 적용

장면은 `Assets/Scenes/Investigation.unity`, 모델 적용 도구는 `Assets/Editor/VarcoCharacterInstaller.cs`다. 현재 설치 도구의 대상 배열은 기존 다섯 인물만 포함하므로 새 모델을 적용할 때 확장해야 한다. 장면을 처음부터 재생성하지 말고 기존 인물 루트·대화 식별자·조사 판정과 위치를 보존하여 외형을 교체한다. Unity 장면·자산 수정은 제공된 Unity 도구와 관련 스킬에 따라 수행한다.

## 이전 작업과 제약

- 부분 기록으로 보고 가능, 최초 조사 비용 통일 및 중복 차감 방지, 조준·배치 보완, 날짜 일정 넘기기 구현됨.
- 날짜 전환은 배경음만 유지하면서 암전과 날짜 자막을 표시한다. 추가 종·북 효과음을 넣지 않는다.
- 채택 배경음은 VARCO Sound의 바람과 깃발 소리이며 천막 소리는 제외한 요청이다.
- 백그라운드 실행, 분기별 수동 저장/불러오기, 조사·분기 변경 자동저장 구현됨.
- 진엔딩 11회 경로와 선택 조사 포함 12회 경로를 실제 Unity 회귀 검사로 확인했으며 27개 항목 통과 기록이 있다. 최신 기록은 `Docs/플레이 회귀 검증 2026-10-04.md`와 `Logs/PlayRegression/result.txt`를 읽는다. 사람이 직접 한 모든 키 입력·청음·장시간 실행까지 확인한 것은 아니다.
- 셰이더 캐시 복구와 Windows 빌드 성공 기록은 `Docs/셰이더 경고 점검 2026-10-04.md` 참고. 이전 미검증 문구만 읽고 최신 검증이 없다고 결론 내리지 않는다.
- 진엔딩 외 후일담 콘텐츠는 사용자 요청대로 추가하지 않는다.
- 이전 사용자 요청으로 Play·빌드 검증은 허용됐지만 이번 인물 작업에 필요 없는 반복 빌드는 피한다. 사용자의 최신 제약이 있으면 우선한다.
- GitHub 및 itch.io에 새 커밋·업로드를 이번 작업만으로 자동 실행하지 않는다.
