# 최종 보고 구성 — 확정

확정일: 2026-09-29

사용자가 채택한 최종 보고의 기획 설정이다. 2026-09-29에 아래 보고 UI와 흐름을 구현했다. 기존 사건 정답지의 핵심 단서와 엔딩 판정 설정은 유지하며, 후속 수사와 엔딩 실행은 아직 구현하지 않았다.

## 구현 범위와 직접 확인 순서

1. 채모·장윤의 설명을 듣고 ‘추가 조사하지 않고 넘어간다’를 선택한다. 수첩의 ‘다음 조사 선택’에서도 접근할 수 있다.
2. 조사 정리에서 ‘조조에게 최종 보고’를 선택하면 기존 지휘 천막으로 이동한다.
3. 지목·의심·미해결 중 결과를 고른다. 지목과 의심은 네 인물을 같은 조건으로 제시한다.
4. 실제 확보한 기록을 한 장씩 넘기며 제출하거나 제출 목록에서 뺀다. 제출하면 해당 근거에 대한 조조의 답변이 표시된다.
5. 후속 조치 요청을 고르고 최종 확인 화면에서 결론·근거·요청을 검토한다. 수정하거나 보고를 보류할 수 있다.
6. 보고 완료 전 Esc 또는 추가 조사 선택은 원래 조사 장소로 복귀하며 조사 기록을 보존한다. 다시 보고하면 제출 초안은 새로 작성한다.
7. ‘이 내용으로 최종 보고 완료’에서만 보고가 확정된다. 완료 화면에서 제출한 보고서를 다시 볼 수 있다. 완료 후 해당 실행의 조사는 종료되며 보고 취소는 불가능하다.

현재 확보 가능한 기록은 문서 부재, 네 인물의 진술, 정비 명령서, 추가 진술 및 발견한 모순이다. 결정적 증거 획득은 미구현이므로 신병 확보 요청은 ‘근거 부족’으로 비활성화한다. 다른 조사 요청은 보고서에 기록만 하며 실제 후속 수사나 자동 엔딩으로 연결하지 않는다. 보고서는 현재 플레이 세션에 보관되며 저장·불러오기는 추가하지 않았다.

검증: Unity가 사용한 참조와 컴파일 설정으로 런타임 스크립트 컴파일을 확인했다. Play 모드 테스트는 사용자가 직접 진행한다.

## 진입과 확정 시점

채모·장윤의 설명을 들은 뒤 플레이어가 추가 조사 대상을 선택하거나 추가 조사 없이 넘어갈 수 있다. 넘어가기는 보고 준비로 이어지며, 그 선택만으로 배드 엔딩을 확정하지 않는다.

보고 준비에서는 확보한 근거와 미확인 항목을 검토하고 추가 조사로 돌아갈 수 있다. 최종 보고는 조조의 지휘 천막에서 진행하며, 보고를 마치는 순간 결말을 확정한다.

## 1. 조사 결과 제시

조조: “문서는 찾았느냐. 누가 가져갔는지 밝혔느냐?”

- 특정 인물을 지목한다.
- 의심되는 인물은 있지만 확정하지 못했다.
- 범인을 밝히지 못했다.

지목 대상은 설평·두석·채모·장윤을 같은 조건으로 제시한다. 선택지의 강조나 안내로 설평을 정답처럼 미리 드러내지 않는다.

## 2. 근거 설명

조조가 지목 또는 의심의 근거를 묻는다. 플레이어는 실제 조사로 확보한 수첩 기록만 제출할 수 있다.

| 제출 근거 | 반응 방향 |
|---|---|
| 문서고 서기라는 직책과 접근 권한 | 접근 가능성만으로 범행을 입증하지 못함을 짚는다. |
| 두석의 경비 공백 | 범행 기회와 실제 행동자를 구분한다. |
| 훈련 진술과 명령서 사이의 모순 | 경력을 재확인할 이유로 인정한다. 절도 확정으로 처리하지 않는다. |
| 확보한 핵심 단서 | 신원과 사건의 연결을 검토한다. |

현장 목격에 관한 거짓 진술, 가명 신원, 절도의 입증을 구분한다. 설평은 가명으로 실제 서리 업무를 수행했으므로 근무 경력 자체를 거짓이라고 단정하지 않는다. 근거에 따라 조조의 반응을 바꾸되, 미확보 증거를 대사나 선택지로 공개하지 않는다.

## 3. 후속 조치 요청

- 해당 인물의 신원과 경력 기록을 확인한다.
- 문서 반출 경로와 전달자를 조사한다.
- 충분한 근거가 있으면 신병 확보와 소지품 확인을 요청한다.
- 현재 결과로 보고를 마친다.

조사 요청과 최종 보고 완료를 구분한다. 요청별 해금 조건과 시간 소모는 후속 구현에서 정한다. 새로운 선택지를 누르지 않았다는 이유만으로 기존 진엔딩 조건을 몰래 추가하지 않는다.

## 엔딩 연결

| 기존 최종 판정 | 결과와 문서 행방 |
|---|---|
| 설평 지목 + 호적 기록 부재 + 본명 밀서 확보 | 진엔딩. 제출 근거에 따라 전달 전에 신병을 확보하고 몸에 숨긴 문서를 회수한다. |
| 설평 지목 + 핵심 단서 부족 | 노멀 엔딩. 범행 관련 입증이 충분하지 않으며 문서 행방은 알 수 없다. |
| 다른 인물을 최종 지목 | 대상별 배드 엔딩. 문서는 이미 오나라에 전달된 상태다. |
| 기한 초과·미해결 | 배드 엔딩 방향. 구체적 처리와 엔딩 ID는 미정이다. |

핵심 단서는 기존 `clue_household_registry_no_record`, `clue_wu_secret_letter_true_name`을 유지한다. 진술 모순만으로 진엔딩이 되지 않으며, 모순을 놓치거나 추가 조사를 건너뛰었다는 사실만으로 즉시 실패시키지 않는다. 배드 엔딩에서 설평이 진범이라는 사실을 명시적으로 공개하지 않는 기존 원칙도 유지한다.

## 미확정 세부 사항

- ‘의심하지만 확정하지 못함’과 ‘밝히지 못함’으로 보고를 마쳤을 때의 세부 판정 및 기한 처리.
- 조조의 최종 대사, 요청별 해금 조건, 조사 시간 규칙.
- 이전 대화에서 제안한 실제 서리 명부 불일치와 설평의 문서고 출입 목격담은 채택하지 않은 후보다. 기존 호적·밀서 단서를 대체하거나 새 필수 조건으로 추가하지 않는다.
