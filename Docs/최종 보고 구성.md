## 보고 내용

한 사람을 고르는 것으로 끝내지 않는다. 각 항목에 주장·근거·인과관계를 작성하고 제출 전 수정할 수 있다.

1. 접근과 이동: 누가 접근했고 누가 문서를 옮기거나 숨겼는가?
2. 거짓말과 이유: 사건의 주요 모순을 누가 어떤 사정으로 만들었는가?
3. 기록 조작: 과거 군적 정정, 당직 시각 허위, 사건 밤 인계 조작을 구분했는가?
4. 군령 조작: 누가 어떤 내용을 바꿨으며 이를 뒷받침하는 자료가 있는가?
5. 진짜 군령: 독립된 부본의 출처를 검증하고 원래 명령을 복원했는가?
6. 목적과 결과: 병력 이동이 감시·확인·화공 대응을 어떻게 무너뜨리는가?
7. 실행 조치: 조작본과 재발행을 중지하고 진본에 따른 배치를 요청했는가?

인물별 책임을 구분하며, 불법 정정이나 도박을 군령 조작 자백으로 취급하지 않는다. 개인 비밀 수집률은 판정에 사용하지 않는다. 다만 최종 인과관계에 필요한 거짓말의 이유와 반증은 해명해야 한다.

## 판정 의미

최신 승인 반영: 설평의 과거 소속과 장윤의 보호 사정은 선택 조사다. 아래 역할복원·모순해결은 이 선택 조사의 완료를 요구하지 않는다. 본 사건의 시점·행동은 별도 자료로 입증할 수 있어야 한다. 상세 기준은 [단계별 조사 구성과 확정 기록](단계별%20조사%20구성과%20확정%20기록.md)을 따른다.

- `역할복원`: 접근·은닉·과거 정정·당직 공백·군령 조작의 행위자를 구분.
- `모순해결`: 핵심 시간·신분·인계 모순을 근거와 함께 해소하고 비공모자의 행위를 구분.
- `진본복원`: 출처를 검증한 부본과 독립 기록으로 원명령 복원.
- `목적연결`: 변경된 명령 → 배치 공백 → 전투 피해를 설명.
- `저지조치`: 기한 내 재발행까지 중단하고 올바른 배치를 요청.

TRUE는 이 다섯 판단이 모두 타당할 때 성립한다. 항목은 인과관계 검증이며 증거 개수나 대화 완료 수가 아니다. 동등한 근거 조합을 허용한다. 자료 보유만으로 올바른 답을 자동 선택하지 않는다.

NORMAL은 실제 군령 조작자 또는 조작 사실을 타당하게 밝혔지만 전체 복원·저지에 이르지 못한 경우다. BAD는 무고한 이를 조작자로 확정하거나 기한까지 유효한 조작 규명 없이 끝낸 경우다. 오지목을 포함한 보고는 다른 항목 일부가 맞아도 TRUE가 될 수 없다.

기한 전 보류·미해결은 조사로 복귀한다. 최종 확정 전 결론과 후속 조치를 다시 보여 준다. 기한과 비용의 새 수치는 조사 구조 문서의 재설계 대상으로 남긴다.

## 필수 검증 시나리오 — 구현 후 수행

- 한진 이름만 맞힘: TRUE 불가.
- 모든 단서 보유 + 잘못된 인과관계: TRUE 불가.
- 전달자의 은닉만 밝혀 조작자로 오지목: BAD.
- 군령 변경 입증 + 진본 미복원: NORMAL.
- 진본 복원 + 재발행 방치: TRUE 불가.
- 핵심 관계 모두 복원 + 저지, 무관한 선택 비밀 미수집: TRUE 가능.
- 같은 결론을 독립된 대체 근거로 입증: 동일 판정.
