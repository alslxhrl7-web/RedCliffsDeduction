# 적벽추리 패치노트

주요 업데이트는 앞으로 이 문서에 최신 버전부터 기록한다. 날짜, 개선·추가·수정, 검증, 알려진 미완료 사항을 구분한다. 실제 반영한 내용만 완료로 쓰고, 빌드와 GitHub 업로드 상태는 별도로 표시한다.

## 0.1.0-demo.7 — 2026-10-09

### 변경

- 군령 조사에서 중간 보고와 후속 보고 단계를 제거했습니다. 조조의 허가나 중간 보고 없이 후속 자료를 조사할 수 있습니다.
- 조조에게 **결론 → 제출할 근거 → 시행 조치**를 선택해 한 번의 최종 보고를 합니다. 확정 전에는 선택을 수정하거나 기한 내 추가 조사로 돌아갈 수 있습니다.
- 수집한 자료가 아니라 **실제로 제출한 근거의 내용**으로 엔딩을 판정합니다. 확보하지 않은 근거는 선택할 수 없습니다.
- 보고를 확정하면 조조의 명령과 현장 결과를 거쳐 BAD / NORMAL / TRUE 엔딩으로 이어집니다.

### 엔딩 기준

- **BAD:** 다른 인물을 조작자로 오지목, 한진의 제출·고의를 입증하지 못한 지목, 또는 유효한 변경 근거 없는 보고.
- **NORMAL:** 변경 사실이나 제출·고의를 입증했지만 책임 구분·원래 지시·배치 영향·저지 조치를 모두 완성하지 못한 보고.
- **TRUE:** 한진 지목과 함께 불일치, 원래 승인 내용, 제출 기록, 거절 수령 순서, 감시 공백, 전달자 은닉 경위를 제출하고 제17호·대체 재발행 중지 및 강 입구 배치 복원을 요청한 보고.

### 저장 및 수정

- 보고 초안의 결론·제출 근거·조치를 저장하고 불러올 수 있습니다.
- 최종 확정 직전 자동저장을 남겨 엔딩에서 보고 직전 기록을 불러올 수 있습니다.
- 수동 저장을 불러온 직후 보고를 확정할 때 자동저장이 갱신되지 않던 문제를 수정했습니다.
- 기존 중간 보고 완료 저장은 계속 읽지만, 과거의 보류·배치 요청 기록을 새 엔딩 점수로 사용하지 않습니다.

### 검증 및 배포

- 진행·저장·엔딩 검사 51개 통과. 결론 7종 × 근거 조합 64종 × 조치 4종의 1,792개 조합과 실제 엔딩 화면·보고 초안 복원을 검증했습니다.
- 엔딩 확정 후 사용할 수 없는 편집 단축키 안내를 제거했습니다. Windows demo.7 빌드 완료: `Builds/RedCliffsDeduction-0.1.0-demo.7-windows-x64/RedCliffsDeduction.exe`. GitHub 업로드 전입니다.
- 현재 엔딩은 제17호 사건의 해결과 감시 배치 결과를 다룹니다. 전체 적벽 전투의 승패를 판정하는 추가 군령·전투 연출은 포함하지 않습니다.

## 0.1.0-demo.6 — 2026-10-09

### 개선

- 인물 답변을 읽은 뒤 ‘돌아가기’를 반복해서 누르지 않고 다음 질문이나 대화 종료를 선택할 수 있습니다.
- 문서 묶음을 열면 핵심 내용과 출처가 함께 표시되고 수첩에 자동으로 기록됩니다. 긴 원문은 원할 때 펼쳐 읽을 수 있습니다.
- 후속 추리를 **변경 시점 → 제출자 → 거절을 알고도 제출했는지**의 세 질문으로 연결했습니다. 확보한 증거를 같은 화면에서 비교합니다.
- 한진은 작업과 제출 해명, 기록 담당자는 반납과 직접 회신 전달을 담당합니다. 각 인물의 대화는 핵심 질문 두 개 이내로 구성했습니다.
- 부본·승인 기록·회신철은 수군 진영의 기록 탁자에서 조사합니다. 인물에게 문서와 추리 메뉴가 한꺼번에 몰리던 구성을 분리했습니다.
- 문서고에서 반환 묶음을 미리 확인하도록 안내하고, 수첩에서 확보한 자료를 다시 비교할 수 있게 해 불필요한 왕복을 줄였습니다.
- 완료한 배치 요청과 후속 보고는 반복 선택지에서 제외하고 결과를 표시합니다.

### 유지

- 문서 열람만으로 범인이나 고의가 자동 확정되지 않습니다.
- 기존 저장 진척, 증언을 활용하는 대체 경로, 주 경로 조사 비용 8회와 전체 한도 12회를 유지합니다.

### 검증 및 배포

- 진행·저장·역할 분산·핵심 화면 크기 검사 42개 통과. 문서 탁자의 실제 시선 상호작용과 스크롤 없는 핵심 비교·수첩 화면 확인.
- Windows demo.6 빌드 완료: `Builds/RedCliffsDeduction-0.1.0-demo.6-windows-x64/RedCliffsDeduction.exe`. GitHub 업로드 전입니다.

### 남은 항목

- 초행 플레이어 기준의 피로도와 추론 난이도 확인.
- 한진 전용 외형, 실제 배치 이행 회신과 이후 결말.
- 기존 Unity API·편집기 패키지 경고는 별도 정리 대상입니다.
