# 인물 작업 대기 모션

2026-10-13. 대기 중 단순히 몸을 흔드는 대신 팔을 굽힌 작업 자세와 시선 변화를 사용한다. 원본 인물은 관절 리그가 없는 단일 메시이므로 Blender의 셰이프 키와 버텍스 그룹으로 편집한다. 완전한 손가락 연기나 물건을 집어 드는 애니메이션은 아니다.

| 인물 | 대기 행동 |

| 조조 | 허리 앞에서 손을 모아 자세를 정리하고 고개를 움직임 |

## 편집 원본과 출력

- 원본: `ArtSource/RoleActivities20261013/RoleActivities.blend`. 인물별 `Original_Game_Mesh`, `WorkRest`, `ActivityA`, `ActivityB` 셰이프 키와 팔·목 버텍스 그룹을 보존한다. 원래 UV와 정점 순서는 바꾸지 않는다.
- 재현 도구: 같은 폴더의 `build_activities.py`. 새 모델을 다운로드하거나 외부 라이선스 자산을 추가하지 않았다. 현재 프로젝트의 모델과 텍스처를 사용했다.
- 보고서: `bake-report.json`. 인물별 정점 수, 변경 정점 수, 동작 길이, 발 고정 여부를 기록한다.
- Unity 출력: `Assets/Art/Characters/RoleActivities/`. 10개 모션 바이너리, 서류 소품 3개 메시, 공통 재질과 베이킹 색상 맵. 씬의 각 `VarcoIdleMotion.RoleActivity`와 `HeldRecord`에 연결한다.
- `Input`, `Output`, `Preview`는 재생성 가능한 전송·검토 파일이라 Git에서 제외한다. 최종 `.blend`, 제작 스크립트, 보고서와 Unity 출력은 보존한다. `.blend1` 자동 백업도 제외한다.

## 베이킹과 재생

Blender Action을 초당 20회로 샘플링해 10~13.85초의 반복 동작을 굽는다. 기본 작업 자세 및 두 동작 자세의 위치 차이와 표면 노멀을 저장한다. 인물마다 재생 시작 시점을 달리한다. 원래 얼굴·의복의 색상과 UV를 변경하지 않아 기존 표면 텍스처를 재사용하며 고정 조명을 색상에 굽지 않는다.

새 서류 소품은 Cycles에서 색상만 512×512로 베이킹했다. 평평한 종이이므로 별도 노멀·AO·금속 맵은 생략하고 금속 0, 매끄러움 0.05를 사용한다. 손과 소품은 같은 베이킹 곡선으로 움직인다. 이 소품은 장식이며 새로운 단서나 조사 횟수를 추가하지 않는다.

재생은 기존 거리·시야 최적화를 유지한다. 대화 중에도 기본 작업 자세를 유지하고 큰 작업 동작을 줄인다. 원래 메시를 직접 수정하지 않고 실행 중 복사본에만 적용한다. 발, 인물 루트, 충돌체, 조사 대상 위치는 변경하지 않는다.

## 다시 제작하는 순서

1. 저장된 Investigation 씬을 Play 밖에서 열고 `Tools/Character Motion/Export Activity Sources`를 실행한다.
2. 프로젝트 루트에서 Blender로 `ArtSource/RoleActivities20261013/build_activities.py`를 실행한다. 원본이 이미 있으면 중단한다. 수작업 원본을 별도로 보존한 뒤 생성본을 교체할 때만 `--replace-generated`를 추가한다.
3. Blender에서 전체 자세와 손·옷자락을 확인한다. 각 인물 셰이프 키를 수정하면 현재 스크립트 재실행은 수작업을 반영하지 않으므로 수정 내용을 생성 로직에도 반영하거나 별도 내보내기 절차를 사용한다.
4. `Tools/Character Motion/Apply Baked Activities`로 적용한다. 같은 이름의 자산과 HeldRecord를 재사용해 중복 생성을 막는다.
5. `Validate Baked Activities`로 10명 연결, 노멀 방향, 곡선, 소품 3개를 검사한다. 격리 Play에서 `Run Live Idle Checks`를 실행하면 인물당 14초간 실제 LateUpdate를 관측한다. 이후 이동·대화·저장 회귀 검사도 실행한다.

씬 적용 전 사본은 프로젝트 밖 `local-backups/BeforeRoleActivities-20261013`에 있다. 커밋과 업로드 여부는 별도로 기록한다.

## 검증 결과

2026-10-13 기준 연결·노멀·곡선 검사 10명과 소품 3개 통과. 실제 Play 프레임에서 인물당 14초 관측해 최대 동작 변위 39.6~71.3mm, 발 이동 0mm를 확인했다. 진행·저장 회귀 검사 59개와 화자 전환·대화 종료 검사도 통과했다. 두석은 최초 촬영에 인물이 잡히지 않아 앞쪽 1.6m 위치에서 다시 촬영해 확인했다. 키보드 수동 플레이와 새 실행 파일 검사는 아니다.
