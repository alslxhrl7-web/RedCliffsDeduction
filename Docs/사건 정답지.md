# 적벽추리 — 사건 정답지

기준일: 2026-10-08. 리디자인의 제작용 진실이며 스포일러를 포함한다. 현재 Unity 새 게임에는 문서 회수·내용 대조·중간 보고까지 반영했다. 이 문서 전체, 특히 교체 수법·원본 행방·범인 확정·새 엔딩이 구현된 것은 아니다. [구현 기록](군령%20조사%20구현%20기록%202026-10-08.md)을 기준으로 한다. 기존 배포 빌드는 갱신하지 않았다.

## 방향과 설정의 지위

사라진 군령을 출발점으로 사람들의 거짓말을 해체하고 사건의 인과관계를 복원한다. 진엔딩은 범인 지목이나 증거 수가 아니라 진짜 군령과 조작의 목적·결과까지 밝혀 잘못된 명령을 막는 데서 발생한다.

[피드백 원문](리디자인%20피드백%20원문%202026-10-08.md)의 핵심 방향을 반영했다. 아래 실명 배역, 시각, 군령 문구와 증거 배치는 원문에 없던 공백을 메운 **신규 집필안 v1**이다. 사용자가 지정한 확정 사실이나 실제 역사로 취급하지 않는다. 이전 설평=목연=오나라 첩자 설정은 새 기획에서 승계하지 않는다.

## 실제로 벌어진 일

최신 승인 사항은 [단계별 조사 구성과 확정 기록](단계별%20조사%20구성과%20확정%20기록.md)을 따른다. 설평의 과거 소속과 장윤의 보호 사정은 선택 조사다. 아래 세부 시간과 제2·3단계 내용은 계속 집필안이며, 안내인 누명은 삭제했다.

조조군 문서고에서 반출된 중요 군령이 수령 부대에 도착하지 않는다. 군령 내용은 그 전에 변경되었다는 집필안이다. 전달자는 필요한 대조를 하지 않고 정상 확인을 남겼고, 뒤늦게 내용 차이를 발견한다. 자신의 거짓 정상 확인이 드러날까 두려워 잠시 전달을 보류하고 조용히 확인하려다가, 미수령 조사가 시작되자 이미 넘겼다고 거짓말하고 문서를 숨긴다. 이 동기와 행동 순서는 승인되었다. 비교 자료의 보관자·접근 절차·구체 물증은 미정이다. 조사자는 문서의 이동과 내용 조작을 따로 밝혀야 한다.

새 배역인 군령 연락관 **한진(가칭·창작 인물)**은 적측과 내통하며 잘못된 명령을 정식 명령처럼 통과시키려 한다는 집필안이다. 안내인에게 책임을 넘기는 설정은 삭제한다. 한진은 초반부터 명령 인계 절차를 설명하는 인물로 등장하며 마지막에 갑자기 추가되는 범인이 아니다.

## 역할 분리

전달자의 확인 생략 사유는 확정되었다. 비슷한 군령을 반복 취급하면서 이번에도 본문이 같다고 생각해 발급 번호·수령 부대만 확인하고 내용 대조를 생략했다. 이는 개인의 안일함이며 조직 전체의 관행이나 과거에도 군령이 조작되었다는 뜻은 아니다. 이번에 뒤늦게 차이를 발견한 구체 계기는 아직 미정이다. ‘분실 이후 중요성 인지’는 검토 중이며 확정된 은닉 원인으로 사용하지 않는다.

| 행위 | 인물 | 책임과 범위 |
|---|---|---|
| 조작 계획·실제 군령 변경 | 한진 | 교체본 작성과 유통 시도라는 집필안. 구체 입증 자료는 3단계에서 설계 |
| 거짓 정상 확인·전달 보류·은닉 | 문서 전달자 | 대조를 생략한 사실을 감추려다 보류·거짓 인계 주장·은닉으로 책임을 키움. 군령 조작과 구분 |
| 과거 군적 수정 | 장윤 | 설평의 과거 소속을 감추는 불법 정정. 이번 군령 변경과 구분 |
| 미등록 인물 입영 | 채모 | 비공식 수로 정찰을 위한 안내인 초청. 내통과 구분 |
| 입영 목격 은폐 | 두석 | 채무 관계인 안내인의 입영을 숨김. 군령 조작 가담 아님 |
| 경비 공백·시각 허위 기재 | 교대 경비 | 도박 채무 정산을 위해 이탈. 군령 조작 가담 아님 |
| 목격 은폐 | 도박 병사 | 경비와 금전 거래를 숨김. 중요 목격자 |
| 사건 전날 무단 열람 | 설평 | 편입 부속 서류에서 과거 소속 노출을 우려. 군령 변경 아님 |

한진 외 인물들의 위반은 별도로 판단한다. 모든 비밀을 공모 증거로 합치지 않는다. 두석과 교대 경비는 별개 인물로 재구성한다.

## 실제 시간순서 — 창작 일정

조사는 열이튿날 아침 시작한다. 아래는 열하룻날 밤이며, 실제 역사 날짜가 아니다.

|---|---|---|
| 수개월 전 | 장윤이 설평의 과거 소속을 군적에서 삭제 | 이전 지급 명부와 현 군적의 불일치, 정정 서명 |
| 전날 | 설평이 편입 서류를 무단 열람 | 열람 묶음 순서와 당직자의 목격 |

| 20:30 | 채모가 수로 안내인을 비공식 입영시킴 | 임시 목패, 수로 스케치, 채모의 지시 흔적 |

| 22:00 | 두석이 안내인을 찾아 기록관 주변에 옴. 한진은 연락관 권한으로 안에 들어감 | 두석의 동선 목격, 연락관 인계 흔적 |

| 다음날 | 한진이 분실을 이유로 조작 문구의 재발행을 요청 | 재발행 초안. 은닉 문서를 찾아도 위험이 끝나지 않는 이유 |

## 인물별 진실·거짓말·반증

| 인물 | 최초 주장 / 거짓말의 이유 | 검증과 방어 근거 |
|---|---|---|
| 두석 | 22시 기록관 부근에 없었다 / 채무와 안내인 보호 | 목격·채무 쪽지로 재질문. 바깥에서 만난 행적은 내부 문서 교체를 입증하지 않음 |
| 설평 | 편입 서류를 다시 본 적 없다. 과거 출항 훈련을 직접 기록했다 / 이전 소속 은폐 | 정비 닷새의 출항 중단과 대조. 실제 서리 경력은 유지. 사건 밤 군량 창고 인수 서명과 독립 목격으로 범행 시간 분리 |
| 장윤 | 군적은 원기록 그대로다 / 불법 정정과 설평 보호 | 옛 지급 명부·정정 필획으로 반박. 종이 묶음과 정정 날짜가 이번 군령 사건 이전임을 확인 |
| 채모 | 미등록 출입자는 없었다 / 비공식 정찰 책임 회피 | 임시 목패·수로 스케치 대조. 안내인은 존재하나 정식 군령 인수 권한이 없음 |
| 교대 경비 | 자리를 지켰다 / 도박·근무 태만 은폐 | 교대 신호, 정산 장부, 병사 증언으로 공백 복원 |
| 도박 병사 | 아무것도 못 봤다 / 금전 거래 은폐 | 경비의 재진술을 대조하면 연락관의 방향과 운반 묶음을 진술. 얼굴 목격만으로 문구 변경을 입증하지 않음 |
| 전달자 | 수령 부대가 보낸 병사에게 넘겼다 / 대조 없이 정상 확인을 남긴 사실이 드러날까 두려움 | 미수령 확인·물품 기록으로 은닉 위치 추적. 정상 확인과 실제 비교 시점을 검증할 증거를 설계한다. 문구 차이는 보류 동기를 뒷받침하나 은닉을 정당화하거나 조작 책임을 입증하지 않음 |
| 한진 | 최초 주장과 조작 책임 입증은 3단계에서 상세화 | 안내인 누명·목패 시각 모순은 사용하지 않는다. 작성 흔적과 재발행 문구의 동일성만으로 고의 조작을 확정하지 않는다 |

증언 하나나 신원 기록 부재만으로 범행을 확정하지 않는다. 한진의 동기는 수령자 표시가 있는 연락 쪽지와 작전 효과를 함께 검증해 판단한다. 쪽지 하나에 전모나 정답을 적어 두지 않는다.

## 진짜 군령과 조작의 효과

- 진짜 군령: 전초 감시선을 강 입구에 유지한다. 접근 선단은 확인 전 통과시키지 않는다. 예비 소화대를 수채 외곽에 대기시킨다.
- 조작 군령: 전초 감시선을 본진으로 철수시킨다. 접근 선단의 확인을 생략한다. 예비 소화대를 내륙 군량고로 이동시킨다.
- 복원 근거: 독립 보관된 봉인 부본의 발급 번호·봉인·인계 이력, 사전 배치도, 수령 부대의 준비 기록을 서로 대조한다. 오래된 문서라는 이유만으로 진본 취급하지 않는다.
- 조작의 목적: 경고·확인·초기 대응을 동시에 무력화한다. 지도와 병력 이동 시간으로 전투상 결과를 추론한다.
- 후반 공개: 최종 배치도와 작전 명칭을 대조할 때 이 군령이 적벽에서 사용될 명령임이 드러난다. 초반 사건명은 ‘군령 분실 사건’이다.

진엔딩은 조조군 관점의 창작 대체역사다. 올바른 군령 집행으로 화공 접근을 조기에 차단하고 해당 적벽 전투의 승패가 바뀐다. 천하 통일까지 자동으로 이어지는 결말은 쓰지 않는다.
