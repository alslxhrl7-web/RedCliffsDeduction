# 지휘 천막 왕복 이동

2026-09-30 적용.

수군 진영 입구의 나무 표지를 E로 조사하거나 Esc → 장소 이동에서 ‘조조군 지휘 천막으로 이동’을 선택한다. 문서고 이동 메뉴에서도 접근 가능하다. 조사 완료 여부와 무관하게 방문할 수 있다.

기존 지휘 천막과 조조가 있는 도입 위치로 이동하며, 조조 대화 메뉴에서 보고 또는 수군 진영·문서고 복귀를 선택한다. 보고는 채모·장윤 설명 확보 또는 기한 종료 후 가능하다. 호적 대조와 모순 확인 후 기한 전에는 개인 서류 조사 허가 요청도 가능하다.

방문 화면에서 Esc는 방문 전 조사 장소로 복귀한다. 기한 전 보고 취소는 이전 조사 장소로 돌아간다. 0회 상태에서 보고에 들어가면 현장 복귀는 잠긴다. 장소 표시와 천막 활성 상태를 함께 정리하며, 이름·증거·시간은 이동 때문에 초기화하거나 추가 차감하지 않는다.

기존 씬 참조를 사용하며 새로운 씬 파일은 만들지 않았다. 허가 수령·보고·장소 복귀는 실제 Play 모드에서 확인했다.
