## 두석

- `Duseok/Duseok_Parts_Workbench.blend`: 원본, 편집 조립, 게임용 베이크 후보를 컬렉션으로 분리했다. 얼굴·갑옷·손을 VARCO에서 각각 생성하고 원본과 참조 이미지를 보존한다.
- 설치된 URPLab Auto Retopology로 얼굴 사각형 메시를 생성했다. 첫 결과는 4,090 quads / 8,963 triangles, 원본 대비 bounds 차이 약 0.28%였다. 이것은 자동 생성 통계이며 외형·애니메이션 품질 통과를 뜻하지 않는다.
- 목 경계는 열린 연결부다. 내부 비정상 연결 0과 경계 개수를 구분했다. 이후 목 변형에서 면 뒤집힘이 생겨 목 아래를 연속된 링으로 재구축했다.
- UV의 첫 전개는 겹침 896쌍으로 기각했다. URPLab 안전 전개로 겹침을 없앴으나 섬이 과도하게 분리되어 근접 셰이딩 품질이 부족했다. 리토폴로지 후보는 검토용으로 보존하고 얼굴 원본 밀도를 유지한 별도 베이크 후보를 제작한다.
- 베이크: 기존 보이는 Blender의 Cycles, 2K, 16px margin, Base Color는 조명 없는 COLOR pass, tangent Normal, Roughness. 피부 Metallic은 0 상수로 생략하며 움직이는 피부에 고정 AO를 합성하지 않는다. 최초 실패와 수정은 [베이킹 문제](베이킹%20문제.md)에 구분한다.
- 갑옷은 6만 삼각형 PBR 원본을 별도 피팅했다. 옛 어깨끈과의 중복, 접촉·후면 검토가 남았다. 생성된 손은 중복 손톱 표현이 발견되어 그대로 완성 처리하지 않는다.
- 미완료: 얼굴 최종 근접 검토, 갑옷·손·헤어 세부 조형, 전 파츠 베이크, Unity 연결, 실제 게임 검증. AA 품질을 통과했다고 판정하지 않았다.

## 대기 인물

- VARCO 3D 2.0: Private, 60,000 triangles, 2K PBR. 수신 원본은 각 인물 폴더의 `*_Varco_Original.glb`에 보존한다.
- Blender 작업 도구: 기존 `LocalArchive/CaoCaoHairEnemies20261016/Revision2` 브릿지 폴더의 `seol_*`, `duseok_*`, `import_seol_head.py`, `fit_seol_head.py`, `import_duseok_head.py`와 요청별 `*-result.json`. 활성 브릿지의 현재 프로젝트·파일·heartbeat를 확인한 뒤 필요한 개별 작업만 실행한다. 기존 파일을 무단 재생성하지 않는다.
- 본 작업은 아직 `Assets`에 출력하거나 Unity 씬에 적용하지 않았다. 컴파일·Play·동선·상호작용 검사, 커밋·업로드·배포를 수행한 것으로 기록하지 않는다.

- 기존 Blender 작업 창과 실행 중 브릿지를 재사용했다. 현재 원본은 LocalArchive/CharacterParts20261018/Duseok/Duseok_Parts_Workbench.blend. 원본·기각 후보는 보존했다.
- 수정 투구는 VARCO 브릿지 직접 내보내기로 받은 4418dc9b-8d0e-49f2-88ef-085700608d8b이며 BridgeReceived/HelmetLamellar에 보관한다. 이전 대판 투구는 보관용이다. 역사적 근거와 복원 추정 범위는 인물 고증 검토 문서를 따른다.
- 투구 후보: Cycles 16 samples, 2K 원본 맵, margin 16px, cage 0.004m, ray 0.014m. 조명 없는 BaseColor, tangent Normal, AO·Roughness·Metallic을 생성했다. 게임 후보는 BaseColor 1K / Normal 2K / ORM 1K(R AO, G Roughness, B Metallic), 30,000 triangles. 출력은 Duseok/GameCandidate/HelmetLamellar이며 원본 베이크는 Baked/HelmetLamellar에 별도 보존한다.

- 목에 UV 전이된 ORM의 금속성·거칠기 영향이 남아 각진 얼룩이 보였다. 피부 Metallic 0과 연속된 목 Roughness 마스크로 보정했다. 정면 검토에서 얼룩 감소를 확인했다. 얼굴·목의 세부 피부 품질과 최종 베이킹은 미완료다.
- 검토: 수정 전 투구 측면·후면 2장, 목/깃 수정 정면·후면 2장, 뒤 의복 후보 및 접합 재수정 각 1장, 총 6장. 뒤 의복 후보는 피부 교차와 판 같은 실루엣 때문에 기각했다. 후보는 숨겨 보존하고 기존 깃으로 복원했다. 새 후보를 완성으로 판정하지 않았다.
- 남은 문제: 뒷깃 재단, 어깨 갑옷 중복 구조, 얼굴·손 세부 조형, 전 파츠 UV·베이킹, 리그와 Unity 연결 및 실제 게임 검증. AA급/고증 전체 통과를 선언하지 않는다.

- 추가 확인: Cycles 정면 렌더에서는 목 얼룩이 감소했으나 저장 후 Blender 재질 미리보기에는 목 측면의 각진 얼룩이 여전히 보였다. 렌더/뷰포트 차이의 원인은 미확정이며 목 재질 문제를 완전 해결로 판정하지 않는다.
