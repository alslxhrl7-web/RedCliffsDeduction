# 인물 세부 보정·외부 모션

2026-10-13. 기존 인물 10명의 손끝 각도와 얼굴 표면을 보정하고 CC0 모션의 머리·팔 회전을 현재 작업 자세에 맞춰 적용했다. 전신 리타기팅이나 손가락 리그 신설은 아니다. 원본의 붙은 손가락·낮은 얼굴 해상도는 남아 있다.

## 원본과 제작
- `ArtSource/CharacterDetail20261013/CharacterDetails.blend`: 원형과 보정 자세, 팔·목·얼굴 편집 그룹, UV와 패킹 텍스처.
- `build_detail.py`: 원래 RoleActivities 입력에서 정점 순서를 유지해 얼굴 요철·손끝 각도를 수정하고 위치·노멀을 베이킹한다. 생성 원본이 있으면 명시적 교체 옵션 없이 덮어쓰지 않는다.
- `extract_motion.py`: 외부 동작 5개의 상대 관절 회전을 20Hz로 샘플링한다. `external-motion.json`은 재현용 곡선이다. 큰 회전은 제한하고 발·루트 이동을 제외했다. 서류 소지자와 창 옆 두석은 팔 동작을 추가하지 않는다.
- `bake_face.py`: 눈·코·입·수염을 보호하는 얼굴 마스크로 볼·이마 색상 대비를 약하게 정리한다. 2048px, Cycles 4 samples, margin 8px, 조명 없는 BaseColor 베이크. 기존 UV와 의복 색상 유지. 얼굴 기하 노멀은 자세별 베이크를 사용하고 기존 재질 노멀 맵은 유지한다. 고정 얼굴 그림자/AO를 추가하지 않았다.
- 재작업은 build_detail → bake_face 순서. 이미 베이킹된 원본에는 색상 처리를 중복 적용하지 못하게 막는다. 수작업 수정 원본은 별도로 보존해야 한다.

## 외부 자료
Quaternius의 `Idle_A`, `Idle_Talking`, `Idle_ShakeOff`, `Idle_FoldArms`, `Yes` 사용. [공식 라이선스](https://quaternius.com/packs/universalanimationlibrary.html)는 CC0. [Mesh2Motion 공개 원본](https://github.com/Mesh2Motion/mesh2motion-assets/blob/main/CC0-packs/Quaternius/Quaternius-human-packs.blend)에서 받은 동작을 Blender로 읽었다. 저장소의 [CC0 라이선스](https://github.com/Mesh2Motion/mesh2motion-assets/blob/main/LICENSE)와 원본 해시는 sources.json에 기록했다. Mixamo는 검토했지만 이번 적용 자료는 아니다. 유료 구매 없음.

## Unity 적용과 확인
- `Tools/Character Detail/Apply`, `Apply Face Bakes`: 기존 GUID와 인물·조사 연결을 유지하며 적용한다.
- 출력: `Assets/Art/Characters/RoleActivities/*-detail.bytes`, 기존 역할 자세 바이너리, `Assets/Art/Characters/CharacterDetails/` 얼굴 텍스처·재질.
- `DetailMotionClip`은 기존 대기·대화 결과에 상대 회전을 더한다. 화면 밖·원거리 갱신 제한을 유지한다. 서류 소품은 기존 손 자세 곡선을 따라간다.
- 검증 로그: `Logs/RoleActivities/validation.txt`, `Logs/LiveIdle/checks.txt`, `Logs/OrderChapter/checks.txt`. 사용자 저장과 분리한 Play 검사 후 원래 저장 경로를 복구한다.
- Downloads·Output·Preview·자동 백업은 Git 제외. 원본·완성 출력·재현 도구는 유지한다. 적용 전 사본은 프로젝트 상위 local-backups/BeforeCharacterDetail-*에 보관했다.

검증 결과: 인물 10명 14초씩 실제 프레임 검사 통과(최대 이동 41.6~71.7mm, 발 이동 0mm), 화자 전환 검사 통과, 진행·저장 59개 통과. 현재 컴파일 실패·콘솔 오류·경고 없음. 수동 키보드 플레이와 새 배포 빌드 검사는 아니다.
