## 반영 범위

- 문서고 서쪽 탁자에 반환 묶음, 그 뒤에 연락관 한진을 배치했다. 한진은 처음부터 만나며 대화를 빠뜨려도 진행할 수 있다.
- 수군 진영 전령 옆에 출고 인계 기록을 배치했다. 기존 발급 기록 담당자에게 접수·승인 회신 자료를 확인한다.
- 내용 보존 재작성 의뢰, 반환된 원래 본문, 접수 목록, 독립 출고 기록, 변경 거절 회신, 실제 수령 기록 또는 전달 증언을 연결했다.
- 전달자 수령 전 변경 → 한진의 완성물 제출 → 거절 회신 도착 후 반납 → 승인 위반·고의 유통 판단을 구분한다. 접근 권한이나 은닉 행위만으로 조작자를 지목할 수 없다.
- 원본/접수 카드 대신 작업 의뢰·담당자 확인·독립 출고 기록으로 제출을 판단하는 대체 경로를 유지했다. 회신 수령 기록 대신 직접 전달 증언을 사용할 수 있다. 같은 출처를 독립 증거 여러 개로 세지 않는다.
- 중간 보고에서 제17호 및 대체 재발행을 보류한다. 올바른 배치 확인 요청은 범인 입증 전에도 가능하다. 요청을 실제 부대 이행이나 승리로 처리하지 않는다.
- 수첩 재열람·비교·보고는 무료다. 재작성/출고 조사와 회신 조사는 각각 1회씩 사용한다. 기존 주 경로와 합쳐 8회다.
- 기존 저장 버전 2에 후속 진척을 추가했다. 예전 파일에 필드가 없으면 후속 조사 미진행으로 읽는다. 저장 사본을 깊게 복사하여 현재 조사로 저장 데이터가 바뀌지 않게 했다.

## 다음 수정 권장

1. 한진의 전용 외형과 직책별 손동작: 지금은 기존 서기 모델·자세를 재사용하고 별도 대화 입 움직임을 연결했다. 인물을 구분하는 외형이 부족하다.
2. 증거 문구와 추론 화면: 현재 문구는 출처와 한계를 명시해 검증하기 쉽지만 설명이 길고 정답 방향을 많이 알려준다. 첫 플레이 관찰 후 문서를 짧게 나누고 비교할 핵심을 강조할 필요가 있다.
3. 장소 일관성: 반환 묶음 화면에서도 접수 자료와 담당자 확인 메뉴로 이어질 수 있다. 현장 이동의 비중을 높이려면 자료 열람과 대면 증언을 더 엄격히 나누는 편이 좋다.
4. 배치 확인 요청 이후의 이행 회신·한진 심문·내통 동기·다른 군령·최종 전투 결과는 다음 구간이다. 현재 보고로 전쟁 결과를 확정하지 않는다.
5. 조사 12회 제한의 난이도는 아직 임시다. 자동 검사의 주 경로 8회 통과가 초행 플레이어의 적정 난이도를 보증하지는 않는다.

재작성·인계 절차는 게임의 창작이다. 목간·묶음 재료의 시대 참고와 구체 행정 절차의 역사적 실재를 혼동하지 않는다.
