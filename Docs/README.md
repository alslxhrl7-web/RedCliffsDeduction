## 변경 기록 운영

사용자 요청에 따라 이후 기획 수정도 계속 문서에 기록한다. 변경할 때마다 승인 내용, 변경 전후, 이유, 영향받는 문서, 기획·코드·씬·빌드별 반영 상태, 남은 미정 사항을 남긴다. 제안과 사용자 확정을 구분하며 기존 기록은 삭제하지 않고 최신 결정으로 대체된 부분을 명시한다. 최신 상세 이력은 [단계별 조사 구성과 확정 기록](단계별%20조사%20구성과%20확정%20기록.md)에 추가한다. 문서 저장을 커밋이나 GitHub 업로드로 표현하지 않는다.

## 현재 실행본 상태

현재 Unity 프로젝트의 새 게임은 군령 분실 조사로 시작하며 문서 회수·내용 대조·중간 보고까지 구현되었다. 새 범행 수법·원본 행방·범인 확정·전투 엔딩은 미구현이다. 기존 시간 시스템은 임시 12회로 유지한다. 저장은 버전 2와 별도 파일명을 사용한다. 이전 배포 빌드는 이번 작업에서 갱신하지 않았다. 상세 범위는 위 구현 기록을 따른다.

‘모순 발견 이후 조사 구성’, ‘밀서와 취조 확정 구성’, ‘두석 시간대 조사 구성’, ‘조사 시간 진행’ 등 이전 상세 문서는 기존 구현을 설명한다. 새 기획과 충돌하면 이 안내의 현재 기획 문서를 따른다. 날짜가 있는 검증 결과는 당시 버전에만 유효하다.
