## 변경 기록 운영

최신 손 교체는 [손가락 조형과 검증](손가락%20조형과%20검증.md), 이전 인물 보정은 [인물 세부 보정](인물%20세부%20보정.md), 베이킹 과정의 오류와 해결 상태는 [베이킹 문제](베이킹%20문제.md)에 정리한다.

소품·인물 작업은 [아트 제작과 유지보수](아트%20제작과%20유지보수.md)를 따른다. 베이킹, 편집 원본, Unity 적용, 검증 절차의 기준이며 프로젝트 루트 `AGENTS.md`에도 작업 규칙을 명시했다.

사용자 요청(2026-10-09): 이후 주요 업데이트는 [패치노트](PATCH_NOTES.md)에 버전별로 기록한다. 개선·추가·수정·검증·알려진 미완료 사항을 구분하고, 빌드/업로드 여부를 따로 명시한다.

사용자 요청에 따라 이후 기획 수정도 계속 문서에 기록한다. 변경할 때마다 승인 내용, 변경 전후, 이유, 영향받는 문서, 기획·코드·씬·빌드별 반영 상태, 남은 미정 사항을 남긴다. 제안과 사용자 확정을 구분하며 기존 기록은 삭제하지 않고 최신 결정으로 대체된 부분을 명시한다. 최신 상세 이력은 [단계별 조사 구성과 확정 기록](단계별%20조사%20구성과%20확정%20기록.md)에 추가한다. 문서 저장을 커밋이나 GitHub 업로드로 표현하지 않는다.

## 현재 실행본 상태

현재 군령 조사는 중간 보고 없이 진행하며, 조조 최종 보고에서 직접 선택한 결론·근거·시행 조치로 제17호 사건의 BAD/NORMAL/TRUE 엔딩에 도달한다. 전체 전쟁 결과의 판정은 별도 구간이다. 저장 버전 2를 유지하며 기존 저장의 중간 보고 기록은 새 엔딩 평가에 사용하지 않는다. 현재 빌드 버전은 demo.7이다. 최신 변경은 패치노트를 따른다.

‘모순 발견 이후 조사 구성’, ‘밀서와 취조 확정 구성’, ‘두석 시간대 조사 구성’, ‘조사 시간 진행’ 등 이전 상세 문서는 기존 구현을 설명한다. 새 기획과 충돌하면 이 안내의 현재 기획 문서를 따른다. 날짜가 있는 검증 결과는 당시 버전에만 유효하다.
