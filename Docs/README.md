# 적벽추리 기획 기준과 문서 안내

기준일: 2026-10-01. 이 폴더의 기획 문서는 현재 코드와 채택한 설정을 반영한다. 기존 파일 경로는 링크 호환을 위해 유지한다. ‘초안’·‘변경안’이라는 파일명만으로 미구현이라고 해석하지 않는다. 과거 제안은 Git 이력에서 확인하며, 현재 본문에는 채택된 규칙과 실제 남은 범위를 구분한다.

경력 서류, 자유 이동·목패 질문, 지휘 천막 왕복, 후속 조사 연결 문서는 각 장소·조작의 세부 설명이다. 기술 오류 수정과 날짜가 붙은 검증 기록은 해당 작업 당시의 기록이며 새 기획 규칙을 정의하지 않는다.

## 공통 확정 사항

- 1인칭, 이름 입력과 조조군 지휘 천막 도입, 문서고·수군 진영 자유 왕복.
- 설평은 목연이라는 본명을 숨기고 실제 서리 경력을 쌓은 오나라 첩자다. 경력 자체와 직접 목격 주장의 진위를 구분한다.
- 진엔딩은 설평 확정 지목과 검증된 호적·밀서 보유 상태로 판정한다. 두석 조사는 선택이다.
- 조사 시작은 열이튿날, 기한은 열나흗날 밤, 접선은 열닷새 새벽이다. 사흘 총 12회, 조사 시작 확인 때 비용 사용. 재열람·이동·수첩·비교·보고는 무료다.
- 배드엔딩 문서 전달은 접선 이후 후일담이며, 노멀은 행방 불명, 진엔딩은 접선 전 소지 문서 회수다.
- 엔딩은 기존 씬 안의 텍스트·암전이며 처형을 직접 묘사하지 않는다.
- 저장은 미리보기가 있는 수동 슬롯 하나다. 조사 기록과 장소를 복원하며 보고 초안·엔딩 자체는 저장하지 않는다.

## 현재 남은 사항

초보자 대상 안내·난이도 평가, 다른 해상도와 배포 빌드 확인, 그림자 품질 경고 검토가 남았다. 자동 저장·다중 슬롯, 별도 전달자 수사, 별도 3D 엔딩 연출은 추가 여부를 결정할 선택 기능이다. 잠입의 정확한 날짜·범행의 분 단위 시각·접선 지명 등은 사건 정답지의 미정 항목으로 남긴다. 이번 문서 정리에서 새 필수 조건이나 시간 비용을 추가하지 않았다.
