## 검사 방법과 저장 보호

`적벽추리 → 플레이 검증 → 전체 회귀 검사` 메뉴로 반복 실행한다. 실제 세션, 조사 대상, 선택 버튼의 onClick, 기록 UI, 파일 저장·불러오기와 엔딩 전환을 사용한다. 날짜 경계의 대량 경로 검사는 연출 대기를 생략하지만, 별도 검사에서는 실제 암전 애니메이션 종료까지 기다렸다.

검사 저장은 `Temp/PlayRegression/Saves-*`에 격리했다. 실제 사용자 저장 파일은 `Temp/PlayRegression/UserSaveBackup`에 백업했으며 검사 슬롯으로 덮어쓰지 않았다. 저장 경로 변경은 `UNITY_EDITOR` 조건에서만 적용되므로 배포 게임의 저장 위치는 유지된다. 검사 전 장면을 저장하고, 검사 후 플레이를 종료하며 원래 Enter Play Mode 설정을 복원한다.

- 조사 4회·8회 날짜 경계, 시간 보내기 취소·진행·복원, 12회 완료 이후 13번째 새 조사 차단, 기한 종료 보고와 미해결 엔딩.

- 수동 저장 메뉴의 저장·미리보기·취소·불러오기, 장소·기록·일정 복원, 불러온 조사 재열람의 중복 차감 방지, 손상된 슬롯 선택 비활성화.

첫 검사에서 3건이 실패했다. 게임 오류로 재현된 것이 아니라 검사 전제가 현재 설계와 맞지 않았다. 11회 경로에서 선택 경비 진술을 무조건 요구한 기록 검사를, 실제 확보한 진술만 표시하고 미확보 진술은 누출하지 않는 검사로 변경했다. 13번째 조사 검사도 사전 정보가 없으면 새 조사가 시작되지 않는 동석 병사 대신 미조사 전령을 사용해 한도 차단을 확인한다. 손상된 저장 검사는 실제 슬롯 버튼의 비활성 상태를 확인하도록 강화했다.
