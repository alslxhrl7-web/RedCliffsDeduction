# NPC 자세와 조사 시간 확인 — 2026-10-06

## 신고 내용

- NPC의 팔과 손이 부자연스럽다.
- 새 조사를 시작해도 날짜와 남은 조사 횟수가 그대로인 경우가 있다.
- 사용자가 지적한 대상은 팔·손과 시간 진행이다. 화면의 가로선과 카메라 시점은 이번 수정 범위에 넣지 않았다.

## 반영한 변경

`Assets/Editor/VarcoRolePoses.cs`에서 서기 모델의 팔꿈치를 추정해 100도 접고 손을 앞으로 이동시키던 처리를 제거했다. 팔 전체를 내리는 기본 자세를 사용한다. `서기 팔 자세 수정` 메뉴로 설평과 기록 담당자만 갱신할 수 있다. 실제 형상이 바뀐 모델은 기록 담당자이며, 설평은 원래 팔을 내린 모델이라 결과 형상에 차이가 없다. 기존 씬이 참조하는 RecordsClerk_RolePose0.asset에 적용했다.

조사 화면에는 아래 두 상태를 구분해 표시한다.

- 새 조사: `조사 1회 사용 · 남은 조사 N회`
- 같은 주제 재방문: `이미 시작한 조사 · 추가 시간 소모 없음`

12회 제한, 새 주제 시작 시 차감, 같은 주제의 추가 질문은 무료라는 규칙은 유지했다. 저장 복원 시 임시 안내 상태는 초기화한다.

## 확인 결과와 한계

현재 소스에서 시간 정지 현상은 재현하지 못했다. 차감 로직의 결함을 확인해 수정했다고 볼 수는 없으며, 이번 시간 관련 변경은 차감 상태를 명확히 알리는 보강이다.

Unity Play 모드에서 사용자 저장과 분리된 임시 저장 폴더로 검사했다.

- 기존 조사·엔딩·저장·날짜 전환 회귀 항목 통과.
- 첫째 날 밤, 9회 남음에서 중간 보고 후 복귀 → 새 채모 조사 → 둘째 날 오전, 8회 남음.
- 채모 재방문 → 8회 유지, 추가 소모 없음 안내.
- 새 장윤 조사 → 둘째 날 오후, 7회 남음.
- 저장 상태 복원 후 새 경력 조사 → 둘째 날 저녁, 6회 남음.
- 각 단계에서 실제 저장 상태, 상단 날짜, 대화창 날짜 및 차감 안내를 함께 비교해 통과.
- 9명 대기 움직임 검사 통과: 원본 메시 유지 및 발 위치 고정.
- 컴파일 오류 없음. 모델 렌더링과 시간 안내 스크린샷 확인.

추가한 검사 메뉴: `적벽추리 > 플레이 검증 > 보고 후 새 조사 시간 표시`.

결과 파일: `Logs/PlayRegression/result.txt`, `Logs/PlayRegression/inquiry-time.png`, `Logs/VarcoPreviews/role-poses.png`, `Logs/VarcoPreviews/idle-check.txt`.

남은 확인 사항: 실제로 멈췄던 인물·질문·실행 버전 또는 해당 저장 기록을 확보해 같은 경로로 재현해야 한다. 기존 배포 실행 파일과 itch 업로드는 이번에 교체하지 않았다.
