# URP 셰이더 오류 조치

## 관찰한 오류

작업 폴더는 `C:\Users\나민재\Documents\poject\RedCliffsDeduction`이다. 이 폴더의 `Logs/Editor.log`에서 URP/Lit의 include 실패 두 건을 확인했다.

```text
Couldn't open include file 'Packages/com.unity.render-pipelines.universal-config/Runtime/ShaderConfig.cs.hlsl'.
```

오류의 Fog.hlsl 위치는 이전 `Documents/RedCliffsDeduction/Library/PackageCache` 경로를 가리켰다. 현재 프로젝트의 `Library/PackageCache/com.unity.render-pipelines.universal-config@561422b74439/Runtime/ShaderConfig.cs.hlsl`은 존재한다. URP와 universal-config 버전은 17.6.0이다. 따라서 이전 프로젝트에서 넘어온 셰이더 가져오기 캐시가 원인일 가능성이 높지만, 캐시의 이전 경로만으로 원인을 확정하지 않았다. 현재 로그에서 배경음 코드의 C# 컴파일 오류는 발견하지 못했다.

## 조치

Unity Pipeline 패키지는 있으나 `unity pipeline list`의 실행 중 편집기 서버는 연결되지 않았다. Play·빌드 또는 별도의 headless Editor를 실행하지 않았다.

전체 Library 삭제 대신 `Assets/Editor/UrpShaderRepair.cs` 일회성 복구 도구와 `Library/UrpShaderRepair.request` 요청을 추가했다. 열린 편집기가 새 스크립트를 가져오면 편집 모드에서 다음 세 파일만 강제 재가져오기한다.

- `Packages/com.unity.render-pipelines.universal-config/Runtime/ShaderConfig.cs.hlsl`
- `Packages/com.unity.render-pipelines.universal/ShaderLibrary/Fog.hlsl`
- `Packages/com.unity.render-pipelines.universal/Shaders/Lit.shader`

요청은 처리 시 `.handled-시각` 이름으로 보존한다. 매번 편집기를 열 때 반복 실행하지 않는다. Play 상태에서는 복구를 수행하지 않고 편집 모드를 기다린다. 이후 ShaderUtil의 현재 메시지를 조회하여 `Docs/URP 셰이더 복구 결과 2026-10-04.md`로 남긴다. 실패도 같은 결과 파일에 기록한다.
