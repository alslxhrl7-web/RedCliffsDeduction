# 인물 고증 검토 — 2026-10-18

기준 시대는 후한 말 적벽 시기(208년). 아래는 실제 확인한 근거와 제작 판단이며, 전체 인물 고증 완료를 의미하지 않는다. 생성 이미지·생성 3D는 증거로 사용하지 않는다.

## 확인 자료와 적용 범위

1. 중국국가박물관 「陶部曲俑」: 후한 부곡·가정 무장 인물의 짧은 상의, 교차 깃, 우임, 환수도 설명을 확인했다. 일반 경비·하급 인물의 여밈 방향과 실용적인 복식에 적용한다. 이 한 유물로 모든 인물의 관모·색·신분별 복식을 확정하지 않는다.
   https://www.chnmuseum.cn/zp/zpml/kgfjp/202110/t20211028_251921.shtml
2. 남월왕박물원 「铁铠甲」: 서한 남월국(기원전 203–111년), 남월문왕묘, 철편 709개를 끈으로 연결한 갑옷. 철편 연결 구조의 비교 자료이며 후한 말 형상·수량·치수의 직접 복제품 기준이 아니다. 출토품의 부식 상태를 당시 사용 중 갑옷의 색으로 복사하지 않는다.
   https://www.admin.nywmuseum.org.cn/Collection/Details/dcjp?nid=148
3. 동화대학학보(사회과학판), 2020년 20권 3호 「解读中国古代的铠甲」: 검색 색인에서 후한 투구의 장조형 철편, 한대 투구의 철편 조합·목 보호 구조에 관한 본문을 확인했다. PDF 직접 열람은 시간 초과로 전체 도판을 검토하지 못했다. 따라서 좁고 긴 철편 구조를 수정 방향으로 삼되 정확한 편수·결속 위치·정수리 마감은 복원 추정으로 남긴다. 논문에 함께 실린 북조·당송 사례를 후한 유물로 사용하지 않는다.
   https://qkzx.dhu.edu.cn/_upload/article/files/60/0f/8126ba314fa59433f859e45f517a/53112926-3fb8-496e-a4f2-8b7da131dee2.pdf
4. 고궁박물원 「陶庖厨男俑」(신00109121): 후한 남성의 책(帻)과 우임 의복을 확인했다. 설평 머리싸개와 교차 깃의 비교 자료. 요리하는 인물의 복식을 설평의 직책 복식으로 그대로 동일시하지 않는다.
   https://www.dpm.org.cn/collection/sculpture/233370.html
