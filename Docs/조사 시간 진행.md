# 조사 시간 진행

첫째 날 오전에 시작한다. 새로운 조사 묶음을 처음 완료할 때마다 오전 → 오후 → 밤 → 다음 날 오전으로 진행한다. 이동, 재열람, 취소, 허가 요청, 최종 보고에는 시간을 쓰지 않는다.

| 묶음 | 완료 기준 |
|---|---|
| 문서고 초동 조사 | 빈 보관함 확인 + 설평 최초 경력 진술 완료 |
| 수군 설명 | 채모·장윤의 훈련 관련 진술 모두 완료 |
| 경력 서류 | 인계 명부와 근무 기록 모두 열람 |
| 호적 | 대조 항목 검토 후 결과 기록 |
| 개인 서류 | 허가받은 조사에서 밀서 펼치기 |
| 목패·취조 | 대조와 진술 제시 후 취조의 마지막 대화 완료 |

각 묶음은 한 번만 차감한다. 먼저 서류를 읽는 등 순서가 달라도 동일하게 계산한다. 일부 기록은 읽는 순간 완료되므로 읽은 뒤 닫는 행동은 완료된 조사를 취소하지 않는다.

화면 상단과 대화창에 현재 날짜를 표시한다. Esc → 날짜와 조사 일정에서 완료 내역을 확인한다. 현재 여섯 묶음을 모두 끝내면 셋째 날 오전이며 세 시간대의 여유가 남는다. 재시작하면 날짜도 초기화된다.

이번 구현은 날짜 표시와 조사별 진행이다. 현재 여섯 묶음으로 기한 만료는 발생하지 않는다. 향후 추가 조사와 연결할 9칸 상한만 준비했으며, 시간 만료 시 강제 호출·새 조사 차단·미해결 엔딩 판정은 아직 연결하지 않았다. 최종 보고는 날짜 때문에 잠기지 않는다.

2026-09-30 추가 구현: [두석 시간대 조사](두석%20시간대%20조사%20구성.md)는 주변 증언 확인과 두석 재질문을 끝내 결과를 기록할 때 한 시간대를 소모하는 선택 조사다. 단순 최초 대화에는 차감하지 않는다. 필수 6개와 이 조사를 모두 완료하면 셋째 날 오후가 된다.
