# 조사 시간 진행 — 인물·주제별 12회

2026-09-30 적용. 이전의 조사 묶음 완료 시 차감 방식을 대체한다.

첫째 날 오전 시작, 하루 오전·오후·저녁·밤의 4칸, 사흘 총 12회다. 새 조사 시작을 확인했을 때 1회를 사용한다. 확인창에서 취소하면 무료다. 시작 후 대화를 중단해도 환불하지 않지만, 같은 주제에 다시 들어갈 때 중복 차감하지 않는다.

| 조사 주제 | 비용 |
|---|---|
| 설평 업무·경력·발견한 목패 소유 이력 | 1회 |
| 두석 최초 경비 상황과 이탈 전후 문서고 상황 | 1회 |

총 13개 주제 중 12개까지 시작할 수 있다. 주요 진엔딩 경로는 8회, 두석 선택 조사 전체까지 포함하면 13회다. 따라서 모든 주제를 무조건 조사할 수는 없다. 이미 산 주제에서 나중에 열린 질문은 무료다.

이동·보관함 및 목패 관찰·정비 명령서 열람·증거 비교·수첩·두석 조사 결과 정리·보고·허가 요청에는 추가 비용이 없다. 이미 읽은 자료는 무료로 다시 확인한다. 목패 질문은 실제 발견 후에만 열린다.

## 마지막 조사와 최종 보고

마지막 1회 사용 전에 경고한다. 12회를 사용해도 선택한 조사의 대화와 결과 확인은 끝낼 수 있다. 이미 시작한 주제는 재방문 가능하지만 새로운 13번째 주제는 차단한다.

대화를 닫거나 새 조사를 시도하면 조조의 호출 화면에서 ‘마지막 조사의 남은 내용 확인’ 또는 ‘조사를 마치고 최종 보고’를 선택한다. 마지막 대화 중에는 강제로 끊지 않는다.

0회 상태에서 최종 보고에 들어가면 현장 복귀·새 조사 요청은 닫힌다. 제출 근거와 결론은 확정 전까지 수정할 수 있고, 보고에 별도의 현실 시간 제한은 없다. 기한 종료 시에는 채모·장윤 대화를 다 못 들었더라도 보고할 수 있다.

- 설평 확정 지목 + 두 핵심 단서: 진엔딩.
- 설평 확정 지목 + 증거 부족: 노멀엔딩.
- 다른 인물 확정 지목: 대상별 배드엔딩.
- 미해결 또는 의심만 한 보고: 미해결 배드엔딩.
- 기한 전 미해결·의심 보고는 기존처럼 조사 복귀 가능.

조조의 도입 대사에 사흘과 실패 책임을 암시하는 경고를 추가했다. 날짜와 남은 조사 횟수는 화면에 표시하며 Esc → 날짜와 조사 일정에서 비용을 낸 주제를 페이지별로 확인한다. 재시작 시 초기화된다. 수동 저장·불러오기를 지원한다. 세부 규칙은 저장과 불러오기 문서를 따른다.

## 검증

12회 비용, 동일 주제 중복 차감 방지, 날짜 경계, 13번째 차단, 기한 전후 미해결·의심 보고와 진/노멀/배드 조건을 편집기 검증 도구에서 확인한다. 실제 Play 모드에서 마지막 조사 완료, 13번째 차단, 보고 잠금과 미해결 엔딩까지 확인했다. 검증 범위는 [플레이 검증 결과](플레이%20검증%20결과%202026-10-01.md)를 따른다.


## 2026-09-30 업무 동선과 접선일 구체화 — 최신 확정

- 이야기 속 같은 달 열이튿날 조사 시작, 열사흗날 둘째 날, 열나흗날 밤 사흘 기한 종료, 열닷새 새벽 접선으로 확정한다. 역사적 적벽대전 날짜를 확정하는 설정은 아니다. 조조의 도입 대사와 날짜 표시에도 반영한다.
- 밀서에는 ‘이달 열닷새 새벽, 약정한 곳’이라고 직접 적는다. 적이 조사 기한을 알고 쓴 편지가 아니라, 플레이어가 별도로 정해진 접선일을 조사 일정과 대조한다. 밀서 발견 후 무료 대조 버튼과 수첩에서 다시 볼 수 있다. 인계 예정과 실제 전달 완료는 구분한다.
- 설평의 ‘맡은 일’ 대화에서 문서 반납·보관 업무, 기록 탁자와 보관함 사이의 동선, 경비 자리의 시야를 듣는다. 두석의 ‘맡은 경비’에서는 서기의 별도 출입 허가가 필요 없었다는 설명과 부재 중 행동을 목격하지 못했다는 한계를 듣는다.
- 각 대화를 끝까지 들어야 별도 진술 상태로 수첩에 기록한다. 두 설명을 모두 들으면 최종 보고에 접근 기회 자료로 제출할 수 있다. 모순·밀서 검증이나 진엔딩 조건을 대신하지 않는다. 기존 조사 비용 안에서 처리한다.
- 실제 부재를 알아차려 훔쳤다는 전모는 문서 회수 뒤 진엔딩 후일담으로 밝힌다. 회수 전에는 접근 기회와 실제 절도를 구분한다.
- 새 진술 상태는 저장·불러오기에 포함한다. 기존 저장은 새 진술을 아직 듣지 않은 상태로 호환한다.
