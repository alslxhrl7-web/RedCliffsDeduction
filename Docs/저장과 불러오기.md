# 저장과 불러오기

기준일: 2026-10-01.

- 조사 화면에서 Esc → 저장 / 불러오기. 수동 슬롯 1개, 덮어쓰기 확인 포함.
- 첫 이름 입력 화면과 엔딩 결과 화면에서도 불러오기 가능.
- 저장 메뉴, 불러오기 확인, 덮어쓰기 확인에서 참모 이름·게임 날짜 및 시간대·남은 조사 횟수·장소·실제 저장 시각을 미리 표시한다. 저장 시각이 없는 구버전 기록은 ‘시각 기록 없음’으로 표시한다.
- 미리보기와 취소는 현재 진행을 바꾸지 않는다. 불러오기 확인에서 본 검증된 기록을 그대로 복원한다. 기록이 없거나 손상·지원하지 않는 버전이면 이유를 안내하고 복원 버튼을 제공하지 않는다.
- 0회 기록은 기한 종료 상태이며 마지막 조사 확인 또는 최종 보고로 이어짐을 미리 알린다.
- 이름, 단서, 진술, 두석 시간대 조사, 호적 확인 과정, 밀서 취조, 수색 허가, 선택한 조사 대상, 이미 비용을 지불한 조사 및 남은 횟수를 복원한다.
- 위치는 문서고 또는 수군 진영 입구로 복원한다. 정확한 발 위치나 시선은 저장하지 않는다.
- 진행 중인 대화 문장과 제출 전 보고서 선택은 저장하지 않는다. 대화·보고에서 조사 화면으로 돌아온 뒤 저장한다.
- 기한 만료 저장을 불러오면 마지막 조사 확인 / 최종 보고 선택으로 이어진다.
- 저장 경로는 Unity Application.persistentDataPath의 investigation-save.json. 프로젝트나 GitHub에 저장되지 않는다.
- 임시 파일 검증 후 교체하며 직전 파일은 .bak으로 남긴다. 자동 백업 복원 기능은 없다.
- 저장 없는 상태, 손상 또는 지원하지 않는 버전의 불러오기는 오류 안내를 표시하고 진행을 유지한다.
- 자동 저장은 없다. 처음부터 다시 시작해도 기존 수동 저장은 지우지 않는다.

## 이야기 설정 확정

설평은 공동 근무 중 당일 두석의 부재를 직접 확인해 범행했다. 접선은 조사 나흘째 새벽이며 사흘·12회 조사 기한은 유지한다. 사전 연락·문서 발송 금지 지시를 밀서에 반영했다. 진엔딩은 접선 전 소지 문서 회수, 배드엔딩은 접선 이후 전달 후일담, 노멀엔딩은 행방 불명이다. 세부 기준은 사건 정답지를 따른다.
