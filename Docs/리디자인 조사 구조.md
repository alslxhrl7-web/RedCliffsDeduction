# 적벽추리 — 리디자인 조사 구조

기준일: 2026-10-08. 전체 조사 구조의 기획 문서다. 현재 런타임에는 문서 회수·내용 대조·중간 보고 구간까지 반영했으며 나머지 경로는 미완성이다. [구현 기록](군령%20조사%20구현%20기록%202026-10-08.md)에서 적용 범위를 확인한다. 인물·시간의 기준은 [사건 정답지](사건%20정답지.md)다.

## 조사 흐름

최신 승인 구성은 [단계별 조사 구성과 확정 기록](단계별%20조사%20구성과%20확정%20기록.md)에 있다. 문서 이동 → 은닉 이유 → 군령 조작의 흐름이며, 1단계 상세는 확정, 2·3단계 상세는 검토 중이다. 설평의 과거 소속·장윤의 보호 사정은 선택 조사이며 진행·진엔딩의 필수 완료 조건이 아니다.

관찰 → 주장 기록 → 플레이어 가설 → 자료 비교 → 모순 선택 → 재질문 → 새 사실 → 관계 연결 → 최종 인과관계 보고.

초기 질문은 인물의 역할과 최초 주장을 얻는 데 사용한다. 같은 질문 반복은 기록 재열람이며 진행을 만들지 않는다. 후속 질문은 관련 사실 또는 플레이어가 확인한 모순이 생길 때만 열린다. 이미 확보한 기록은 무료로 재열람하며 오답 비교는 증거를 없애거나 영구적으로 질문을 잠그지 않는다.

## 단서와 재질문 연결

| 경로 | 선행 자료 | 플레이어 비교 | 열리는 질문 / 새 사실 |
|---|---|---|---|
| 문서 이동 | 빈 보관 위치·수령 서명·수령 부대 미수령 | 정상 전달 주장과 인계 결과 불일치 | 전달자에게 마지막 보관 위치 질문 → 수송함과 교체본 |
| 두석 행적 | 부재 주장·22시 목격 | 같은 장소·시간의 상충 | 22시 방문 이유 → 채무와 안내인 |
| 경비 공백 | 당직 기록·교대 신호·도박 장부 | 기록 시각과 실제 정산 시각 | 경비 이탈 재질문 → 실제 공백. 병사 재질문 → 연락관 목격 |
| 설평 과거 | 직접 출항 목격 주장·정비 명령·기간 재확인 | 중단된 출항을 직접 봤다는 모순 | 무단 열람 이유 → 숨긴 소속. 실제 서리 경력은 부정하지 않음 |
| 군적 신뢰 | 현 군적·과거 지급 명부 | 같은 인물의 소속 불일치 | 장윤 정정 사유 → 과거 기록 조작. 사건 밤 행위와 분리 |
| 안내인 신분 | 목패·입영 주장·군적 | 미등록 입영과 정식 인수 권한의 차이 | 채모 비공식 임무 → 수로 스케치·목패 발급 시각 |
| 군령 진위 | 교체본·봉인 부본·인계 이력·배치 준비 기록 | 같은 발급 번호의 상충 문구 | 전달자 보류 동기 확인, 발급 경위 재조사 |
| 조작자 | 변경·승인·재발행 자료를 3단계에서 설계 | 작성 업무와 무단 변경·고의 유통을 구분 | 한진 관련 책임 검증. 안내인 누명·목패 인계 시각 모순은 삭제 |
| 전투 효과 | 복원 군령·지도·부대 이동 시간·연락 쪽지 | 감시·확인·소화대 공백의 연결 | 목적·예상 피해 판단 → 적벽 작전명 공개 |

문서 이동, 인물 행적, 기록 검증은 병렬 조사 경로다. 한 경로를 모두 끝내야 다른 경로를 시작하게 만들지 않는다. 후반의 군령 비교에서 합류한다. 필수 사실은 인물의 자백만으로 얻지 않도록 문서·물건의 대체 검증 경로를 둔다.

## 조사 보드

전달자의 확인 생략 사유는 반복 업무에 익숙해져 발급 번호·수령 부대만 확인하고 본문 대조를 건너뛴 것으로 확정한다. 이번에 차이를 발견한 계기와 이를 입증할 자료는 미정이다. 문서의 중요성을 깨닫는 것과 문구 차이를 확인하는 것을 같은 사실로 처리하지 않는다.

전달자 동기 검증: 먼저 정상 인계 절차와 ‘수령’·‘내용 대조 완료’의 차이를 설명한다. 이후 정상 확인 기록과 실제 비교 경위를 대조해, 확인 절차 위반을 감추려던 임시 보류가 미수령 조사 이후 거짓말·은닉으로 커졌는지 검증한다. 구체 물증과 대체 경로는 추가 설계하며, 고백 하나로 조작자 여부까지 확정하지 않는다.

- 확인된 사실: 플레이어가 관찰하거나 대조를 마친 사실과 출처만 표시한다.
- 미검증 주장: 발언자·장소·시각을 표시하고 사실과 분리한다.
- 현재 의문: 문서 위치, 접근 권한, 기록 차이 등 조사 가능한 문제를 표시한다.
- 연결되지 않은 단서: 확보했으나 플레이어가 관계를 지정하지 않은 자료를 표시한다.

초기 보드는 조조에게 전달받은 ‘반출 기록은 있으나 수령 부대는 받지 못했다는 사건 개요’와 ‘어디서 인계가 끊겼는가?’를 보여 준다. 개별 기록은 직접 확인한 뒤 검증 사실로 표시한다. 숨은 인물·전투·정답·정답률을 미리 표시하지 않는다. 시스템은 비교할 자료를 제공하고, 모순과 인과관계 선택은 플레이어가 한다.

## 상호작용 요구사항

대상 강조, 이름, 조사/대화 안내, 미조사·조사 완료·새 질문·재열람 상태를 구분한다. ‘군적 — 병사의 소속과 등록 내역을 적은 명부’처럼 기능 설명을 붙인다. 중요한 자료 표시는 자료 종류에 사용하고 범인 관련성이나 진위의 자동 판정에는 사용하지 않는다.

## 구현 전환 항목

| 기존 기능 | 변경 용도 |
|---|---|
| Duseok Timeline | 두석 행적 검증. 교대 경비 공백과 인물 분리 |
| Token / Registry | 신분·권한 및 기록 정정 검증 |
| Testimony / Reconfirm | 주장 저장, 모순별 질문 해금 |
| Document / Returned | 문서 이동·은닉과 문구 조작 분리 |
| Guard Departure / Return / Gambling Witness | 공백의 교차 검증 |
| Journal | 출처 있는 사실·주장·의문·플레이어 연결 |
| Final Report / Ending | 역할·동기·진본·작전 결과를 판단 |

새 NPC, 질문 조건, 증거 출처, 보고 선택과 인과관계 데이터를 먼저 정의한 뒤 대사·UI·엔딩·저장을 함께 이전한다. 기존 저장을 새 증거로 자동 인정하지 않는다. 새 저장 버전 또는 명시적 새 게임 전환이 필요하다.

기존 사흘·12회는 현재 실행본의 규칙이다. 새 경로에 그대로 적용하지 않는다. 필수 검증을 모두 수행해도 탐색 여유가 남는지 플레이테스트한 뒤 비용을 확정한다. 재열람·이동·비교·보고는 무료라는 방향을 유지한다.
