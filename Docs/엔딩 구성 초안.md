# 엔딩 구성 초안


밀서·취조 최신 확정: [밀서와 취조 확정 구성](밀서와%20취조%20확정%20구성.md)을 우선한다. 호적 의문 → 귀속된 밀서 발견 → 취조로 목연 연결 확인 → 최종 보고와 수색 → 화공대비책 회수 순서다. 밀서의 발견과 검증 완료를 구분하며 구체 연결 물증은 아직 미정이다.

2026-09-29. 기존 확정 조건을 바탕으로 구성한 초안이며 사용자 요청으로 최종 보고에 텍스트 엔딩을 연결했다. 미정인 후속 수사와 기한 규칙은 추가하지 않았다.

## 현재 게임 연결 상태

- 확정 지목 후 ‘현재 결과로 보고를 마친다’ → 보고 완료에서 엔딩으로 진행한다. 신병 확보 요청은 두 핵심 단서와 설평 확정 지목이 있어야 열린다.
- 현재 플레이에서 설평 지목은 노멀, 채모·장윤·두석 지목은 각각 배드로 연결된다.
- 진엔딩 판정·문구는 구현했지만 호적·밀서 획득 장면이 없어 일반 플레이에서는 아직 진입할 수 없다. 경력 서류나 모순 발견을 핵심 단서로 대체하지 않았다.
- 의심/미해결 보고 및 추가 조사 요청은 조사를 계속할 수 있게 처리한다. 이 미정 분기를 배드로 확정하지 않는다. 요청별 새로운 수사는 아직 연결하지 않았다.
- 시간 초과 엔딩은 문구만 준비했다. 시간 진행·기한 만료 호출은 구현하지 않았다.
- 엔딩은 조조의 판단 → 시간 경과와 후속 상황 → 결과 화면으로 구성한다. 별도 영상이나 오나라 3D 장면은 추가하지 않았다.
- 결과 화면에서 보고서 확인, 엔딩 다시 보기, 초기화 확인 후 처음부터 다시 시작이 가능하다. 별도 제목 화면은 없다.

## 공통 구조와 유지할 조건

최종 보고 내용 확인 → 보고 완료 → 조조의 판단 → 후속 상황 → 결과 화면 순서다. 중간 조사 요청, 대화 오답, 모순 미발견, 추가 조사 건너뛰기만으로 결말을 확정하지 않는다.

- 설평을 최종 지목하고 호적 부재 및 본명 밀서 두 핵심 단서를 확보하면 진엔딩.
- 설평 지목에 핵심 단서가 부족하면 노멀. 추측 지목도 기존 규칙을 유지한다.
- 채모·장윤·두석을 최종 지목하면 대상별 배드.
- 기한 초과·미해결은 배드 방향이나 기한 처리와 의심/미해결 보고의 구체 판정은 아직 미정.
- 현재 규칙은 핵심 단서 확보 여부를 기준으로 한다. 보고 화면에서 제출을 빠뜨렸다고 몰래 다른 엔딩으로 보내지 않는다. 확보/제출 중 무엇을 판정 기준으로 삼을지는 별도 논의한다.
- 실제 서리 경력과 가명 신원을 구분한다. 경력 전체가 날조됐다는 결론을 사용하지 않는다.
- 문서 회수만으로 적벽대전 전체의 승패를 확정하지 않는다.

## 진엔딩 제안 — 되찾은 대비책

조건: 설평 지목 + `clue_household_registry_no_record` + `clue_wu_secret_letter_true_name`.

조조는 실제 근무 기록을 인정하면서 호적 대조와 밀서가 밝혀낸 신원·사건 연결을 검토한다. 군사를 보내 설평의 신병을 확보하고 몸에 숨긴 화공대비책을 회수한다. 설평이라는 이름으로 실제 근무한 사람이 목연이며 오나라의 절도 지시를 받았다는 사실이 밝혀진다. 주인공의 보고로 전달 전에 회수했다는 성취로 마무리한다.

조조 대사 초안: “서리로 일한 것은 사실이었다. 그러나 그 이름으로 감춘 충성까지 우리 것이었던 것은 아니구나.”

결과: 범인과 신원 확인 / 화공대비책 회수 / 오나라 전달 저지.

호적 기록 부재만으로 유죄를 단정하지 않는다. 밀서는 본명만이 아니라 위장 신분과 오나라 연락, 문서 확보·인계 지시를 연결해야 한다. 구체적인 증거 획득 과정은 후속 설계다.

## 노멀엔딩 제안 — 끝내 닿지 못한 증거

구현 추가: 기존 Investigation 씬에서 후일담 → ‘보고서를 덮는다’ → 암전 → ‘엔딩?’ 화면으로 이어진다. ‘그때 다른 질문을 했다면, 놓친 말을 다시 살폈다면… 이 사건은 다른 결말에 닿을 수 있었을까?’라는 문구로 다른 결말을 암시한다. ‘다시 조사한다’는 초기화 확인을 거쳐 이름 입력부터 재시작하고, ‘이번 조사 결과를 확인한다’는 결과 화면으로 이어진다. 진엔딩 조건이나 미확보 단서는 공개하지 않는다. 별도 씬 파일이나 처형 연출을 추가하지 않았다. 컴파일 확인 완료, 플레이 테스트는 사용자 진행.

조건: 설평 지목 + 핵심 단서 하나 이상 부족.

주인공은 설평을 지목하지만, 조조는 확보된 근거로 확인 가능한 범위만 인정한다. 문서 회수로 이어지는 결정적인 조치를 이끌어내지 못한 채 이번 조사가 끝난다. 설평의 체포·도주·처형을 임의로 확정하지 않으며, 플레이어가 얻지 못한 본명이나 밀서 내용도 공개하지 않는다.

조조 대사 초안: “그자를 지목한 까닭은 들었다. 하지만 아직 밝혀지지 않은 일을 사실로 기록할 수는 없다.”

결과: 설평 지목 / 사건 입증 미완료 / 문서 행방 불명.

확보 근거에 따른 문구 차이: 호적만 있으면 신고 신원 문제, 밀서만 있으면 문서에 적힌 연결과 추가 신원 대조 필요성, 둘 다 없으면 제출한 진술·기록의 한계만 언급한다. 밀서 하나로도 유죄 입증이 충분해 보이지 않도록 밀서의 진위·귀속 확인 구조를 추가 설계해야 한다. 아무 근거 없이 맞힌 경우 ‘범인을 밝혀냈다’는 칭찬은 하지 않는다.

## 배드엔딩 제안 — 채모 지목 / 빗나간 지휘선

채모를 중심으로 지휘 계통과 훈련 기록을 재조사하느라 실제 반출 경로를 놓친다. 채모가 설명한 출항 중단 사실과 절도 책임이 별개였다는 점을 보여 준다. 근거 없는 지목만으로 처형하지 않는다.

조조 대사 초안: “훈련을 지휘한 책임과 문서를 훔친 죄는 같은 것이 아니다.”

결과: 채모 지목 / 절도 입증 실패 / 문서 오나라 전달 완료.

## 배드엔딩 제안 — 장윤 지목 / 장부 밖으로 사라진 문서

장윤과 군량 기록을 중심으로 조사하지만 군량 지급의 지속은 보수·육상 훈련과 양립한다. 보고의 실제 근거를 존중하며 플레이어가 선택하지 않은 ‘군량 지급은 불가능했다’는 주장을 강제로 대사에 넣지 않는다. 잘못된 대상에 조사가 집중된 사이 반출을 막지 못한다.

조조 대사 초안: “군량 장부를 살핀 것만으로 사라진 문서의 행방이 밝혀지지는 않았다.”

결과: 장윤 지목 / 절도 입증 실패 / 문서 오나라 전달 완료.

## 배드엔딩 제안 — 두석 지목 / 빈 경비 자리

두석의 근무 이탈 책임과 문서를 가져간 사람의 책임을 구분하지 못한다. 두석에 대한 조사에 집중하지만 절도 증거를 확보하지 못하고 실제 반출을 놓친다. 이탈 이유나 시각은 아직 정하지 않았으므로 새 자백·목격담을 추가하지 않는다.

조조 대사 초안: “자리를 비운 책임은 물을 것이다. 그러나 그자가 문서를 가져갔다는 증거는 어디 있느냐?”

결과: 두석 지목 / 경비 공백과 절도 책임 혼동 / 문서 오나라 전달 완료.

## 미해결 배드엔딩 후보 — 늦어 버린 보고

기한을 넘겨 사건을 해결하지 못한 경우의 후보다. 보고가 충분한 결론에 이르지 못한 채 전달을 막을 기회를 잃는다. 기한 전에 ‘범인을 밝히지 못했다’ 또는 ‘의심하지만 확정하지 못했다’고 말한 것만으로 이 엔딩에 보내지는 않는다. 해당 보고를 최종 확정할 때의 처리는 별도 합의가 필요하다.

조조 대사 초안: “주어진 시간은 끝났다. 사라진 문서에 대비해야 할 때다.”

결과: 조사 미해결 / 문서 오나라 전달 완료.

## 공통 연출 제안

사용자 요청으로 배드엔딩에 처형 암시와 재조사 메시지를 구현했다. 처형 대상은 임시 참모인 주인공으로 해석했다. 기존 배드엔딩의 문서 전달 설명 이후 조조가 주인공에게 참형을 명하고 군사들이 데려간다는 텍스트를 보여 준다. 계속을 누르면 1.2초간 암전하고 0.8초간 검은 화면을 유지한 뒤 ‘다시 조사하시겠습니까?’를 표시한다. 처형 동작·신체 훼손·타격음은 넣지 않는다. ‘예’는 이름 입력부터 초기화하여 재시작하고 ‘아니요’는 결과 화면으로 이동한다. 진엔딩과 노멀엔딩에는 이 연출을 적용하지 않는다. 시간 초과 배드는 기존대로 자동 진입 조건 미구현이다. 스크립트 컴파일 통과, 플레이 테스트는 사용자 진행.

모든 배드엔딩은 지목 직후 곧바로 문서가 순간 이동한 것처럼 보이지 않도록 ‘그 뒤’의 시간 경과를 보여 준다. 오나라 측 책상에 화공대비책이 놓이는 짧은 장면으로 전달 완료를 알리되 전달자의 얼굴·본명·설평임을 드러내는 특징은 보여 주지 않는다. 노멀에서는 이 장면을 사용하지 않는다.

결과 화면에는 최종 보고 요약, 해당 결말에서 확인 가능한 사실, 문서 상태만 보여 준다. 미확보 증거의 정답 목록을 공개하지 않는다. 다시 시작과 제목 화면으로 돌아가기 등 화면 기능은 추후 구현한다.

## 2026-09-30 전달 일정 확정 및 게임 반영

접선은 조사 나흘째 새벽 한 차례다. 밀서에 사전 연락·문서 발송 금지를 명시하고 약정일 대조 안내를 표시한다. 설평은 공동 근무 중 두석의 빈 경비 자리를 직접 확인해 서기의 접근 권한으로 범행했다. 진엔딩에서 이 경위를 공개하고 예정된 인계 전에 소지 문서를 회수한다. 모든 배드엔딩의 오나라 전달 장면은 나흘째 새벽 이후 후일담이다. 노멀엔딩은 문서 행방을 확정하지 않는다. 기존 사흘·12회와 엔딩 판정 조건은 유지한다. 이 확정 사항은 앞선 전달 시점 미정 표기보다 우선한다.
