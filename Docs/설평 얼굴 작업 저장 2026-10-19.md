# 설평 얼굴 작업 저장 — 2026-10-19

사용자 요청으로 외형 수정을 중단하고 현재 Unity 씬·Blender 편집 원본을 저장했다. 완성 또는 판매 품질 통과가 아니다. 편집 원본 자체는 [ArtSources](../ArtSources/README.md)에 포함하며 도구로 복원할 수 있다.

## 저장한 변경

- 사용자가 제시한 기존 얼굴의 정체성과 의상을 기준으로 복원하고 얼굴·몸·눈·수염을 분리했다. 앞선 둥근 얼굴 버전을 기준으로 개선했다고 보고하지 않는다.
- 얼굴 UV 경계의 틈을 막고 눈꺼풀·입 주변의 형상과 피부색·거칠기를 보정했다. 눈썹·콧수염 424개 리본은 자체 제작이다. Blender 5.2.2에서 원본을 조립하고 Cycles 16 samples, margin 12px로 베이킹했다. 몸·얼굴 색/탄젠트 노멀 2K, 얼굴 금속 R/매끄러움 A 1K, 눈 RGBA 512px, 수염 RGBA 256px이다. 눈·수염은 기하 노멀을 사용하며 고정 AO·조명을 색에 추가하지 않았다.
- 몸통의 원본 노멀을 보존해 노멀 맵을 다시 베이킹했다. Unity의 기존 `Parts20261018/Seolpyeong/Parts_Game.asset` GUID를 유지하고 새 얼굴 묶음은 `Assets/Art/Characters/SeolpyeongFace20261019`에 적용했다. 실제 씬은 Investigation이다.
- 기존 대기·상호작용을 유지했다. 복원된 얼굴 높이에 맞춰 기존 입 변형 중심을 조정했다. 얼굴 동작을 새로 제작한 작업은 아니다.

## 미해결과 재개 지점

**Play에서 눈이 청록색으로 보인다.** 눈 이미지와 GPU 색 샘플은 갈색이며 UV·노멀의 NaN/Infinity 및 MaterialPropertyBlock은 발견하지 못했다. 환경 반사 해제와 전용 Eye 셰이더는 해결하지 못했다. 임시 Unlit 진단은 정상 색을 보였으나 최종 재질로 채택하지 않았고 진단 임시 객체는 복원했다. 현재 저장된 버전에도 문제가 남아 있다. 원인은 확정하지 않았다. 재개 시 눈의 길이 0 노멀·탄젠트와 조명 패스를 먼저 계측해야 한다.

실제 Play 정면·얼굴·측면·대화 접근 화면을 검사했으며 상호작용은 통과했다. 눈 외형은 실패다. 이전 얼굴 캡처와 현재 캡처의 카메라가 달라 최종 동일 조건 비교를 완료했다고 보지 않는다. 새 실행 빌드·전체 동선 회귀·상용 품질 검수는 하지 않았다.

얼굴은 창작 인물이며 실제 초상으로 고증하지 않는다. 한대 남성의 책·교차 깃 비교는 [고궁박물원 陶庖厨男俑](https://www.dpm.org.cn/collection/sculpture/233370.html)을 참고했다. 구체적인 현재 관모 형태와 신분 대응은 미확정이며 고증 완료가 아니다. 생성 질감 후보는 고증 근거가 아니다.

Blender와 Unity·웨일 창을 종료하거나 재실행하지 않았다. Unity는 Play를 종료한 편집 상태로 씬을 저장했다. 현재 Blender에는 설평 얼굴 원본이 열려 있다. 검증 자료와 이미지 생성 기록은 보존 원본 및 원본 묶음의 제작 기록을 따른다.
