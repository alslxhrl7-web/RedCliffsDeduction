# 군영 배경음과 날짜 암전

## 최신 연출

이 문서는 앞선 날짜 연출 문서의 합성 종소리와 날짜 안내 확인 단계를 대체한다.

- 0.45초 검은 화면으로 암전 → 날짜 자막 1.8초 → 0.55초 화면 복귀. 총 약 2.8초.
- 암전 완료 후에만 날짜 자막을 보여준다. 날짜와 마지막 조사일 표시만 남기며 잔여 횟수는 기존 일정 화면에서 확인한다.
- 별도 종·북 효과음을 재생하지 않는다. 추가 날짜 확인 버튼 없이 원래 선택한 조사 또는 일정 화면으로 자동 복귀한다.
- 이동과 대화 입력 잠금, 전환 취소 및 저장 복원 규칙은 유지한다.

## VARCO 군영 환경음

채택한 생성 프로젝트: https://sound.varco.ai/app/editor/60889a36-dd13-4b1a-8742-a472f72b7ae4

프롬프트는 적벽대전 직전 군영을 상상한 환경음이다. 역사적으로 고증한 음원이라는 의미는 아니다. 사용자가 바람·깃발 버전을 채택하여 게임 배경음을 교체했다. 낮고 길게 이어지는 바람을 배경으로, 선명하고 짧은 깃발의 펄럭임을 전경으로 구분해 혼합하도록 요청했다. 천막·발걸음·장비·물소리·새·음악·북·종·대사·전투·현대 기계음을 제외했다. 생성 결과에서 각 요소가 의도대로 들리는지는 실제 청음으로 판단해야 한다.

채택 원본은 `AudioPreviews/varco-wind-flags-original.mp4`, 추출 WAV와 미리듣기는 같은 폴더에 보존한다. 원본 길이는 10.24초다. 게임용 `Assets/Resources/Audio/CampWindAmbience.wav`는 시작·끝 0.6초를 선형 겹침으로 연결한 9.64초 스테레오 반복 음원이다. 음량은 피크 0.45로 보정했다. 반복 경계의 청감상 자연스러움은 아직 확인하지 않았다. 이전 천막 포함 버전의 원본도 `AudioPreviews/varco-ancient-camp-original.mp4`에 보존한다.

조사 세션의 AudioSource에서 반복 재생하며, 날짜 전환 UI와 분리하여 암전 중에도 끊지 않는다. 소리가 들리지 않는다는 사용자 피드백 후, 서막 종료 조건을 제거해 시작 화면과 조조 대화부터 재생하도록 수정했다. 최종 보고 완료 시 정지한다. 날짜별 음량은 0.40 / 0.44 / 0.48로 올리고 완만하게 변경한다. 음원 로드 실패 시 콘솔에 경로를 경고한다. 실제 무음 원인이 서막 조건인지 다른 실행 환경 문제인지는 아직 확인하지 않았다. 별도의 긴장감 음원이나 음정 변조는 추가하지 않았다.

## 확인 범위

오디오 파일 추출·길이·채널·샘플레이트·피크와 코드 차이만 확인했다. Unity 실행·빌드·실제 청음 검증은 하지 않았다. 날짜 검사 도구는 자동 복귀에 맞게 수정했지만 실행하지 않았다. 기존 두 신규 파일의 meta에서 줄이 분리된 guid를 원래 값 그대로 한 줄로 정리했다.
