# 군령 조사 구현 기록

## 요청과 적용 범위

사용자 요청: 교체 수법·원본 행방·조작자 입증을 채우기 전까지 작성한 통합 집필안을 Unity에 반영하고 다음 안을 진행한다.

이번 요청으로 통합 집필안의 문서 이동·은닉 동기·자료 비교 구간을 구현 대상으로 채택했다. 한진의 실제 범행 수법과 원래 본문 행방, 새 최종 판정·전투 엔딩은 확정하거나 구현하지 않았다.

## 게임 변경

- Investigation 씬의 새 게임은 군령 분실 조사로 시작한다. 조조의 임시 참모 임명·이름 입력·천막 시작·1인칭 이동을 유지한다.
- 보관 자리와 반출 대장, 채모의 미수령 확인, 장윤의 인계 절차 설명을 연결했다. 문서고를 전부 조사하지 않아도 수군 진영으로 갈 수 있다.
- 전달자의 제삼자 인계 주장, 부대의 파견 부인 또는 두석의 동선 설명, 수송 물품 반입 기록을 대조해 군령을 회수한다. 전달자 자백은 회수 필수 조건이 아니다.
- 전달자 옆에 조사 가능한 수송 물품 상자를 추가했다. 기존 수군 탁자와 기록 담당자는 배치도와 발급 자료 조사로 연결했다.
- 번호·부대만 확인하고 대조 완료를 남긴 실수, 뒤늦은 회신 장소 차이 발견, 임시 보류, 조사 시작 이후 거짓말·은닉을 대화에 반영했다.
- 군령·인계 확인표를 비교해 불일치를 선택하고, 보관 부본·승인 확인으로 정식 변경 가능성을 검토한다. 오답은 증거를 지우거나 진행을 잠그지 않는다.
- 수군 배치도에서 감시 공백 가능성을 추론한 뒤 조조에게 중간 보고한다. 기존 호적·밀서 기반 엔딩을 호출하지 않는다.
- 설평의 과거와 장윤의 보호 진술은 선택 조사로 제공하며 회수·비교·중간 보고에 필요하지 않다. 상세 과거 조사 전체를 완성한 것은 아니다.
- 수첩은 자료·진술·대조 결과·추론을 구분한다. 자유롭게 선을 잇는 별도 조사 보드는 아직 만들지 않았다.

## 구현용 단서와 임시 규칙

제17호 발급 번호, 보관소 반입 기록과 꾸러미 표식, 별도 보관 부본·승인 확인을 실제 조사 자료로 작성했다. 이는 게임 진행용 창작 자료이며 역사 제도가 아니다. 원래 군령 본문이 사라진 방법이나 범인 귀속 증거로 사용하지 않는다.

기존 시간 시스템은 임시 12회로 유지하고 새 조사 묶음 일곱 개만 사용한다. 부대 확인 경로의 검증 플레이는 여섯 회, 두석 조사까지 더하면 일곱 회다. 같은 묶음의 재질문과 재열람·비교·선택 과거 조사는 추가 차감하지 않는다. 이 수치는 후속 수사 전체의 확정 비용이 아니다. 새 구간의 메뉴에서는 임의 시간 보내기를 제공하지 않는다.

## 저장

새 이야기 저장 버전은 2이며 조사 사실과 추론 결과를 별도로 저장한다. 새 파일명은 order-investigation-save.json 및 같은 접두사의 슬롯·자동저장이다. 예전 investigation-save.json 파일을 덮어쓰거나 옛 증거를 새 사건 증거로 변환하지 않는다.

자료 화면에서 저장한 경우 확보 상태와 시간·장소를 복원하고 수첩에서 재개한다. 모든 개별 질문 화면의 정확한 위치까지 복원하는 구현은 아니다. 이동 화면과 천막 방문은 기존 복원 기능을 사용한다.

## 검증

- Unity 런타임 컴파일 통과.
- 실제 Play Mode 검사 24개 항목 통과: Logs/OrderChapter/checks.txt, COMPLETE failures=0.
- 이름 입력과 새 임무, 조기 보고, 자유 이동, 조사 비용·재방문·날짜 전환, 자백 없는 회수, 오답 후 재비교, 부본·승인 검증, 은닉 동기, 저장 왕복과 스냅샷 독립성, 구버전 조사 ID 혼입 거부, 씬 상호작용, 중간 보고·자동저장·현장 복귀 확인.
- 동선 증거를 사용하는 대체 회수 조건과 선택 비밀 없는 보고 가능성은 상태 검사로 확인. 해당 대체 경로 전체를 별도 실제 이동 플레이로 반복하지는 않았다.
- 수첩과 중간 보고 화면 캡처를 직접 확인. 긴 본문은 기존 스크롤 UI로 읽는다.
- 실행 검사 후 현재 Unity 콘솔 오류 0, 컴파일 실패 없음 확인.
- 보관소를 정면 3m 이내, 서 있는 눈높이에서 바라볼 때 다른 물체에 가리지 않고 조사 콜라이더에 닿는지 확인: Logs/OrderChapter/visibility.txt 통과.

새 itch 빌드·업로드·Git 커밋은 수행하지 않았다. 실행 검사는 사용자의 실제 저장과 다른 임시 저장 폴더에서 진행했다.
