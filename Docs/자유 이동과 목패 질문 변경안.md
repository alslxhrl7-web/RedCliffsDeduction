# 문서고 자유 이동과 목패 발견 후 질문

사용자가 요청한 진행 방향을 정리한 구현용 문서다. 2026-09-30 게임 코드에 적용했다. 기존 Investigation 씬의 출입문·목패·NPC 상호작용이 수정된 코드를 그대로 사용하므로 씬 오브젝트를 다시 배치할 필요는 없다.

## 1. 문서고 조사를 끝내지 않아도 이동

조조에게 임무를 받고 문서고에 도착하면 수군 진영으로 이동할 수 있다. 빈 보관함 조사, 설평의 최초 경력 진술, 두석 대화, 목패 확인을 이동의 필수 조건으로 삼지 않는다.

문서고 출입문, Esc의 장소 이동, 수첩의 장소 선택은 동일한 조건을 적용한다. ‘떠나기 전에 확인할 일’로 이동을 차단하지 않는다. 남은 조사는 수첩에 미확인으로 남기며 언제든 돌아와 이어갈 수 있다. 이동 때문에 단서가 자동 확보되거나 사라지지 않는다.

두석의 안내 대사 예시:

> 제 옆의 문을 나서면 수군 진영입니다. 채모 장군과 장윤 장군을 만나실 수 있습니다. 돌아오실 때는 진영 입구의 나무 표지를 살펴보십시오.

목표 안내는 강제 명령 대신 선택 가능한 행동을 제시한다.

> 문서고를 살피거나 출입문을 통해 수군 진영으로 이동할 수 있다.

수군 진영을 먼저 방문한 경우 채모·장윤은 당시 훈련과 군량에 대해 독립적으로 설명한다. 아직 듣지 않은 설평의 발언을 주인공이 알고 있는 것처럼 대화하지 않는다. 두 사람의 설명을 다 들은 뒤 추가 조사 대상 선택과 보고 준비는 기존처럼 가능하다.

## 2. 목패 질문은 직접 발견한 뒤 해금

처음 설평과 대화할 때는 목패에 관한 질문을 표시하지 않는다. 비활성 선택지로도 미리 노출하지 않는다. 문서고의 실제 목패 오브젝트를 E키로 조사해야 발견 상태가 된다.

| 상태 | 허용 행동 | 기록 |
|---|---|---|
| 목패 미발견 | 주변 물건 조사, 일반 대화 | 수첩에는 미확인만 표시 |
| 목패 발견 | 설평에게 목패의 소유·사용 이력 질문 | 물결 무늬와 비대칭 세 홈을 관찰한 사실 |
| 소유 이력 답변 완료 | 이후 밀서와 비교·취조에 활용 | 설평이 형주 근무 때부터 자신의 물건으로 썼다는 진술 |

질문 예시:

> 저 서류 묶음에 달린 목패는 누구의 것인가?

답변 예시:

> 제 것입니다. 형주에서 일할 때부터 개인 서류를 묶는 데 썼습니다.

발견은 관찰이고 소유 이력은 인물 진술이다. 질문만으로 발견 상태를 자동 생성하지 않는다. 소유 답변 도중 취소하면 소유 이력 확인을 완료 처리하지 않는다. 다시 질문해 끝까지 들으면 정상적으로 기록한다.

## 3. 조사 순서가 달라도 연결 유지

- 수군 진영 → 문서고 → 목패 발견 순서도 가능하다.
- 밀서를 먼저 발견했어도 목패를 직접 조사하기 전에는 소유 질문이 열리지 않는다. 이후 목패로 돌아가 조사할 수 있다.
- 목패를 발견했다고 곧바로 연락패나 첩자 신분을 공개하지 않는다. 밀서 발견 전에는 평범한 개인 물건으로만 기록한다.
- 발견·본 대조·소유 이력·취조 완료를 별도로 관리한다. 발견만으로 검증된 밀서 단서나 진엔딩이 열리지 않는다.
- 모순 비교에 필요한 진술·명령서·재확인은 유지한다. 빈 문서 보관함 확인을 훈련 진술 비교의 불필요한 선행 조건으로 삼지 않는다.
- 호적 대조, 조조의 개인 서류 조사 허가, 검증된 밀서 획득 조건은 유지한다.

## 4. 날짜와 조사 기록

이동과 재방문은 시간을 쓰지 않는다. 문서고 초동 조사 시간은 기존처럼 빈 보관함과 설평의 최초 경력 진술을 둘 다 확보했을 때 한 번만 진행한다. 수군 설명을 먼저 확보했다면 그 묶음의 시간이 먼저 진행된다. 장소 이동 자체로 문서고 묶음을 완료 처리하지 않는다.

목패 발견과 소유 질문은 별도 시간 차감 항목으로 추가하지 않는다. 기존 ‘목패 대조와 취조 완료’ 묶음만 한 번 차감한다. 모든 기록과 날짜는 장소 왕복 후에도 유지한다.

## 5. 코드 적용 시 점검할 곳

- `ShowTravel`, `ShowStageSelection`, `EnterNavalCamp`: 이동 조건에서 `FirstInvestigationComplete`를 분리한다. 도입 완료와 유효한 이동 경로 확인은 유지한다.
- `ShowJournalPage`: 이동·추가 조사 메뉴가 문서고 초동 조사 미완료 때문에 사라지지 않도록 한다.
- `ShowTestimonyComparison`: 비교 자료 조건과 문서고 완료 조건을 분리한다.
- `TalkToDuseok`, `NextInvestigationStep`: 문서고 조사부터 해야 한다는 안내를 수정한다.
- `ShowSeolpyeongFollowUp`: `TokenObserved`일 때만 목패 질문을 추가한다. 답변 완료 시에는 소유 이력만 기록한다.
- `InspectPersonalToken`: 실제 오브젝트 조사만 목패 발견을 기록하도록 한다. 다른 대화·수첩·밀서 열람에서 이 상태를 자동 생성하지 않는다.

## 6. 적용 후 확인 시나리오

1. 문서고에서 아무것도 조사하지 않고 수군 진영으로 이동·귀환한다.
2. 보관함만 조사하거나 설평만 만난 경우에도 이동한다.
3. 목패 발견 전에는 설평의 대화 어디에도 목패 질문이 없다.
4. 실제 목패를 조사한 뒤 질문이 생기며, 답변 취소와 재개가 정상 작동한다.
5. 수군 조사부터 진행해도 필요한 자료를 모으면 모순 비교·호적·허가·밀서·취조·진엔딩으로 연결된다.
6. 재방문과 반복 질문으로 조사 시간이 중복 차감되지 않는다.

기존 문서에서 문서고 초동 조사를 이동 필수 조건으로 삼거나 질문만으로 목패를 발견하도록 설명한 부분은 이 구현 내용을 따른다. 시간 계산의 문서고 초동 조사 완료 기준은 그대로 유지한다. 기존 수첩 페이지 순서 변경은 보존했다. 플레이 테스트는 사용자 진행으로 남긴다.
