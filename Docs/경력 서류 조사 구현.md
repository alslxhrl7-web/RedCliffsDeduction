# 경력 서류 조사

2026-09-29 구현. 기존 Investigation 씬의 수군 진영 입구 왼편에 기록 담당자와 두 서류가 놓인 탁자를 추가했다. 담당자는 기본 도형으로 구성한 임시 외형이다.

## 직접 확인 순서

1. 수군 진영에 들어가 입구 왼편의 기록 탁자로 이동한다.
2. 기록 담당자에게 E로 말을 걸거나 탁자를 향해 E를 누른다.
3. 인력 인계 명부와 이전 근무 기록을 원하는 순서로 읽는다.
4. 두 장을 읽으면 ‘확인한 내용 정리’에서 실제 근무 사실과 미확인 신원을 구분한다.
5. J 수첩 8·9쪽에서 기록을 다시 읽는다. 조조에게 최종 보고할 때 읽은 서류만 제출 목록에 나타난다.

명부의 신고 출신지는 우선 형주 남군 강릉으로 정했다. 이는 게임 사건의 창작 세부 설정이며, 신고된 내용이지 확인된 신원이 아니다. 업무는 실제 군량 장부 정리와 훈련 보고서 취합으로 기록한다. 직접 목격하지 않았다는 정답, 가명, 본명과 첩자 신분은 이 단계에서 공개하지 않는다.

호적 대조·서류 기반 재질문·밀서·엔딩은 연결되어 있다. 상세 흐름은 [모순 발견 이후 조사](모순%20발견%20이후%20조사%20구성.md)를 따른다. 서류 열람에 모순 발견을 강제하지 않으며, 미리 읽어도 이후 조사를 진행할 수 있다.
